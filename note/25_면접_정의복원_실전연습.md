## 1. 참조 변수 · 클래스 · 객체 · 업캐스팅

**기본 질문:** 참조 변수 · 클래스 · 객체 · 업캐스팅을 정확히 정의하고 구별하세요.

**꼬리 질문:** `List<String> b = names; names = new LinkedList<>();` 뒤에는 `b`가 원래 `ArrayList`를 참조한다. 변수의 재대입은 기존 객체를 비우지 않는다.

**자주 하는 오류:** `List`가 객체로 생성되었다는 말은 틀리다. `List`는 인터페이스이며, `ArrayList` 객체의 참조를 `List` 타입 변수에 대입하는 것이 업캐스팅이다. `List`는 순서가 있으며 중복을 허용한다.

**답변 기준:** 참조 변수의 선언 타입은 컴파일 시 사용할 수 있는 멤버를 결정하고, 실제 객체의 클래스는 오버라이딩된 인스턴스 메서드의 실행 구현을 결정합니다. `List`는 인터페이스이므로 직접 생성하지 않고 구현 클래스의 객체를 참조합니다.

## 3. 0행 · 0 · NULL · COUNT

**기본 질문:** 0행 · 0 · NULL · COUNT을 정확히 정의하고 구별하세요.

**꼬리 질문:** `SELECT COUNT(*) FROM users WHERE id=99`와 `SELECT id FROM users WHERE id=99`의 반환 행 수와 값의 차이를 설명한다.

**자주 하는 오류:** `NULL`은 특정 열 값의 부재·미상을 나타내는 표식이지, 숫자 0이나 빈 문자열, 조회 결과 0행과 같지 않다.

**답변 기준:** 조건에 맞는 행이 없는 일반 조회는 결과가 0행입니다. 집계 함수 COUNT(*)는 일치 행 수를 계산하므로 0을 포함한 결과 행을 반환할 수 있습니다.

## 6. undefined · null · 값 · 비동기

**기본 질문:** undefined · null · 값 · 비동기을 정확히 정의하고 구별하세요.

**꼬리 질문:** `async function f(){return 3}`의 `f()` 결과는 숫자 3이 아니라 Promise다. `await f()`의 평가 결과는 3이다.

**자주 하는 오류:** `async` 함수가 즉시 최종 값을 반환한다는 말은 틀리다. `async` 함수는 Promise를 반환하며 `await`는 해당 비동기 결과를 기다려 이후 실행을 이어간다.

**답변 기준:** JavaScript에서 비동기 작업은 Promise로 결과나 실패를 표현할 수 있고, async/await는 이를 순차적인 코드 형태로 다루는 문법입니다.

**답변 기준:** forward는 서버 내부에서 같은 요청을 다른 자원에 전달하고, redirect는 클라이언트가 새로운 요청을 하도록 응답하는 방식입니다.
