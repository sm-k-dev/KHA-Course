Cursor 유용한 단축키 정리

비전공자도 이해할 수 있는 AI 코드 에디터 Cursor 실전 단축키 가이드

1. Cursor란?

Cursor는 AI 기능이 들어간 코드 편집기입니다. 쉽게 말하면 Visual Studio Code처럼 코드를 작성하는 프로그램인데, 여기에 AI가 붙어서 코드를 설명해주고, 고쳐주고, 자동완성까지 도와줍니다.

비전공자용 설명:
Cursor는 개발자를 위한 “AI 비서가 들어있는 메모장”이라고 생각하면 됩니다. 내가 코드를 선택하고 “이거 고쳐줘”, “설명해줘”, “Spring Boot 방식으로 바꿔줘”라고 말하면 AI가 바로 도와줍니다.

2. 가장 먼저 외워야 하는 핵심 단축키 TOP 5

기능 Windows 단축키 언제 쓰나요?
AI 채팅 열기 Ctrl + L AI에게 코드 설명, 오류 원인, 리팩토링 방향을 물어볼 때 사용합니다.
선택한 코드 AI 수정 Ctrl + K 코드를 선택한 뒤 “이 코드 고쳐줘”처럼 바로 수정 요청할 때 사용합니다.
파일 빠르게 찾기 Ctrl + P 프로젝트 안의 Controller, Service, HTML, JS 파일을 빠르게 찾을 때 사용합니다.
전체 검색 Ctrl + Shift + F 프로젝트 전체에서 특정 단어, 함수명, URL 주소를 찾을 때 사용합니다.
터미널 열기 Ctrl + ` npm, git, Spring Boot 실행 명령어를 입력할 때 사용합니다.
추천 학습 순서: 처음에는 Ctrl + L, Ctrl + K, Ctrl + P 이 3개만 먼저 익혀도 충분합니다.

3. AI 관련 단축키

AI Chat 열기

Ctrl + L

Cursor 오른쪽 또는 별도 창에서 AI와 대화할 수 있습니다.

예시 질문:
“이 Java 코드를 비전공자도 이해할 수 있게 설명해줘”
“이 오류가 왜 발생하는지 알려줘”
“Spring Boot 3 방식으로 바꿔줘”

선택 코드 AI 수정

Ctrl + K

코드 일부를 드래그해서 선택한 뒤 AI에게 바로 수정 요청할 수 있습니다.

예시 명령:
“주석 추가해줘”
“중복 코드 제거해줘”
“초보자도 이해하기 쉽게 바꿔줘”

AI 자동완성 수락

Tab

Cursor가 회색 글씨로 코드를 추천하면 Tab 키로 받아들일 수 있습니다.

AI가 “이 다음 코드는 아마 이렇게 작성할 것 같아요”라고 제안하면 Tab으로 “좋아, 이 코드 사용할게”라고 선택하는 것입니다.

4. 파일 이동과 검색 단축키

기능 단축키 쉬운 설명
파일 찾기 Ctrl + P 파일 이름을 입력해서 바로 열 수 있습니다.
전체 검색 Ctrl + Shift + F 프로젝트 전체에서 특정 단어를 찾습니다.
현재 파일 안에서 검색 Ctrl + F 현재 보고 있는 파일 안에서만 단어를 찾습니다.
현재 파일 안에서 바꾸기 Ctrl + H 특정 단어를 다른 단어로 바꿉니다.
Spring Boot 프로젝트 예시:
Ctrl + P → UserController 입력 → 바로 Controller 파일 열기

5. 코드 이동 단축키

기능 단축키 언제 쓰나요?
정의로 이동 F12 함수, 클래스, 변수의 실제 선언 위치로 이동합니다.
이전 위치로 이동 Alt + ← 방금 전에 보던 코드 위치로 돌아갑니다.
다음 위치로 이동 Alt + → 이전 위치로 갔다가 다시 앞으로 이동합니다.
파일 안의 함수 목록 보기 Ctrl + Shift + O 현재 파일 안에 있는 함수나 메서드 목록을 빠르게 확인합니다.
비전공자용 설명:
코드는 여러 파일이 연결되어 있습니다. F12는 “이 코드가 실제로 어디서 만들어졌는지 찾아가기” 버튼입니다.

6. 코드 정리 단축키

기능 단축키 설명
코드 자동 정렬 Shift + Alt + F 들여쓰기와 줄 정리를 자동으로 해줍니다.
Import 정리 Shift + Alt + O Java에서 사용하지 않는 import를 정리합니다.
이름 한 번에 변경 F2 변수명, 함수명, 클래스명을 안전하게 한 번에 변경합니다.
주의: 파일 전체를 복사해서 직접 바꾸는 것보다 F2로 이름을 변경하는 것이 더 안전합니다. 연결된 코드까지 함께 바뀌기 때문입니다.

7. 여러 줄을 한 번에 수정하는 단축키

기능 단축키 쉬운 설명
여러 커서 만들기 Alt + 마우스 클릭 여러 위치에 커서를 두고 동시에 입력할 수 있습니다.
같은 단어 하나씩 선택 Ctrl + D 같은 단어를 하나씩 추가 선택합니다.
세로 방향 선택 Shift + Alt + 드래그 여러 줄의 같은 위치를 세로로 선택합니다.
예시:
input 태그 10개에 같은 class를 붙여야 할 때, 하나씩 수정하지 않고 여러 줄을 동시에 수정할 수 있습니다.

8. 터미널 단축키

기능 단축키 사용 예시
터미널 열기 Ctrl + ` 명령어 입력 창을 엽니다.
새 터미널 만들기 Ctrl + Shift + ` 터미널 창을 하나 더 만듭니다.
자주 쓰는 명령어 예시:
npm install
npm run dev
git status
git add .
git commit -m "작업 내용"

9. 웹 풀스택 개발자 추천 사용 흐름

Spring Boot 개발할 때

  1. Ctrl + P로 Controller 파일을 찾습니다.
  2. F12로 Service 또는 Repository 구현 위치로 이동합니다.
  3. 오류가 있는 코드를 선택하고 Ctrl + K로 AI에게 수정 요청합니다.
  4. 이해가 안 되는 코드는 Ctrl + L로 AI에게 설명을 요청합니다.

HTML / CSS / JavaScript 개발할 때

  1. Ctrl + P로 HTML 파일을 엽니다.
  2. Ctrl + F로 수정할 태그를 찾습니다.
  3. Alt + 클릭으로 여러 줄을 동시에 수정합니다.
  4. Shift + Alt + F로 코드 정렬을 합니다.

10. Cursor AI에게 요청하면 좋은 문장

상황 AI에게 이렇게 말하기
코드가 이해 안 될 때 “이 코드를 비전공자도 이해할 수 있게 설명해줘.”
오류가 났을 때 “이 오류의 원인과 해결 방법을 단계별로 알려줘.”
Spring Boot 코드 수정 “Spring Boot 3 기준으로 더 좋은 코드로 리팩토링해줘.”
JPA 성능 개선 “JPA N+1 문제가 발생할 수 있는지 확인하고 개선해줘.”
React 코드 수정 “React hooks 방식으로 초보자도 이해하기 쉽게 바꿔줘.”
