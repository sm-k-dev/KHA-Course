Tutorial: Using Thymeleaf

이 자습서는 Thymeleaf 공식 튜토리얼(3.1 버전)의 장 구성과 순서를 그대로 따릅니다. 각 개념을 프로그래밍 용어로 정의하고, 코드는 한 줄씩 해설합니다. 코드를 직접 입력하고 실행하면서 읽는 것을 전제로 합니다.

📖 기본 용어 정의

HTML: 웹 페이지의 구조를 적는 문서 형식입니다. <p>, <table> 같은 태그로 이루어집니다.

태그(Tag): < 와 > 사이에 적은 이름입니다. 시작 태그 <p> 와 종료 태그 </p> 가 한 쌍으로 글을 감쌉니다.

속성(Attribute): 태그 안의 이름="값" 형식의 설정입니다. 예: <a href="/product"> 에서 href 가 속성 이름입니다.

템플릿(Template): 서버가 값을 채워 넣을 수 있도록 th: 속성이 붙은 HTML 파일입니다.

템플릿 엔진(Template Engine): 템플릿 파일을 읽고 th: 속성을 처리한 뒤, 완성된 HTML 문자열을 만드는 Thymeleaf의 실행 객체입니다.

컨트롤러(Controller): 특정 URL 주소로 요청이 들어왔을 때 실행되는 자바 클래스입니다. @Controller 어노테이션으로 표시합니다.

메서드(Method): 클래스 안에 정의된 실행 단위입니다. 자바에서는 public String home() { ... } 형태로 씁니다.

어노테이션(Annotation): @ 기호로 시작하는 표식입니다. 프레임워크가 이 표식을 읽고 동작을 정합니다. 예: @GetMapping("/").

요청(Request)과 응답(Response): 브라우저가 서버에 주소를 보내는 것이 요청, 서버가 HTML을 돌려주는 것이 응답입니다.

모델(Model): 컨트롤러가 템플릿에 값을 전달할 때 쓰는 객체입니다. addAttribute(이름, 값) 메서드로 값을 넣습니다.

🧭 이 문서 사용법

📋 복사 버튼: 코드 상자 오른쪽 위 버튼입니다. 누르면 코드 전체가 클립보드에 복사됩니다.

☑️ 미션: 실습 과제입니다. 완료하면 체크 칸을 누릅니다.

🧠 퀴즈: 보기를 누르면 즉시 정답 여부가 표시되고 해설이 나옵니다.

진행률은 오른쪽 아래 원형 그래프에 표시되며, 이 브라우저의 localStorage(브라우저 내부 저장소)에만 저장됩니다.

0 실습 환경 준비

원문 예제는 서블릿(Servlet) API를 직접 호출하는 방식입니다. 서블릿은 자바로 웹 요청을 처리하는 표준 인터페이스입니다. 이 자습서는 Spring Boot 프레임워크를 사용합니다. Spring Boot는 서블릿 설정, 웹 서버(Tomcat) 실행, Thymeleaf 연결 등을 자동으로 설정해 주는 자바 프레임워크입니다. Thymeleaf의 문법과 동작은 원문과 같습니다.

1 Introducing Thymeleaf

1.1 Thymeleaf란?

Thymeleaf는 자바로 작성된 서버 측 템플릿 엔진입니다. "서버 측"은 HTML이 브라우저가 아니라 서버 프로그램 안에서 만들어진다는 뜻입니다. 템플릿 엔진은 HTML, XML, JavaScript, CSS, 일반 텍스트를 처리할 수 있습니다.

Thymeleaf의 중요한 특징은 자연 템플릿(Natural Templates)입니다. 자연 템플릿이란 th: 속성을 붙인 HTML 파일을 브라우저가 그대로 열어도 깨지지 않는 구조를 말합니다. 브라우저는 자기가 모르는 속성을 무시하기 때문입니다.

1.2 템플릿 모드(Template Mode)

템플릿 모드는 Thymeleaf가 파일의 형식을 어떻게 해석할지 정하는 설정값입니다. 6가지가 있습니다.

모드종류의미
HTML마크업 모드HTML4, HTML5, XHTML을 모두 허용합니다. 입력 HTML의 구조를 최대한 그대로 출력합니다. 웹 페이지에서 가장 많이 씁니다.
XML마크업 모드XML 문법을 따라야 합니다. 닫는 태그가 없거나 따옴표가 빠지면 오류가 납니다.
TEXT텍스트 모드태그를 해석하지 않고 글자로 취급합니다. 이메일 본문 같은 텍스트 파일에 씁니다.
JAVASCRIPT텍스트 모드자바스크립트 파일을 처리합니다. 서버 값을 자바스크립트 문법에 맞게 넣습니다.
CSS텍스트 모드CSS 파일을 처리합니다.
RAW무처리 모드Thymeleaf 문법을 전혀 처리하지 않고 그대로 출력합니다.
📖 용어 정의

마크업(Markup): 태그로 문서의 구조를 표시하는 형식입니다. HTML과 XML이 여기에 속합니다.

파싱(Parsing): 파일 글자를 읽어 태그, 속성, 글자 단위로 분해하는 작업입니다.

1.3 표준 방언(Standard Dialect)

방언(Dialect)은 th: 속성과 대괄호 문법 등 Thymeleaf 문법을 정의한 규칙 묶음입니다. 방언 안에는 프로세서(Processor)가 여럿 들어 있습니다. 프로세서는 특정 속성이나 태그를 발견했을 때 실행되는 처리 코드입니다. 예를 들어 th:text 를 처리하는 프로세서는 태그 안의 글자를 교체합니다.

표준 방언은 Thymeleaf 코어 라이브러리에 기본으로 들어 있는 방언입니다. 이 자습서에서 배우는 모든 th: 속성은 표준 방언의 기능입니다.

템플릿 예시
<input type="text" name="userName" value="James Carrot" th:value="${user.name}" />
💡 줄별 해설
부분의미
<input type="text" ...>문자 입력칸을 만드는 HTML 태그입니다.
name="userName"폼을 전송할 때 이 입력칸 값을 userName 이라는 이름으로 보냅니다.
value="James Carrot"브라우저가 기본으로 보여 주는 값입니다. Thymeleaf를 거치지 않은 원본 파일에서 보입니다.
th:value="${user.name}"서버 처리 시 value 속성 값을 user.name 의 값으로 교체합니다. 브라우저는 th:value 를 모르므로 무시합니다.
🛠️ 미션 1

src/main/resources/templates/ 폴더에 test.html 파일을 만듭니다. 파일 안에 <p th:text="안녕하세요">임시 글</p> 을 적고, 파일을 브라우저에서 직접 열어 "임시 글"이 보이는지 확인하세요. 그다음 서버 주소로 접속하면 결과가 어떻게 다른지도 메모하세요.

🧠 퀴즈 1-1. 웹 페이지 파일을 처리할 때 사용하는 템플릿 모드는?

정답은 ②번 HTML입니다. HTML 태그 구조를 유지하면서 처리합니다.

🧠 퀴즈 1-2. th: 속성이 붙은 HTML을 브라우저에서 직접 열어도 화면이 깨지지 않는 이유는?

정답은 ①번입니다. HTML 표준은 알 수 없는 속성을 오류로 처리하지 않고 무시하도록 정해져 있습니다.

2 The Good Thymes Virtual Grocery

원문은 Good Thymes Virtual Grocery(GTVG)라는 가상의 식료품 쇼핑몰 예제 프로그램을 사용합니다. 이 예제에는 다음 데이터 클래스가 있습니다.

클래스역할주요 필드 예시
Product판매 상품 한 개를 표현하는 클래스id, name, price, inStock, comments
Customer고객 한 명을 표현하는 클래스name, address
Order주문 한 건을 표현하는 클래스id, customer, total
Comment상품 후기 한 건을 표현하는 클래스content, productId

2.1 요청과 응답의 흐름

브라우저가 주소 / 를 요청했을 때 실행되는 순서는 다음과 같습니다.

① 브라우저: GET / 요청→ ② DispatcherServlet: 주소에 맞는 컨트롤러 찾기→ ③ HomeController.home() 실행→ ④ "home" 문자열 반환→ ⑤ 템플릿 엔진: templates/home.html 처리→ ⑥ HTML 응답 전송
단계실행 주체설명
②DispatcherServletSpring Boot가 자동으로 등록한 요청 분배 클래스입니다. 개발자가 직접 호출하지 않습니다.
③HomeController개발자가 작성한 클래스입니다. 화면에 보낼 데이터를 Model에 넣습니다.
④HomeController반환된 문자열 "home" 은 화면 파일 이름입니다. 실제 파일 경로가 아닙니다.
⑤Thymeleaf문자열 "home" 에 접두사 templates/ 와 접미사 .html 을 붙여 파일 경로를 만든 뒤 파일을 처리합니다.

HomeController.java

src/main/java/com/example/demo/HomeController.java
package com.example.demo;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.ui.Model;

@Controller
public class HomeController {

    @GetMapping("/")
    public String home(Model model) {
        model.addAttribute("today", "2026년 10월 15일");
        return "home";
    }
}
💡 줄별 해설
줄의미
package com.example.demo;이 파일이 속한 패키지(클래스 묶음의 폴더 이름)를 선언합니다. Spring Boot는 이 패키지 아래의 클래스를 자동으로 찾습니다.
import ...;다른 패키지에 있는 클래스를 이 파일에서 사용하겠다고 선언합니다.
@Controller이 클래스가 HTTP 요청을 처리하는 컨트롤러임을 Spring에 알립니다. Spring이 프로그램 시작 시 이 클래스를 객체로 만들어 보관합니다.
@GetMapping("/")브라우저가 GET 방식으로 주소 / 를 요청하면 바로 아래 메서드를 호출하라는 표식입니다.
public String home(Model model)메서드 이름은 home, 반환 타입은 문자열(String)입니다. 매개변수 model 은 Spring이 호출할 때 자동으로 넣어 줍니다.
model.addAttribute("today", "...")템플릿에서 ${today} 로 꺼낼 수 있도록, 이름 "today" 에 값을 저장합니다. 이름과 값을 쌍으로 저장하는 구조를 맵(Map)이라고 합니다.
return "home";메서드를 끝내고 "home" 을 Spring에 돌려줍니다. Spring은 이 값을 받아 templates/home.html 템플릿을 실행합니다.

호출 위치와 반환 위치: 이 메서드는 Spring 내부의 DispatcherServlet이 호출합니다. 반환된 문자열은 같은 DispatcherServlet으로 돌아가 템플릿 처리 단계로 넘어갑니다.

2.2 템플릿 엔진 설정

원문은 템플릿 엔진을 직접 설정합니다. 핵심 구성 요소는 두 가지입니다.

구성 요소클래스역할
템플릿 리졸버(Template Resolver)WebApplicationTemplateResolver템플릿 이름 "home" 을 실제 파일 위치로 바꿉니다. setPrefix("/WEB-INF/templates/") 는 앞에 붙일 경로, setSuffix(".html") 은 뒤에 붙일 확장자를 정합니다.

3 Using Texts

이 장에서는 홈 화면에 환영 문구를 출력하는 방법을 배웁니다. 문구를 HTML 안에 직접 쓰지 않고 별도 파일로 분리하는 방식을 함께 익힙니다.

3.1 메시지(Message)와 th:text

메시지는 화면에 나오는 문구를 키(key)와 값(value) 쌍으로 저장한 것입니다. 키는 문구를 찾을 때 쓰는 이름이고, 값은 실제 화면에 나갈 문장입니다. 문구를 파일로 분리하면, 언어를 바꿀 때 HTML을 고치지 않고 파일만 바꾸면 됩니다. 이를 국제화(i18n, Internationalization)라고 합니다.

home.html

src/main/resources/templates/home.html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
  <head>
    <title>Good Thymes Virtual Grocery</title>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
  </head>
  <body>
    <p th:text="#{home.welcome}">Welcome to our grocery store!</p>
  </body>
</html>
💡 줄별 해설
줄의미
<!DOCTYPE html>이 파일이 HTML5 문서임을 브라우저에 알리는 선언입니다.
<html xmlns:th="http://www.thymeleaf.org">th: 접두어가 Thymeleaf의 속성임을 선언합니다. 편집기(IDE)가 경고를 표시하지 않게 하는 역할을 합니다. 처리 결과에는 영향이 없습니다.
<title>브라우저 탭에 표시되는 제목입니다.
<p th:text="#{home.welcome}">th:text 속성은 이 태그의 본문(시작 태그와 종료 태그 사이 글자)을 속성 값의 결과로 바꿉니다. #{home.welcome} 은 메시지 키 home.welcome 의 값을 가져오라는 표현식입니다.
본문 "Welcome to our grocery store!"템플릿 처리 후에는 사라집니다. 원본 파일을 브라우저로 직접 열었을 때만 보입니다. 이 글은 디자인 확인용 임시 글입니다.

메시지 파일은 .properties 확장자를 가진 텍스트 파일입니다. 한 줄에 키=값 형식으로 한 개의 메시지를 적습니다. 파일 이름의 끝부분은 언어 코드입니다.

파일 이름사용 조건

브라우저는 HTTP 요청 헤더 Accept-Language 에 선호 언어를 담아 보냅니다. Spring은 이 값을 Locale(지역·언어 정보 객체)로 바꾸고, Locale에 맞는 메시지 파일을 고릅니다. 맞는 파일이 없으면 messages.properties 를 사용합니다.

✅ 성공 확인

브라우저 설정에서 언어를 스페인어(es)로 바꾸고 페이지를 새로고침하면 스페인어 문장이 나옵니다. 설정을 한국어(ko)로 바꾸고 messages_ko.properties 를 만들면 한국어 문장이 나옵니다.

⚠️ 오류: 메시지 파일을 고쳤는데 글이 바뀌지 않음

메시지 파일은 서버가 시작될 때 읽어 메모리에 저장합니다. 파일을 고친 뒤 서버를 Ctrl + C 로 멈추고 다시 실행해야 바뀝니다.

3.2 이스케이프와 변수

이스케이프(Escape)란?

HTML에서 < 와 > 는 태그의 시작과 끝을 뜻합니다. 글자로 "<b>"를 보여 주고 싶다면 이 기호를 &lt;, &gt; 로 바꿔 적어야 합니다. 이렇게 특수 기호를 안전한 표기로 바꾸는 작업을 이스케이프라고 합니다.

메시지 값에 HTML 태그가 들어 있다고 가정합니다.

messages.properties
home.welcome=Welcome to our <b>fantastic</b> grocery store!
속성처리 방식브라우저 결과
th:text태그 기호를 이스케이프합니다. 기본 동작입니다.화면에 <b>fantastic</b> 이라는 글자가 그대로 보입니다.
th:utext이스케이프하지 않고 HTML로 출력합니다. (unescaped text)fantastic 이 굵은 글씨로 보입니다.
⚠️ 보안 주의: XSS(Cross-Site Scripting)

th:utext 에 사용자가 입력한 값(댓글, 검색어 등)을 넣으면, 입력자가 <script> 태그를 넣어 다른 사용자 브라우저에서 스크립트를 실행시킬 수 있습니다. 이를 XSS 공격이라고 합니다. 따라서 th:utext 는 개발자가 직접 작성한 고정 문구에만 사용합니다.

변수 표현식 ${...}

컨트롤러에서 model.addAttribute("today", "2026년 10월 15일") 로 저장한 값을 템플릿에서 꺼내려면 ${today} 를 씁니다. ${...} 안의 문법은 Spring 환경에서 SpEL(Spring Expression Language)로 해석됩니다. 원문은 OGNL(Object-Graph Navigation Language)이라는 표현식 언어를 설명하며, 두 언어의 기본 문법은 거의 같습니다.

home.html
<p th:utext="#{home.welcome}">Welcome to our grocery store!</p>
<p>Today is: <span th:text="${today}">13 February 2011</span></p>
💡 줄별 해설
부분의미
th:utext="#{home.welcome}"메시지의 값을 HTML 그대로 출력합니다. 메시지 값에 태그가 없으므로 th:text 와 결과가 같습니다.
<span th:text="${today}">변수 today 의 값을 이스케이프하여 span 태그 본문으로 출력합니다.
13 February 2011템플릿 처리 전 원본 파일에 보이는 임시 글입니다. 실제 처리 결과로는 사라집니다.
📖 변수 경로 표기

${user.name}: user 객체를 꺼낸 뒤, 그 객체의 getName() 메서드를 호출한 결과를 씁니다. 자바 빈(JavaBean) 규칙에서는 getXxx() 메서드가 속성 xxx 로 노출됩니다.

4 Standard Expression Syntax (표준 표현식 문법)

표현식(Expression)은 값을 계산하거나 꺼내는 코드 조각입니다. Thymeleaf 속성 값 안에 씁니다. 이 장에서는 Thymeleaf가 제공하는 표현식 종류를 모두 정리합니다.

표기이름결과
${...}변수 표현식Model에 저장된 값 또는 객체
*{...}선택 변수 표현식th:object 로 선택한 객체의 속성 값
#{...}메시지 표현식메시지 파일의 값
@{...}링크 주소 표현식URL 문자열
~{...}조각 표현식HTML 조각(fragment)

4.1 메시지 표현식 #{...}

메시지 값에 변동 값을 넣을 때는 {0}, {1} 같은 자리표시자를 씁니다. 번호는 0부터 시작합니다. 값의 형식은 java.text.MessageFormat 규칙을 따릅니다.

messages.properties
home.welcome=Welcome to our grocery store, {0}!
home.html
<p th:text="#{home.welcome(${userName})}">Welcome to our grocery store!</p>
💡 해석

#{home.welcome(${userName})}: 키 home.welcome 의 값에서 {0} 자리에 변수 userName 의 값을 넣습니다. 값이 여러 개면 쉼표로 구분합니다. 예: #{key(${a}, ${b})}.

메시지 키 자체도 변수로 만들 수 있습니다. 예: #{${welcomeMsgKey}}. 변수 값이 home.welcome 이면 위와 같은 메시지를 가져옵니다.

4.2 변수 표현식 ${...} 세부 문법

표현실행 의미
${person.father.name}person.getFather().getName() 과 같습니다.
${person['father']['name']}위와 같은 의미입니다. 대괄호 안에 속성 이름을 문자열로 씁니다.
${countriesByCode.ES}Map 객체에서 키가 ES 인 값을 꺼냅니다.
${personsArray[0].name}배열 또는 리스트의 첫 번째 요소(인덱스 0)의 name 을 꺼냅니다. 인덱스는 0부터 셉니다.
${person.createCompleteName()}매개변수가 없는 메서드를 호출한 결과입니다.
${person.createCompleteNameWithSeparator('-')}문자열 인자 '-' 를 넘겨 메서드를 호출합니다.

기본 객체 #

# 으로 시작하는 이름은 Thymeleaf가 미리 제공하는 객체입니다.

이름타입설명

유틸리티 객체 (Expression Utility Objects)

유틸리티 객체는 자주 쓰는 기능을 모아 둔 도구입니다. 함수처럼 호출합니다. 예: #strings.isEmpty(text).

객체처리 대상대표 메서드 예시

#datesjava.util.Dateformat(날짜, '패턴')

#numbers숫자formatDecimal(숫자, 자릿수, '콤마', 자릿수, '소수점')
#strings문자열isEmpty(s), contains(s, 찾을글자)
#lists리스트size(목록), isEmpty(목록)
#messages메시지msg('키') (표현식 안에서 메시지 가져오기)
날짜 형식 지정 (home.html)
<p>
  Today is: <span th:text="${#calendars.format(today,'dd MMMM yyyy')}">13 May 2011</span>
</p>
💡 패턴 문자 해설

4.3 선택 변수 표현식 *{...}

th:object="${...}" 로 객체를 하나 선택하면, 그 태그 안에서는 *{속성} 으로 짧게 씁니다. 이때 *{} 는 선택된 객체를 기준으로 계산합니다.

userprofile.html
<div th:object="${session.user}">
  <p>Name: <span th:text="*{firstName}">Sebastian</span>.</p>
  <p>Surname: <span th:text="*{lastName}">Pepper</span>.</p>
</div>
💡 줄별 해설
줄의미
th:object="${session.user}"세션(사용자 접속 상태 저장소)에 저장된 user 객체를 선택 대상으로 지정합니다.
*{firstName}선택된 객체의 getFirstName() 결과입니다. 즉 ${session.user.firstName} 과 같습니다.

선택 대상이 없으면 ${...} 과 *{...} 의 결과가 같습니다. 선택된 객체 자체는 ${#object} 로 참조할 수 있습니다.

4.4 링크 주소 표현식 @{...}

@{...} 는 URL 문자열을 만듭니다. 컨텍스트 경로(프로젝트 주소 앞부분)를 자동으로 붙이고, 쿼리 문자열과 경로 변수를 처리합니다.

URL 형식예시설명
절대 URL@{http://www.thymeleaf.org}그대로 씁니다.
컨텍스트 상대 URL@{/order/list}슬래시로 시작하면 프로젝트 이름이 자동으로 붙습니다.
쿼리 파라미터@{/order/details(orderId=${o.id})}결과: /order/details?orderId=3
경로 변수@{/order/{orderId}/details(orderId=${o.id})}결과: /order/3/details
서버 루트 상대 URL@{~/billing/processInvoice}같은 서버의 다른 애플리케이션 주소를 가리킬 때 씁니다.
home.html 메뉴
<ol>
  <li><a href="product/list.html" th:href="@{/product/list}">Product List</a></li>
  <li><a href="order/list.html" th:href="@{/order/list}">Order List</a></li>
</ol>
💡 줄별 해설
부분의미
href="product/list.html"정적 HTML로 열었을 때 사용하는 상대 경로입니다. 서버 처리 시에는 무시됩니다.
th:href="@{/product/list}"서버 처리 시 href 값을 /프로젝트이름/product/list 형태로 바꿉니다.
⚠️ 참고: 컨텍스트 경로

프로젝트를 Spring Boot로 실행하면 컨텍스트 경로는 기본적으로 / 입니다. 따라서 @{/order/list} 는 /order/list 가 됩니다. 원문 예시의 /gtvg/ 는 서블릿 WAR 배포에서 쓰는 프로젝트 이름입니다.

4.5 조각 표현식 ~{...}

HTML 조각을 가리키는 표현식입니다. 자세한 내용은 8장에서 다룹니다.

예시
<div th:insert="~{commons :: main}">...</div>
💡 해석

~{commons :: main}: commons.html 파일 안에서 th:fragment="main" 이 붙은 HTML 조각을 가리킵니다.

4.6 고정값 (Literals)

종류예시설명
문자열 리터럴'working web application'작은따옴표로 감쌉니다. 문자열 안에 작은따옴표를 쓰려면 \' 로 씁니다.
숫자 리터럴0, 34, 12.3따옴표 없이 씁니다.
불리언 리터럴true, false참과 거짓 값입니다.
null 리터럴null값이 없음을 뜻합니다. 자바의 null 과 같습니다.
토큰 리터럴content, main영문 대소문자, 숫자, 점(.), 하이픈(-), 밑줄(_), 대괄호만 쓰면 따옴표 없이 문자열로 취급됩니다.
예시
<div th:class="content">...</div>
<p>The year is <span th:text="2013">1492</span>.</p>
💡 해석

th:class="content" 는 th:class="'content'" 와 같은 결과입니다. 토큰 리터럴은 따옴표를 생략한 문자열 표기입니다.

4.7 문자열 연결 +

예시
<span th:text="'The name of the user is ' + ${user.name}">...</span>
💡 해석

+ 는 두 값을 이어 붙여 하나의 문자열을 만듭니다. 문자열과 변수를 섞을 때 씁니다.

4.8 리터럴 치환 |...|

세로선(|) 사이에서는 ${...} 를 바로 넣을 수 있습니다. 문자열 연결 + 를 줄여 줍니다.

예시
<span th:text="|Welcome to our application, ${user.name}!|">...</span>
⚠️ 제한

|...| 안에는 ${...}, *{...}, #{...} 만 넣을 수 있습니다. 작은따옴표 문자열이나 조건식은 넣을 수 없습니다.

4.9 사칙연산

+, -, *, /, %(나머지) 연산자를 씁니다. 글자 별명으로 div(나눗셈), mod(나머지)도 쓸 수 있습니다.

예시: 짝수 여부 확인
<div th:with="isEven=(${prodStat.count} % 2 == 0)">...</div>
💡 해석

${prodStat.count} % 2 는 count를 2로 나눈 나머지입니다. 나머지가 0이면 == 0 이 참이 되어 isEven 은 true 가 됩니다.

4.10 비교 연산자

기호글자 별명의미
>gt왼쪽이 크다
<lt왼쪽이 작다
>=ge왼쪽이 크거나 같다
<=le왼쪽이 작거나 같다
==eq같다
!=ne다르다
⚠️ 오류: 속성 안의 부등호 기호

XML 규칙상 속성 값 안에 < 를 쓰면 파싱 오류가 납니다. 이때 lt, gt 같은 글자 별명을 쓰거나 &lt;, &gt; 로 씁니다.

4.11 조건 연산자 A ? B : C

조건 A가 참이면 B, 거짓이면 C를 결과로 씁니다. 자바의 삼항 연산자와 같은 문법입니다.

예시
<tr th:class="${row.even}? 'even' : 'odd'">...</tr>
💡 해석

${row.even} 이 참이면 class="even", 거짓이면 class="odd" 가 됩니다. 콜론(:) 뒤 부분을 생략하면 거짓일 때 결과는 null 입니다.

4.12 기본값 연산자 ?:

왼쪽 값이 null 이 아니면 왼쪽 값을, null 이면 오른쪽 값을 씁니다.

예시
<span th:text="*{age}?: '(no age specified)'">27</span>
💡 해석

*{age} 값이 null 이면 글자 (no age specified) 를 출력합니다. 값이 있으면 그 값을 출력합니다. 아래 두 줄은 같은 결과입니다.

같은 뜻의 조건 연산자 표현
th:text="*{age != null}? *{age} : '(no age specified)'"

4.13 무처리 토큰 _

밑줄(_)은 "이 속성 처리를 하지 않는다"는 뜻입니다. 속성이 없는 것처럼 동작하여, 태그 안에 적힌 원본 글자가 그대로 남습니다.

예시
<span th:text="${user.name} ?: _">no user authenticated</span>
💡 해석

user.name 이 null 이면 th:text 처리를 하지 않으므로 원본 글자 no user authenticated 가 남습니다. 값이 있으면 그 값으로 바뀝니다.

4.14 변환 표현식 ${{...}}

두 겹 중괄호를 쓰면 등록된 변환 서비스(ConversionService)가 값을 문자열로 바꿉니다. 날짜 객체처럼 기본 문자열 표현이 보기 어려운 값에 쓰입니다.

예시
<td th:text="${{user.lastAccessDate}}">...</td>
⚠️ 참고

변환 서비스가 등록되어 있지 않으면 객체의 toString() 결과가 출력됩니다. Spring 환경에서는 Spring의 변환 서비스가 자동으로 연결됩니다.

4.15 전처리 __...__

밑줄 두 개(__)로 감싼 표현식은 먼저 한 번 평가된 뒤, 그 결과 문자열이 다시 표현식으로 실행됩니다. 메시지 값을 표현식 자리에 넣을 때 쓰는 고급 기능입니다.

예시
<p th:text="${__#{article.text('textVar')}__}">Some text here...</p>
⚠️ 보안 제한

전처리는 표현식을 실행하므로 보안 제한이 엄격합니다. 사용자 입력값을 전처리 대상에 넣으면 안 됩니다. 부록 21을 참고하세요.

🛠️ 미션 5

(1) 홈 화면에 "상품 목록"과 "주문 목록" 링크를 th:href="@{...}" 로 만듭니다. (2) 컨트롤러에서 model.addAttribute("now", java.time.LocalDate.now()) 로 값을 넣고, 화면에서 ${#temporals.format(now, 'yyyy-MM-dd')} 로 날짜를 출력합니다.

정답은 ②번입니다. @{...} 는 URL 문자열을 만듭니다.

5 Setting Attribute Values (속성 값 설정)

HTML 태그의 속성 값(href, src, value, class 등)을 서버 데이터로 바꾸는 방법을 배웁니다.

5.1 임의의 속성 설정 th:attr

subscribe.html
<form action="subscribe.html" th:attr="action=@{/subscribe}">
  <fieldset>
    <input type="text" name="email" />
    <input type="submit" value="Subscribe!" th:attr="value=#{subscribe.submit}"/>
  </fieldset>
</form>
💡 줄별 해설
부분의미
th:attr="action=@{/subscribe}"action 속성의 값을 @{/subscribe} 표현식의 결과로 바꿉니다.
th:attr="value=#{subscribe.submit}"value 속성 값을 메시지 키 subscribe.submit 의 값으로 바꿉니다.

여러 속성을 바꿀 때는 쉼표로 구분합니다. 예: th:attr="src=@{/images/logo.png},title=#{logo},alt=#{logo}". 같은 속성을 두 번 쓰면 HTML 규칙에 어긋나므로 쉼표 목록을 씁니다.

5.2 속성 전용 처리 속성 (th:value, th:href 등)

th:attr 은 문법이 복잡하므로, 실제로는 속성마다 전용 속성을 씁니다. 전용 속성 이름은 th: 뒤에 HTML 속성 이름을 붙인 형태입니다.

전용 속성 사용
<form action="subscribe.html" th:action="@{/subscribe}">
  <input type="submit" value="Subscribe!" th:value="#{subscribe.submit}"/>
</form>

전용 속성의 예: th:action, th:value, th:href, th:src, th:class, th:id, th:style. 원문은 HTML5 속성 전체에 대응하는 목록을 제공합니다.

5.3 두 속성 동시 설정 th:alt-title

th:alt-title 은 alt 와 title 두 속성에 같은 값을 한 번에 넣습니다.

예시
<img src="../../images/gtvglogo.png" th:src="@{/images/gtvglogo.png}" th:alt-title="#{logo}" />

5.4 값 추가 th:attrappend, th:classappend

th:attrappend 은 기존 속성 값 뒤에 문자열을 덧붙입니다. th:attrprepend 는 앞에 붙입니다. th:classappend 는 class 속성에 CSS 클래스 이름만 추가합니다.

예시
<tr th:each="prod : ${prods}" class="row" th:classappend="${prodStat.odd}? 'odd'">...</tr>
💡 줄별 해설

class="row" 는 원본 값입니다. ${prodStat.odd} 가 참이면 odd 가 뒤에 덧붙어 class="row odd" 가 됩니다. 거짓이면 null 이므로 아무것도 추가되지 않아 class="row" 로 남습니다.

5.5 불리언 속성 th:checked 등

HTML의 checked 처럼 이름만 있으면 참이 되는 속성을 불리언 속성이라고 합니다. Thymeleaf의 th:checked 는 조건이 참일 때만 이 속성을 붙입니다.

예시
<input type="checkbox" name="active" th:checked="${user.active}" />
💡 해석

user.active 가 true 이면 checked 속성이 붙고, false 이면 속성 자체가 생기지 않습니다.

5.6 전용 속성이 없는 경우 th:이름

Thymeleaf가 전용 처리를 정의하지 않은 속성이라도, th:속성이름 으로 쓰면 기본 처리기가 그 속성의 값을 설정합니다.

예시
<span th:whatever="${user.name}">...</span>
<!-- 처리 결과: <span whatever="John Apricot">...</span> -->

5.7 HTML5 표준 표기 data-th-...

th: 접두어는 HTML5 표준에서 허용하지 않는 형식입니다. data-th- 접두어를 쓰면 HTML5 규칙에 맞는 파일이 됩니다. 두 표기는 같은 기능입니다.

예시
<td data-th-text="${user.login}">...</td>
⚠️ 참고

이 자습서는 가독성을 위해 th: 표기를 사용합니다. 두 표기 중 하나만 골라 한 파일 안에서 일관되게 쓰세요.

🛠️ 미션 6

(1) 홈 화면의 로고 이미지 태그에 th:alt-title="#{logo}" 를 붙입니다. (2) messages.properties 에 logo=우리 쇼핑몰 로고 를 추가합니다. (3) 마우스를 이미지 위에 올렸을 때 툴팁이 나오는지 확인합니다.

정답은 ②번입니다. th:class 는 값을 덮어쓰고, th:classappend 는 뒤에 추가합니다.

6 Iteration (반복)

반복(Iteration)은 목록(리스트)의 요소 수만큼 같은 HTML 태그를 여러 번 출력하는 것입니다. 상품 3개를 출력할 때 <tr> 줄을 3번 쓰지 않고, 줄 하나를 만든 뒤 Thymeleaf가 반복하게 합니다.

6.1 반복의 기본 th:each

ProductController.java

src/main/java/com/example/demo/ProductController.java
package com.example.demo;

import java.util.List;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class ProductController {

    @GetMapping("/product/list")
    public String list(Model model) {
        List<String> prods = List.of("Fresh Sweet Basil", "Italian Tomato", "Yellow Bell Pepper");
        model.addAttribute("prods", prods);
        return "product/list";
    }
}
💡 줄별 해설
줄의미
import java.util.List;자바 표준 라이브러리의 List 인터페이스(순서가 있는 목록)를 사용합니다.
@GetMapping("/product/list")브라우저가 /product/list 를 요청하면 아래 메서드를 호출합니다.
List<String> prods = List.of(...)문자열 3개를 담은 불변(변경할 수 없는) 리스트를 만듭니다. 실습용 고정 데이터입니다. 실제 서비스에서는 데이터베이스에서 가져옵니다.
model.addAttribute("prods", prods)템플릿에서 ${prods} 로 꺼낼 수 있도록 이름 "prods" 로 저장합니다.
return "product/list";templates/product/list.html 파일을 처리하라는 뜻입니다. 슬래시(/)는 폴더 구분자입니다.

product/list.html

src/main/resources/templates/product/list.html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head><title>상품 목록</title><meta charset="UTF-8"></head>
<body>
  <h1>상품 목록</h1>
  <ul>
    <li th:each="prod : ${prods}" th:text="${prod}">양파</li>
  </ul>
</body>
</html>
💡 줄별 해설
부분의미
<meta charset="UTF-8">파일의 문자 인코딩을 UTF-8로 지정합니다. 한글이 깨지지 않게 하는 설정입니다.
th:each="prod : ${prods}"prods 의 요소를 하나씩 꺼내 변수 prod 에 넣고, 이 태그를 요소 수만큼 반복 출력합니다.
th:text="${prod}"현재 반복의 prod 값을 태그 본문으로 출력합니다.
양파처리 전 원본의 임시 글입니다. 처리 후에는 사라집니다.
✅ 성공 확인

http://localhost:8080/product/list 에서 목록 항목 3개가 보입니다.

반복 구문의 구성 요소

구성 요소예시이름
반복 대상${prods}이터레이트 변수(iterated variable)
반복 변수prod이터레이션 변수(iteration variable), 줄여서 iter 변수
반복 범위prod 는 태그와 그 하위 태그 안에서만 사용지역 범위(scope)

6.1.1 반복 가능한 대상

타입설명
Iterable 구현 객체리스트, 집합(Set) 등
Enumeration, Iterator과거 방식의 순회 객체
Map반복 변수가 Map.Entry(키와 값 쌍)입니다.
Stream, 배열스트림과 배열 요소를 순회합니다.
그 밖의 객체 1개요소가 1개인 목록으로 취급합니다.

6.2 반복 상태 변수 (Status Variable)

상태 변수는 반복 진행 정보를 담는 객체입니다. th:each="prod,iterStat : ${prods}" 처럼 쉼표 뒤에 이름을 적어 만듭니다. 이름을 생략하면 반복 변수 이름에 Stat 을 붙인 prodStat 이 자동 생성됩니다.

속성타입값
index정수0부터 시작하는 번호
count정수1부터 시작하는 번호
size정수전체 요소 수
current객체현재 반복의 요소(반복 변수와 같음)
even, odd불리언짝수 번째 또는 홀수 번째 여부. count 기준입니다.
first, last불리언첫 번째 또는 마지막 요소 여부
예시: 줄 번호와 홀수 줄 클래스
<tr th:each="prod,iterStat : ${prods}" th:class="${iterStat.odd}? 'odd'">
  <td th:text="${iterStat.count}">1</td>
  <td th:text="${prod.name}">Onions</td>
</tr>
💡 줄별 해설

${iterStat.odd} 가 참인 줄에만 class="odd" 가 붙습니다. iterStat.count 는 1, 2, 3 순으로 번호를 출력합니다.

6.3 지연 로딩 LazyContextVariable

지연 로딩(Lazy Loading)은 값이 실제로 사용되는 순간에만 데이터를 가져오는 방식입니다. 데이터베이스 조회는 비용이 크므로, 템플릿에서 사용하지 않는 조건이면 조회를 하지 않습니다.

자바 코드 예시 (개념 설명용)
context.setVariable("users", new LazyContextVariable<List<User>>() {
    @Override
    protected List<User> loadValue() {
        return databaseRepository.findAllUsers();   // 실제로 사용될 때만 호출됩니다
    }
});
💡 해석

loadValue() 메서드는 템플릿이 ${users} 를 실제로 평가할 때만 호출됩니다. 바깥의 th:if 조건이 거짓이면 loadValue() 는 실행되지 않습니다.

🛠️ 미션 7

상품 목록 화면을 표(table)로 바꾸고, 열 세 개(번호, 상품명, 재고)를 출력하세요. 번호는 iterStat.count 로 출력하고, 짝수 번째 줄에만 th:classappend 로 even 클래스를 붙입니다.

🧠 퀴즈 6. th:each="prod,iterStat : ${prods}" 에서 1부터 시작하는 번호를 얻는 속성은?

정답은 ②번 count 입니다. index 는 0부터 시작합니다.

7 Conditional Evaluation (조건부 출력)

조건에 따라 태그를 출력하거나 출력하지 않는 방법을 배웁니다. 이를 조건 분기(Conditional Branch)라고 합니다.

7.1 th:if, th:unless

예시: 댓글이 있을 때만 링크 출력
<a href="comments.html"
   th:href="@{/product/comments(prodId=${prod.id})}"
   th:if="${not #lists.isEmpty(prod.comments)}">view</a>
💡 줄별 해설
부분의미
th:if="..."괄호 안의 표현식 결과가 참일 때만 이 태그를 출력합니다. 거짓이면 태그 자체가 출력되지 않습니다.
not논리 부정입니다. 참을 거짓으로, 거짓을 참으로 바꿉니다. 기호 ! 와 같습니다.
#lists.isEmpty(prod.comments)comments 리스트가 비어 있으면 참을 반환하는 유틸리티 메서드입니다.
prodId=${prod.id}주소 뒤에 ?prodId=2 처럼 쿼리 문자열을 붙입니다.

th:unless 는 조건이 거짓일 때 출력합니다. 위 예시를 아래처럼 바꿔도 결과가 같습니다.

같은 결과를 내는 두 표현
th:if="${not #lists.isEmpty(prod.comments)}"
th:unless="${#lists.isEmpty(prod.comments)}"

참(true)으로 판단하는 기준

th:if 는 불리언이 아닌 값도 참과 거짓으로 판단합니다.

값의 종류판단 결과
null거짓
true참
0이 아닌 숫자참 (0이면 거짓)
문자열"false", "off", "no" 이면 거짓, 그 밖에는 참
그 밖의 객체참

7.2 여러 경우 분기 th:switch, th:case

자바의 switch 문과 같은 역할입니다. 값을 th:switch 에 지정하고, 각 th:case 와 비교합니다. 일치하는 첫 번째 case 만 출력합니다.

예시
<div th:switch="${user.role}">
  <p th:case="'admin'">User is an administrator</p>
  <p th:case="#{roles.manager}">User is a manager</p>
  <p th:case="*">User is some other thing</p>
</div>
💡 줄별 해설

th:case="'admin'" 은 값이 문자열 admin 과 같은지 비교합니다. th:case="*" 는 어떤 case에도 해당하지 않을 때 출력하는 기본(default) 경우입니다. 자바의 default: 와 같습니다.

🛠️ 미션 8

(1) 컨트롤러에서 model.addAttribute("isAdmin", true) 를 저장합니다. (2) 템플릿에 <p th:if="${isAdmin}">관리자 메뉴</p> 를 씁니다. (3) 값을 false 로 바꿔 글이 사라지는지 확인합니다.

🧠 퀴즈 7. th:unless="${list.isEmpty()}" 는 언제 태그를 출력할까요?

정답은 ②번입니다. isEmpty() 결과가 거짓일 때 unless 가 참이 되어 출력합니다.

8 Template Layout (조각과 레이아웃)

여러 페이지에 같은 HTML(머리말, 꼬리말, 메뉴)을 반복해서 쓰지 않도록, 공통 부분을 조각(Fragment)으로 한 번만 정의하고 여러 파일에서 가져다 씁니다.

8.1 조각 가져오기

조각 정의 th:fragment

src/main/resources/templates/footer.html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<body>
  <div th:fragment="copy">
    &copy; 2026 The Good Thymes Virtual Grocery
  </div>
</body>
</html>
💡 줄별 해설
부분의미
th:fragment="copy"이 div 를 copy 라는 이름의 조각으로 등록합니다. 파일 단독으로 열어도 화면에 보입니다.
&copy;저작권 기호 ©를 나타내는 HTML 문자 참조입니다.

조각 사용 th:insert

home.html 의 body 안
<div th:insert="~{footer :: copy}"></div>
💡 해석

~{footer :: copy} 는 "footer.html 파일에서 copy 조각을 가져오라"는 뜻입니다. :: 기호 앞은 파일 이름, 뒤는 조각 이름입니다.

조각 지정 형식

형식의미
~{footer :: copy}footer 파일의 copy 조각
~{footer}footer 파일 전체
~{::copy}현재 파일 안에서 copy 조각을 찾습니다.

조각 지정: HTML의 id 사용

th:fragment 가 없어도, HTML의 id 속성으로 조각을 지정할 수 있습니다. CSS 선택자의 #id 문법과 같습니다.

예시
<div th:insert="~{footer :: #copy-section}"></div>

th:insert 와 th:replace 의 차이

속성처리 결과
th:insert현재 태그는 유지하고, 그 안(본문)에 조각을 넣습니다.
th:replace현재 태그 자체를 조각으로 교체합니다.
같은 조각을 두 방식으로 사용
<div th:insert="~{footer :: copy}"></div>
<div th:replace="~{footer :: copy}"></div>
💡 처리 결과

첫째 줄은 <div> 가 남고 그 안에 <div> 조각이 들어갑니다. 둘째 줄은 <div> 태그가 사라지고 조각의 <div> 만 남습니다.

8.2 매개변수가 있는 조각

조각 정의와 사용
<!-- 정의: onevar, twovar 는 매개변수 이름 -->
<div th:fragment="frag (onevar,twovar)">
    <p th:text="${onevar} + ' - ' + ${twovar}">...</p>
</div>

<!-- 사용 1: 순서대로 값 전달 -->
<div th:replace="~{ ::frag (${value1},${value2}) }">...</div>

<!-- 사용 2: 이름=값 형식으로 전달 (순서 무관) -->
<div th:replace="~{ ::frag (twovar=${value2},onevar=${value1}) }">...</div>
💡 해석

매개변수는 조각 안에서 ${onevar} 처럼 변수로 사용됩니다. 호출하는 쪽이 값을 넘기고, 조각은 그 값으로 HTML을 만듭니다.

매개변수 없는 조각에 지역 변수 전달

예시
<div th:replace="~{::frag (onevar=${value1},twovar=${value2})}"></div>

조각이 원래 매개변수를 선언하지 않아도 이 형식으로 값을 넘길 수 있습니다. 이 값은 조각 처리 중에만 유효한 지역 변수입니다.

th:assert 검사

th:assert 는 조건식이 거짓이면 처리를 중단하고 오류를 냅니다. 필수 매개변수가 비어 있는지 확인할 때 씁니다.

예시
<header th:fragment="contentheader(title)" th:assert="${!#strings.isEmpty(title)}">...</header>
💡 해석

#strings.isEmpty(title) 이 참(비어 있음)이면 ! 로 부정되어 거짓이 되므로 오류가 발생합니다. 제목이 있어야 조각이 정상 처리됩니다.

8.3 HTML 태그를 매개변수로 전달하는 레이아웃

조각의 매개변수에는 글자뿐 아니라 HTML 태그 조각도 넘길 수 있습니다. 공통 머리말(head)에 페이지마다 다른 제목과 CSS 링크를 넣을 때 씁니다.

base.html (공통 머리말 조각)
<head th:fragment="common_header(title,links)">
  <title th:replace="${title}">The awesome application</title>
  <link rel="stylesheet" th:href="@{/css/awesomeapp.css}">
  <!--/* 페이지마다 다른 링크를 넣을 자리 */-->
  <th:block th:replace="${links}" />
</head>
main.html (호출하는 페이지)
<head th:replace="~{ base :: common_header(~{::title},~{::link}) }">
  <title>Awesome - Main</title>
  <link rel="stylesheet" th:href="@{/css/bootstrap.min.css}">
</head>
💡 줄별 해설
표현의미
~{::title}현재 파일(main.html)에 있는 title 태그를 가져와 title 매개변수에 넣습니다.
~{::link}현재 파일의 link 태그들을 가져와 links 매개변수에 넣습니다.
th:replace="${title}"매개변수 값으로 title 태그 자체를 교체합니다.

호출 위치와 반환 위치: main.html 의 th:replace 가 base.html 의 조각을 호출하고, 처리된 결과가 main.html 의 head 자리에 들어갑니다.

특수 표현 3가지

표현의미결과
~{}빈 조각매개변수 자리에 아무 HTML도 들어가지 않습니다.
_무처리 토큰조각 안의 원본 태그를 그대로 씁니다. 예: title 에 _ 를 넘기면 The awesome application 이 남습니다.
~{::title}현재 파일의 title 태그 참조호출하는 페이지의 제목이 들어갑니다.

조건부 조각 삽입

관리자일 때만 조각 삽입
<div th:insert="${user.isAdmin()} ? ~{common :: adminhead} : ~{}">...</div>
💡 해석

isAdmin() 이 참이면 common.html 의 adminhead 조각을 넣습니다. 거짓이면 빈 조각 ~{} 을 넣어 아무것도 넣지 않습니다.

8.4 태그 제거 th:remove

디자인 확인용으로 만든 샘플 행을 실제 처리 결과에서 지울 때 씁니다. 속성 값에 따라 제거 방식이 다릅니다.

값제거 대상
all태그와 그 안의 모든 자식 요소
body태그는 남기고 자식 요소만 제거
tag태그만 제거하고 자식 요소는 남김
all-but-first첫 번째 자식만 남기고 나머지 자식 제거
none아무것도 제거하지 않음
예시: 샘플 행 제거
<tr class="odd" th:remove="all">
  <td>Blue Lettuce</td>
</tr>
💡 줄별 해설

th:remove="all" 이 붙은 tr 과 그 안의 td 는 처리 결과 HTML에서 모두 사라집니다. 원본 파일을 브라우저로 열면 샘플 행이 보입니다.

예시: tbody 의 자식을 한 번에 정리
<tbody th:remove="all-but-first">
  <tr th:each="prod : ${prods}">...</tr>
  <tr>...샘플 행 1...</tr>
  <tr>...샘플 행 2...</tr>
</tbody>
💡 해석

all-but-first 는 첫 번째 자식(반복 행 tr)은 남기고, 뒤의 샘플 행 두 개를 제거합니다.

8.5 레이아웃 상속

틀이 되는 레이아웃 파일 하나를 만들고, 각 페이지가 이 파일을 호출해 자기 제목과 본문을 넘깁니다.

layoutFile.html (레이아웃 파일)
<!DOCTYPE html>
<html th:fragment="layout (title, content)" xmlns:th="http://www.thymeleaf.org">
<head>
  <title th:replace="${title}">Layout Title</title>
</head>
<body>
  <h1>Layout H1</h1>
  <div th:replace="${content}"><p>Layout content</p></div>
  <footer>Layout footer</footer>
</body>
</html>
page.html (각 페이지)
<!DOCTYPE html>
<html th:replace="~{layoutFile :: layout(~{::title}, ~{::section})}">
<head>
  <title>Page Title</title>
</head>
<body>
<section>
  <p>Page content</p>
</section>
</body>
</html>
💡 해석

page.html 의 html 태그가 layout 조각으로 교체됩니다. 레이아웃의 title 자리에는 page.html 의 title 태그가, content 자리에는 section 태그가 들어갑니다.

🛠️ 미션 9

templates/fragments/footer.html 에 copy 조각을 만듭니다. 홈 화면과 상품 목록 화면 두 곳에서 th:insert="~{fragments/footer :: copy}" 로 가져와 같은 꼬리말이 보이는지 확인하세요.

🧠 퀴즈 8-1. th:replace 와 th:insert 의 차이로 맞는 설명은?

정답은 ②번입니다. replace는 태그 자체를 바꾸고, insert는 태그 안쪽에 넣습니다.

🧠 퀴즈 8-2. 매개변수 자리에 아무 HTML도 넣지 않으려면 어떤 표현을 쓸까요?

정답은 ②번 빈 조각 ~{} 입니다. _ 는 원본 태그를 그대로 두는 무처리 토큰입니다.

9 Local Variables (지역 변수)

지역 변수(Local Variable)는 특정 태그와 그 하위 태그 안에서만 사용할 수 있는 변수입니다. th:with 로 만듭니다.

예시
<div th:with="firstPer=${persons[0]},secondPer=${persons[1]}">
  <p>The name of the first person is <span th:text="${firstPer.name}">Julius Caesar</span>.</p>
  <p>But the name of the second person is <span th:text="${secondPer.name}">Marcus Antonius</span>.</p>
</div>
💡 줄별 해설
부분의미
th:with="firstPer=${persons[0]}"변수 firstPer 에 리스트의 0번 요소를 저장합니다.
secondPer=${persons[1]}쉼표로 구분해 변수를 여러 개 선언합니다. 1번 요소를 저장합니다.
범위변수는 이 div 태그와 안쪽 태그에서만 사용할 수 있습니다. 바깥에서 쓰면 오류가 납니다.
home.html: 날짜 형식을 메시지에서 가져와 사용
<p th:with="df=#{date.format}">
  Today is: <span th:text="${#calendars.format(today,df)}">13 February 2011</span>
</p>
💡 해석

#{date.format} 메시지 값을 df 에 저장한 뒤, #calendars.format 의 두 번째 인자로 사용합니다. 언어가 바뀌면 메시지 파일의 날짜 형식도 함께 바뀝니다.

⚠️ 참고: 처리 순서

th:with 는 같은 태그의 th:text 보다 먼저 실행됩니다. 그래서 th:text 안에서 df 를 쓸 수 있습니다. 실행 순서는 10장에서 설명합니다.

🛠️ 미션 10

🧠 퀴즈 9. th:with 로 만든 변수를 사용할 수 있는 범위는?

정답은 ②번입니다. 지역 변수는 선언한 태그 범위 안에서만 유효합니다.

10 Attribute Precedence (속성 처리 순서)

한 태그에 th: 속성이 여러 개 있으면 처리 순서가 중요합니다. HTML에서 속성의 작성 순서는 의미가 없으므로, Thymeleaf는 우선순위(precedence) 표에 따라 처리합니다. 우선순위 숫자가 작은 속성이 먼저 실행됩니다.

예시: th:each 와 th:text 를 같은 태그에 사용
<li th:each="item : ${items}" th:text="${item.description}">Item description here...</li>
💡 해석

th:each(우선순위 2)가 th:text(우선순위 7)보다 먼저 실행됩니다. 그래서 각 반복마다 item 이 정의된 뒤 글자를 출력할 수 있습니다.

우선순위기능속성
1조각 삽입th:insert, th:replace
2반복th:each
3조건th:if, th:unless, th:switch, th:case
4지역 변수 정의th:object, th:with
5일반 속성 설정th:attr, th:attrprepend, th:attrappend
6전용 속성 설정th:value, th:href, th:src 등
7본문 글자 설정th:text, th:utext
8조각 이름 정의th:fragment
9태그 제거th:remove
속성 위치를 바꾼 예시 (결과 동일)
<li th:text="${item.description}" th:each="item : ${items}">Item description here...</li>
✅ 핵심 정리

속성을 적는 순서는 결과에 영향을 주지 않습니다. 실행 순서는 위 표로만 결정됩니다. 원인을 찾기 어려운 오류가 나면 이 표를 먼저 확인하세요.

🛠️ 미션 11

한 태그에 th:if 와 th:each 를 같이 쓰고, 두 속성의 순서를 바꿔 결과가 같은지 확인하세요. 우선순위 표에 따라 어떤 속성이 먼저 실행되는지 메모하세요.

🧠 퀴즈 10. 같은 태그에 th:text 와 th:each 가 있으면 먼저 실행되는 속성은?

정답은 ②번입니다. 우선순위 2번인 th:each 가 우선순위 7번인 th:text 보다 먼저 실행됩니다.

11 Comments and Blocks (주석과 블록)

11.1 일반 HTML 주석

<!-- ... --> 는 HTML 주석입니다. 브라우저 화면에 보이지 않습니다. Thymeleaf는 주석 안의 th: 속성도 처리합니다. 따라서 처리 결과 HTML에도 주석 자체는 남습니다.

예시
<!-- User info follows -->
<div th:text="${...}">...</div>

11.2 파서 단계 주석 <!--/* ... */-->

이 형식은 Thymeleaf가 HTML을 읽는 파싱 단계에서 완전히 제거합니다. 처리 결과 HTML에도 남지 않습니다. 원본 파일을 브라우저로 열었을 때만 보이는 샘플 코드를 넣을 때 씁니다.

예시
<table>
  <tr th:each="x : ${xs}">...</tr>
  <!--/*-->
  <tr>...샘플 행...</tr>
  <!--*/-->
</table>
💡 줄별 해설

<!--/* 와 */--> 사이의 내용은 Thymeleaf 처리 단계에서 삭제됩니다. 브라우저는 HTML 주석 <!-- --> 로 인식하므로 원본 화면에서도 보이지 않습니다. 주석 안의 샘플 행은 어디에서도 보이지 않습니다. 샘플 행을 보려면 앞의 <!--/*--> 와 <!--*/--> 를 제거해야 합니다.

11.3 시안 전용 주석 <!--/*/ ... /*/-->

이 형식은 반대입니다. 브라우저에서는 주석이지만, Thymeleaf는 안쪽 내용을 실제 코드로 처리합니다.

예시
<span>hello!</span>
<!--/*/
  <div th:text="${...}">...</div>
/*/-->
<span>goodbye!</span>
💡 해석

Thymeleaf는 <!--/*/ 와 /*/--> 표시만 제거합니다. 안쪽 <div> 는 일반 HTML 태그가 되어 처리 대상이 됩니다. 브라우저 원본 화면에서는 <div> 가 주석 안에 있으므로 보이지 않습니다.

11.4 가상 태그 th:block

th:block 은 실제 HTML 출력에 남지 않는 Thymeleaf 전용 태그입니다. 속성 처리만 하고 자신은 결과에 나타나지 않습니다. 반복 한 번에 여러 줄을 출력해야 할 때 씁니다.

예시: 사용자 한 명당 두 줄 출력
<table>
  <th:block th:each="user : ${users}">
    <tr>
      <td th:text="${user.login}">...</td>
      <td th:text="${user.name}">...</td>
    </tr>
    <tr>
      <td colspan="2" th:text="${user.address}">...</td>
    </tr>
  </th:block>
</table>
💡 줄별 해설

th:each 가 th:block 에 붙어 있으므로, 사용자 수만큼 th:block 안의 두 tr 이 함께 반복됩니다. th:block 태그 자체는 결과에 나타나지 않습니다.

✅ 핵심 정리

table 안에 div 를 넣으면 HTML 규칙 위반입니다. th:block 은 결과에 남지 않으므로 table 안에서도 규칙을 지킬 수 있습니다.

🛠️ 미션 12

상품 목록 화면에서 th:block th:each="prod : ${prods}" 를 사용해 상품 한 개당 "상품명" 행과 "가격" 행, 두 줄을 출력하세요. 처리 후 HTML 소스 보기(Ctrl+U)에서 th:block 태그가 남아 있지 않은지 확인하세요.

🧠 퀴즈 11. th:block 에 대한 설명으로 맞는 것은?

정답은 ②번입니다. th:block 은 여러 태그를 묶는 용도이며, 결과 HTML에는 나타나지 않습니다.

12 Inlining (인라인 표현)

인라인(Inlining)은 태그 속성 대신 본문 글자 안에 바로 표현식을 적는 방식입니다. 표현식 표기는 [[...]] 와 [(...)] 두 가지입니다.

12.1 표현식 인라인

두 가지 표기 비교
<p>Hello, <span th:text="${session.user.name}">Sebastian</span>!</p>
<p>Hello, [[${session.user.name}]]!</p>
표기같은 기능의 속성처리 방식
[[...]]th:text결과 문자열의 특수 기호를 이스케이프합니다.
[(...)]th:utext이스케이프하지 않고 HTML로 출력합니다.
💡 이스케이프 예시

변수 msg 의 값이 This is <b>great!</b> 라고 가정합니다.

표기처리 결과 HTML브라우저 화면
[(${msg})]This is <b>great!</b>This is great! (굵게 표시)
[[${msg}]]This is &lt;b&gt;great!&lt;/b&gt;This is <b>great!</b> (태그 글자 그대로)
⚠️ 주의: 원본 화면에서 표현식이 그대로 보임

인라인 표기는 원본 HTML 파일을 브라우저로 직접 열면 [[${session.user.name}]] 글자가 그대로 보입니다. 디자인 확인용으로 쓰는 파일에는 th:text 를 쓰는 편이 낫습니다.

인라인 처리 끄기
<p th:inline="none">A double array looks like this: [[1, 2, 3], [4, 5]]!</p>
💡 해석

th:inline="none" 이 붙은 태그 안에서는 [[ ]] 를 표현식으로 처리하지 않고 글자로 출력합니다.

12.2 텍스트 인라인 th:inline="text"

th:inline="text" 가 붙은 태그의 본문은 TEXT 템플릿 모드로 처리됩니다. 표현식 출력뿐 아니라 반복과 조건 문법(13장)도 쓸 수 있습니다.

⚠️ 참고

Thymeleaf 3.x에서는 HTML 모드에서도 [[ ]] 가 기본으로 동작하므로, 대부분의 경우 th:inline="text" 를 따로 쓸 필요가 없습니다.

12.3 자바스크립트 인라인 th:inline="javascript"

자바스크립트 코드 안에 서버 값을 넣을 때 씁니다. 문자열은 자바스크립트 문법에 맞게 따옴표와 특수 문자가 자동으로 처리됩니다.

home.html
<script th:inline="javascript">
    var username = [[${session.user.name}]];
    console.log("접속한 사용자: " + username);
</script>
💡 줄별 해설
줄처리 결과
var username = [[${session.user.name}]];이름이 Sebastian 이면 var username = "Sebastian"; 이 됩니다. 문자열은 큰따옴표로 감싸집니다.
이름에 큰따옴표가 있는 경우예: Sebastian "Fruity" Applejuice 는 "Sebastian \"Fruity\" Applejuice" 로 이스케이프되어 자바스크립트 오류가 나지 않습니다.
console.log(...)브라우저 개발자 도구의 Console 탭에 메시지를 출력하는 자바스크립트 명령입니다.
🛠️ 미션 13

(1) 홈 화면 본문에 [[${today}]] 를 넣어 날짜가 출력되는지 확인합니다. (2) th:inline="javascript" 스크립트에서 같은 값을 console.log 로 출력하고, 개발자 도구(F12)의 Console 탭에서 확인하세요.

🧠 퀴즈 12. [[${name}]] 와 [(${name})] 의 차이는?

정답은 ②번입니다. 보안상 기본적으로 [[ ]] 를 사용합니다.

13 Textual template modes (텍스트 템플릿 모드)

13.1 텍스트 모드의 문법

TEXT, JAVASCRIPT, CSS 모드는 HTML 태그를 해석하지 않습니다. 대신 Thymeleaf 전용 대괄호 문법을 씁니다. 대괄호 문법은 [# 로 시작하는 처리 태그와 [[ ]] 표현식으로 구성됩니다.

TEXT 모드 예시 (이메일 본문)
[# th:each="item : ${items}"]
  - [# th:utext="${item}" /]
[/]
💡 줄별 해설
줄의미
[# th:each="item : ${items}"]반복 구간의 시작입니다. HTML의 <tr th:each=...> 와 같은 역할을 합니다.
- [# th:utext="${item}" /]각 항목 값을 출력합니다. 끝의 /] 는 태그를 닫는 표기이며, 처리 태그에 본문이 없을 때 씁니다.
[/]반복 구간의 끝입니다. 시작 처리 태그를 닫습니다.
⚠️ 주의

TEXT 모드에서는 < 기호가 태그로 해석되지 않습니다. HTML이 들어 있어도 글자로 취급되므로, 웹 페이지 본문에는 HTML 모드를 쓰세요.

13.2 자바스크립트 자연 템플릿

자바스크립트 파일 안에서 주석 형식으로 값을 넣습니다. 파일을 브라우저로 직접 열면 주석 뒤의 기본값이 보이고, Thymeleaf가 처리하면 서버 값으로 바뀝니다.

static/js/app.js (또는 templates 안의 .js)
var username = /*[[${session.user.name}]]*/ 'Sebastian';
💡 줄별 해설
부분의미
/*[[${...}]]*/자바스크립트 주석 안에 표현식이 있습니다. 브라우저는 주석으로 무시하고, Thymeleaf는 표현식으로 처리합니다.
'Sebastian'처리 전 기본값입니다. Thymeleaf 처리 후에는 표현식 결과로 대체됩니다.
🛠️ 미션 14

src/main/resources/templates/js/app.js 파일을 만듭니다. 파일 안에 위 자연 템플릿 문법 한 줄을 씁니다. 이 파일을 메모장으로 열었을 때 기본값 'Sebastian' 이 보이는지 확인하세요. 그다음 서버에서 이 파일을 처리하는 방법은 원문 13장 하단에서 확인하세요.

16 Template Cache (템플릿 캐시)

캐시(Cache)는 이미 처리한 결과를 메모리에 보관해 같은 요청을 빠르게 처리하는 방법입니다. 템플릿을 매번 파일에서 읽지 않으므로 운영 환경 속도가 빨라집니다.

💡 개발 중 문제

캐시가 켜져 있으면 HTML 파일을 수정해도 서버가 예전 결과를 계속 보냅니다. 개발 중에는 캐시를 끄는 설정을 씁니다.

src/main/resources/application.properties
spring.thymeleaf.cache=false
💡 줄별 해설

spring.thymeleaf.cache 는 Thymeleaf 캐시 사용 여부를 정하는 설정 키입니다. false 이면 요청마다 파일을 다시 읽습니다.

✅ 성공 확인

설정 후 서버를 다시 실행합니다. HTML 글자를 고치고 브라우저를 새로고침하면 바로 바뀝니다.

🛠️ 미션 17

(1) spring.thymeleaf.cache=false 를 설정하고 서버를 재시작합니다. (2) 홈 화면 글자를 바꾸고 새로고침하여 반영되는지 확인합니다. (3) 확인 후 설정을 지우거나 true 로 바꿉니다.

17 Decoupled Template Logic (분리된 템플릿 로직)

⚠️ 요약 안내

이 장도 원문 본문을 대조하지 않고 요약했습니다. 개념을 이해하는 수준으로만 읽고, 실제 적용 전에 원문에서 설정 방법을 확인하세요.

보통은 HTML 파일 안에 th:* 속성을 직접 씁니다. 분리된 템플릿 로직(Decoupled Template Logic)은 이 처리 명령을 HTML 파일 밖의 별도 파일에 적는 방식입니다. HTML에는 처리 명령이 없으므로 디자이너가 순수 HTML만 다룰 수 있습니다.

방식처리 명령의 위치
결합된 로직(Coupled)HTML 태그의 th:* 속성
분리된 로직(Decoupled)별도 로직 파일, HTML에서는 th:ref 속성으로 연결
💡 입문자 권장

처음에는 지금까지 배운 th:* 방식만 쓰면 충분합니다. 분리 방식은 원문의 성능 영향 항목을 읽은 뒤 필요할 때 도입하세요.
