컴퓨터 RAM은 데이터를 잠깐 저장하는 부품. 
    내부에는 수 많은 칸(셀)으로 나뉨. 칸 하나엔 2진수만 저장. 
    칸 하나의 가장 작은 단위 비트(bit)
    비트 8개 = 바이트 (byte) = 한 칸의 기본 크기
    각 칸엔 주소(ex. 0x006, 주소는 16진수)가 붙어있다.
        비트 > 바이트 > KB > MB > GB > TB (1024배씩 커짐)

연산자
    값을 계산하거나 비교할 때 쓰는 기호
    계산하기 (더하기/빼기), 비교하기 (크다/같다), 판단묶기(그리고/또는)
        - 연산자 좌/우에 오는 값들을 피연산자 라고 한다.
    
    산술: 계산 (숫자)
    비교: 두 값 비교 (참/거짓)
    논리: 여러 조건 묶기 (참/거짓)
    삼항: 조건으로 둘 중 선택

    복합 연산자
        +=
        -=
        *=
        /=
        %=
            예) hp += 10 은 hp = hp + 10
                hp -= 20 은 hp = hp - 20
                gold *= 2 는 gold = gold * 2
    
    비교 연산자
        > 크다
        < 작다
        >= 크거나 같다
        === 같다
        !== 다르다
    
    논리 연산자
        && 그리고 (and) 둘 다 참 이어야 참
        || 또는 (or) 하나만 참이어도 참
        ! 아님 (not) 참 <> 거짓 뒤집기
    
    삼항 연산자
        조건 ? 참일 때 출력할 값 : 거짓일 때 출력할 값

함수
    실행할 코드들을 하나의 이름으로 선언해 두고, 필요할 때 그 이름으로 호출해서 실행하는 문법

    함수를 만드는 방법 3가지

        함수 선언문 (function) 으로 함수를 만들경우, 
            호출문을 먼저 적고 함수를 작성해도 오류가 생기지 않는다. (호이스팅 가능)

            function 함수명 ( 매개변수1, 매개변수2 ) {
                실행할 코드;
                return 반환값;
            }

            함수명 ( 인수1, 인수2 ); <- 함수 호출 구문


        함수 표현식 (const) 으로 함수를 만들경우, 
            호출문을 먼저 적고 함수를 작성하면 오류가 생긴다

            const 상수명 = fuction ( 매개변수1, 매개변수2 ) {
                실행할 코드;
                return 반환값;
            }

            const 상수명 = function 함수명 ( 매개변수1, 매개변수2 ) {
                실행할 코드;
                return 반환값;
            };
            
            상수명( 인수1, 인수2 ); <- 함수 호출 구문

        
        화살표 => 함수 정의 및 매개변수 처리

            const 상수명 = ( 매개변수1, 매개변수2 ) => {
                실행할 코드;
                return 반환값;
            };

            const 상수명 = ( 매개변수1, 매개변수2 ) => 반환값;
                * 화살표 함수에서 반환값이 한줄일 경우 return과 중괄호 {}를 생략 가능
            
            상수명( 인수1, 인수2 ); <- 함수 호출 구문
        
                * 함수 표현식으로 함수를 정의할때는 const키워드를 주로 사용한다.
                var, let키워드를 사용해도 문제없지만, const키워드로 정의하는 것이 좋습니다.
                보통 함수는 일관된 목적을 가진 코드 집합이라서 재정의 해서도, 재할당해서도 안되는 경우가 많기 때문이다.
    
    IIFE (즉시 실행 함수)
        함수들은 프로그램이 실행되면 변수명 등을 프로그램 실행이 끝나기 전 까지 차지한다.
        하지만 한번만 쓸 함수들이 변수명을 차지해 버리면 다음에 그 변수명을 사용 할 수 없게 된다.
            이것을 스코프 오염이라고 한다.

        전역 스코프 오염을 방지하기 위해 딱 한번만 쓸 코드들을 블록 스코프로 묶는데, 블록을 빠져나오면 변수명등은 리셋이 된다(변수의 유효 범위를 제한, 전역 공간을 보호). (블록으로 묶는 행위를 거친 객체를 함수라고 부른다.)
        함수를 괄호()로 감싸고 뒤에 소괄호()를 붙여서 만들면 이름 없이 그 자리에서 바로 실행되고 끝난다.
            ( function() => {
                실행할 코드;
            } )();
        
        ES6+ (최신 자바스크립트 버전)
            블록스코프 (let, const)
                함수를 만들지 않고, 그냥 중괄호 {} 블록만 만들어도 변수가 오염되는 것을 방지
            모듈 (Module) 시스템
                요즘은 파일 단위 (import / export)로 코드를 나누어 개발, 파일 내에 선언한 변수가 자동으로 격리 => 전역 공간을 오염시키지 않는다.

배열
    배열이름 = [];

    배열이름.push("값");
        마지막에 값 추가
    배열이름.pop();
        마지막 값 삭제
    배열이름.unshift("값");
        제일 앞에 값 추가
    배열이름.shift();
        제일 앞 값 삭제
    
    배열이름.length
        배열의 크기 (값이 몇개 있는지) 구함
    
    배열.map(n => 계산식);
        ex) 배열.map(n => n * 2);
            map(콜백) (콜백은 화살표 함수 (n => ...))
                모든 값을 변환 → 새 배열 (개수 같음)
                원본 배열은 그대로 두고 '새 배열'을 돌려줌

    배열.filter(n => 조건식);
        ex) 배열.filter(n => n > 2);
            filter(콜백) (콜백은 화살표 함수 (n => ...))
                조건에 맞는 값만 선별 → 새 배열 (개수 줄 수 있음)
                원본 배열은 그대로 두고 '새 배열'을 돌려줌
