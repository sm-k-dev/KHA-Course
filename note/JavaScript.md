컴퓨터 RAM은 데이터를 잠깐 저장하는 부품. 
    내부에는 수 많은 칸(셀)으로 나뉨. 칸 하나엔 2진수만 저장. 
    칸 하나의 가장 작은 단위 비트(bit)
    비트 8개 = 바이트 (byte) = 한 칸의 기본 크기
    각 칸엔 주소(ex. 0x006, 주소는 16진수)가 붙어있다.
        비트 > 바이트 > KB > MB > GB > TB (1024배씩 커짐)

변수 메모리 (Variable)
    - 하나의 데이터를 저장할 메모리 공간
    예) let 변수명;
        | undefined |

        변수명      = 데이터;
        | 데이터 |

        변수명      = 데이터2;
        | 데이터2 |

    - 결론: 하나의 데이터만 저장할 하나의 메모리 공간

객체 메모리 (Object)
    - 하나의 메모리 공간에 여러 개의 속성명(Key)과 값(Value), 메소드(Method)와 식을 짝(Pair)으로 묶어서 저장하는 큰 메모리 공간

    - { name: "홍길동", age: 20 }; <--- 하나의 객체 메모리(Object) 공간이때 객체 내부에 저장된 속성명과 값의 쌍을 프로퍼티(Property)라고 부르며, 
        값이 함수인 경우를 메소드(Method)라고 부른다.

    - 객체 메모리는 각 칸에 저장된 데이터에 접근하거나, 데이터를 불러오거나, 값을 변경하기 위해 번호(index) 대신 속성명(Key)을 식별자로 사용한다.
        {  name: "홍길동",  age: 20  }; <- 하나의 객체 메모리 전체 공간
            name             age       <- 속성명 (Key, 데이터에 접근하는 기준)

    - 객체 메모리의 각 데이터(값)는 속성명을 사용하여 접근하며, 배열과 마찬가지로 어떤 데이터 유형(문자열, 숫자, 배열, 다른 객체, 함수 등)이든 자유롭게 추가, 변경, 삭제할 수 있다.

    - 자바스크립트 객체 메모리는 동적 구조를 가지므로, 객체가 생성된 이후에도 새로운 속성을 언제든지 동적으로 추가하거나 제거할 수 있어 크기가 자동으로 조절된다.

    - 자바스크립트 객체는 데이터를 다루기 위한 다양한 내장 메소드와 속성을 연동하여 사용할 수 있다.
    
배열 객체 메모리 (Array)
    - 하나의 메모리에 칸을 나누어서 하나 이상의 데이터를 저장할 전체 메모리공간
    - [1,  2,  3,  4];  <--- 하나의 배열 메모리(Array) 공간

    이때  각 칸에 저장된 1  또는 2 또는 3또는 4 등의 데이터를 요소라고 부른다

    - 배열 메모리는 각 칸의 데이터에 접근하거나  저장된 데이터를 불러오거나
        각 칸에 저장된 값을 변경하기 위해  각 칸  위치에 번호가 0 부터 ~ 1씩 증가하면서
        붙게 되는데.. 이번호를 index라고 부릅니다.
        [ 1,  2,  3,  4 ]; <- 하나의 배열 메모리 전체 공간
          0   1   2   3    <- index

    - 배열 메모리의 각 칸에 저장된 데이터(요소)는 index를 사용하여 각요소에 접근하며
        배열 메모리에 어떤 데이터유형(문자열, 숫자, 객체, 다른배열)이든 추가 저장, 삭제할 수 있습니다.

    - 자바스크립트 배열메모리는 동적배열로 , 크기가 (칸의 갯수가)자동으로 조절됨

    - 자바스크립트 배열메모리(Array)다양한 내장메소드(함수)와 속성(변수)등을 제공함
        예)  length 속성,  push()메소드, shift()메소드, unshift()메소드 등.......

연산자
    값을 계산하거나 비교할 때 쓰는 기호
    계산하기 (더하기/빼기), 비교하기 (크다/같다), 판단묶기(그리고/또는)
        - 연산자 좌/우에 오는 값들을 피연산자 라고 한다.
    
    산술: 계산 (숫자)
    비교: 두 값 비교 (참/거짓)
    논리: 여러 조건 묶기 (참/거짓)
    삼항: 조건으로 둘 중 선택

    복합 연산자
        +=
        -=
        *=
        /=
        %=
            예) hp += 10 은 hp = hp + 10
                hp -= 20 은 hp = hp - 20
                gold *= 2 는 gold = gold * 2
    
    비교 연산자
        > 크다
        < 작다
        >= 크거나 같다
        === 같다
        !== 다르다
    
    논리 연산자
        && 그리고 (and) 둘 다 참 이어야 참
        || 또는 (or) 하나만 참이어도 참
        ! 아님 (not) 참 <> 거짓 뒤집기
    
    삼항 연산자
        조건 ? 참일 때 출력할 값 : 거짓일 때 출력할 값

함수
    실행할 코드들을 하나의 이름으로 선언해 두고, 필요할 때 호출해서 실행하는 재사용 가능한 코드 블록입니다.
        매개변수 (Parameter): 함수를 정의할 때 외부에서 받을 값을 담는 변수 (예: 매개변수1)
        인수 (Argument): 함수를 호출할 때 함수에 실제로 전달하는 값 (예: 인수1)

    함수를 만드는 방법 3가지

        함수 선언문 (function declaration) 으로 함수를 만들경우, 
            함수 호이스팅이 발생, 코드 작성 순서상 호출문이 선언문보다 위에 있어도 정상 작동

            function 함수명 ( 매개변수1, 매개변수2 ) {
                실행할 코드;
                return 반환값;
            }

            함수명 ( 인수1, 인수2 ); <- 함수 호출 구문

        -------------------------------------------------------------------------------------------------------------------------------------------------------
    
        함수 표현식 (function expression) 으로 함수를 만들경우, 
            변수에 함수를 할당하는 방식.
            변수 호이스팅 규칙을 따르므로 선언 전 호출 시 에러가 발생.
            안전성을 위해 const를 주로 사용

            익명 함수 / 무명 함수
                const 상수명 = function ( 매개변수1, 매개변수2 ) {
                    실행할 코드;
                    return 반환값;
                };

            기명 함수
                const 상수명 = function 함수명 ( 매개변수1, 매개변수2 ) {
                    실행할 코드;
                    return 반환값;
                };
            
            상수명( 인수1, 인수2 ); <- 함수 호출 구문

        -------------------------------------------------------------------------------------------------------------------------------------------------------
            
        화살표 함수 (arrow function, =>)
            익명 함수를 축약한 형태.
            매개변수가 1개면 ( ) 소괄호는 생략 가능하다.
            본문이 한줄이면 return과 { } 중괄호 생략 가능하다.
                화살표 함수에서 { } 를 생략하면 화살표 다음에 오는 코드는 return문으로 처리된다
            치명적 제한: 문법만 짧아진 것이 아니라 this 바인딩이 다르게 작동, argument 객체를 사용할 수 없다.

            const 상수명 = 매개변수 => {
                실행할 코드;
                return 반환값;
            };

            const 상수명 = ( 매개변수1, 매개변수2 ) => {
                실행할 코드;
                return 반환값;
            };

            const 상수명 = 매개변수 => 반환값;

            const 상수명 = ( 매개변수1, 매개변수2 ) => 반환값;
            
            상수명( 인수1, 인수2 ); <- 함수 호출 구문
        
                * 함수 표현식으로 함수를 정의할때는 const키워드를 주로 사용한다.
                var, let키워드를 사용해도 문제없지만, const키워드로 정의하는 것이 좋습니다.
                보통 함수는 일관된 목적을 가진 코드 집합이라서 재정의 해서도, 재할당해서도 안되는 경우가 많기 때문이다.

    함수의 반환과 종료
        return; 
            반환값 없이 함수를 그 즉시 강제 종료 시키고 싶을 때 사용 (조기 리턴 패턴에 자주 사용)
        return 반환값;
            함수를 호출한 자리로 결과값을 돌려주고 함수를 즉시 종료
        반환값이 없는 함수
            return문이 아예 없거나 값 없이 return;만 적힌 함수를 호출하면, 
            자바스크립트는 내적으로 undefined를 반환한 것으로 처리

    변수 키워드와 호이스팅 (Scope & Hoisting) - 함수 호이스팅, 변수/상수 호이스팅
        함수의 동작을 완벽히 이해하려면 변수의 호이스팅 매커니즘을 먼저 알아야 한다.

        호이스팅(Hoisting)
            코드가 실행되기 전, 자바스크립트 엔진이 선언문들을 최상단으로 끌어올려 먼저 해석하는 현상
        
        함수 선언문 호이스팅
            선언과 동시에 함수 내용 전체가 메모리에 등록된다.
            선언문 위에서 호출해도 정상 실행된다.
        
        var (함수 스코프)
            블록 { } 을 무시한다.
            선언문 위에서 호출해도 에러가 나지 않고 undefined로 초기화 되어 출력 (남용 금지)
        
        let / const (블록 스코프)
            블록 { } 내부에 갇힌다.
            let, const도 사실 호이스팅은 일어난다. 
            다만, 초기화되기 전까지 접근할 수 없는 TDZ (Temporal Dead Zone, 일시적 사각지대)에 빠지기 때문에 브라우저가 '호이스팅이 안 되어서 에러가 난 것'처럼 작동하게 만든다.
            결과적으로 선언 전 호출 시 에러가 나므로 '선언 후 사용' 규칙을 강제

    전역 스코프 오염 방지 기술
        하나의 웹페이지에서 모든 코드가 변수명을 공유하면 이름이 겹쳐 충돌하는 스코프 오염이 발생
        
        IIFE (즉시 실행 함수)
            그 자리에서 실행되고 메모리에서 사리지는 이름 없는 함수

            함수들은 프로그램이 실행되면 변수명 등을 프로그램 실행이 끝나기 전 까지 차지한다.
            하지만 한번만 쓸 함수들이 변수명을 차지해 버리면 다음에 그 변수명을 사용 할 수 없게 된다.
                이것을 스코프 오염이라고 한다.

            전역 스코프 오염을 방지하기 위해 딱 한번만 쓸 코드들을 블록 스코프로 묶는데, 블록을 빠져나오면 변수명등은 리셋이 된다 (변수의 유효 범위를 제한, 전역 공간을 보호). 
                (블록으로 묶는 행위를 거친 객체를 함수라고 부른다.)
                함수를 괄호()로 감싸고 뒤에 소괄호()를 붙여서 만들면 이름 없이 그 자리에서 바로 실행되고 끝난다.
                    // 일반 익명 함수 IIFE
                    ( function() {
                        실행할 코드;
                    } )();

                    // 화살표 함수 IIFE 
                    (() => {
                        실행할 코드;
                    })();
                
                기명함수로 IIFE를 만들었을때
                    작성시 이미 한번 실행 했기때문에 식별자로 (함수명) 다시 호출하면 오류가 발생한다.
        
            ES6+ (최신 자바스크립트 버전)
                블록스코프 (let, const)
                    함수를 만들지 않고, 그냥 중괄호 {} 블록만 만들어도 변수가 오염되는 것을 방지

            모듈 (Module) 시스템
                요즘은 파일 단위 (import / export)로 코드를 나누어 개발, 파일 내에 선언한 변수가 자동으로 격리 => 전역 공간을 오염시키지 않는다.

객체
    여러 개의 값을 하나의 참조값으로 관리하는 참조형 데이터.
    객체 안에는 속성(Property)과 메소드(Method)를 작성할 수 있다.

    객체? 현실에 존재하는 자신만의 값 + 기능 을 가진 모든 사물이나 사람 등을 객체라고 한다.
    객체 모델링? 현실에 존재하는 객체의 값과 기능을 추출해서 설계하는 작업.

    객체 (Object) - 여러 값을 하나의 구조로 묶어서 관리하는 참조형 데이터
    속성 (Property) - 객체 안에 저장된 데이터
    메소드 (Method) - 객체 안에 속성값으로 저장된 함수 
        객체 내부의 함수 = 메소드
        객체 외부의 함수 = 함수
    Key - 속성 이름
    value - 속성에 저장된 값
    참조값 (Reference) - 객체가 생성된 메모리 위치를 가리키는 값

    객체의 종류
        - 사용자 정의 객체
            정의: 
                개발자가 특정 목적에 맞게 속성과 메소드를 직접 정의하여 생성한 객체
            핵심 역할: 
                현실 세계의 사물이나 프로그램에 필요한 복잡한 데이터를 구조화하고 코드를 재사용하게 합니다
            대표적인 예시:
                let user = { name: "홍길동", age: 25 }; // 개발자가 직접 만든 회원 객체

        - 자바스크립트 문법에서 이미 만들어 놓고 개발자에게 제공하는 객체
            - 내장 객체
                정의: 
                    자바스크립트 엔진에 기본적으로 탑재되어 있어 환경에 상관없이 언제나 사용할 수 있는 객체
                핵심 역할: 
                    날짜 계산, 수학 연산, 문자열 처리 등 프로그래밍에서 빈번하게 쓰이는 기본 기능을 제공합니다
                대표적인 객체:
                    Date: 날짜와 시간을 다루는 객체
                    Math: 수학적인 계산과 상수를 제공하는 객체
                    Array: 여러 데이터를 순서대로 저장하고 다루는 배열 객체

            - 브라우저 객체 모델 (BOM: Browser Object Model)
                정의: 
                    웹 브라우저의 기능들을 자바스크립트에서 제어할 수 있도록 묶어놓은 객체 모델
                핵심 역할: 
                    브라우저 창을 제어하거나, 사용자의 화면 정보를 얻고, 페이지를 이동시키는 등 브라우저 자체를 제어합니다
                대표적인 객체:
                    window: BOM의 최상위 객체이며 브라우저 창 전체를 제어함 (DOM의 document도 window의 자식임)
                    location: 현재 웹 페이지의 URL 주소 정보를 가지고 있거나 페이지를 이동시킴
                    navigator: 현재 사용자가 쓰고 있는 브라우저의 종류나 버전 정보를 제공함
            
            - 문서 객체 모델 (DOM: Document Object Model)
                정의: 
                    웹 브라우저가 HTML 웹 페이지를 인식하고 제어할 수 있도록 트리 구조의 객체로 변환한 모델
                핵심 역할: 
                    자바스크립트를 이용해 HTML의 텍스트, 스타일, 속성, 구조를 동적으로 추가, 수정, 삭제할 수 있게 합니다
                대표적인 객체:
                    document: DOM 트리의 최상위 객체이며, 웹 페이지의 모든 HTML 요소에 접근하는 관문 역할을 합니다.

    객체 생성 방법
        1.  생성자 함수 (Constructor) 방식
            let 객체참조변수명 = new Object();
                new Object();로 생성된 객체 메모리의 주소가 객체참조변수명 메모리에 저장된다.
                
                new 뒤에오는 함수를 기반으로 객체를 새로 생성하겠다는 예약어
                Object() 자바스크립트가 기본 제공하는 빌트인 객체(오브젝트) 생성 함수

                객체 안에 속성과 메소드를 정의 하는 방법
                    객체참조변수명.속성명 = 값;
                    객체참조변수명.메소드명 = function 함수명(){ 실행코드; };

        2.  리터럴(Literal) 방식
            let 객체참조변수명 = {
                                속성명: 값,
                                메소드명: function () { 실행할 코드; };
                            };
                - 중괄호 `{}`를 사용하여 객체를 직접 생성하는 가장 직관적이고 흔하게 쓰이는 방식
                - 내부에 작성하는 함수(메소드)는 이름을 생략한 '익명 함수' 형태로 주로 작성
    
    객체 호출 방법
        1. 점 표기법으로 속성 이나 메소드 사용
            객체참조변수명.속성명; <- 값을 얻을 수 있다.
            객체참조변수명.속성명 = 새값; <- 객체에 저장된 기존 값을 새 값으로 변경 할 수 있다.
            객체참조변수명.새속성명 = 값; <- 객체 메모리 { } 내부에 새속성명: 값; 한쌍을 추가할 수 있다.
            객체참조변수명.메소드명(); <- 객체 안의 메소드를 호출
            delete 객체참조변수명.속성명; <- 객체에 저장된 속성을 삭제

        2. 대괄호 표기법으로 속성 이나 메소드 사용
            대괄호 표기법 사용 이유 - 하이픈을 포함하는 속성명 or 메소드명이 있다면 [] 표기법으로만 사용 할 수 있다.

            객체참조변수명["속성명"]; <- 속성명에 관한 값을 얻어 올 수 있다. 속성명은 반드시 ""로 감싸야 한다. 객체 {} 내부에 "속성명: 값" 중에서 "값"을 가져오는 문법
            객체참조변수명["속성명"] = 새값 <- 객체 {} 내부에 "속성명: 값" 중에서 "값"을 변경하는 문법
            객체참조변수명["새속성명"] = 값; <- 객체 메모리 { } 내부에 새속성명: 값; 한 쌍을 추가할 수 있다.
            delete 객체참조변수명["속성명"]; <- 객체에 저장된 속성을 삭제

            메소드는 대괄호 표기법으로 사용 할 수 없다.

    객체 중첩하기
        { } 객체 안에 "속성명: 값" 에서 "값" 자리에 { }개체를 포함 시킬 수 있다.

            객체명 {
                속성명1: 값1,
                속성명2: {
                    속성명3: 값3,
                    속성명4: 값4,
                    메소드명: function() { 코드; }
                }
            };
        
        사용할때
            객체명.속성명2.속성명3
            객체명.속성명2.메소드명();
    
        this 이해하기
            this는 해당 객체가 저장된 참조값(주소번지)을 가리키는 포인터. 
                - 객체 메모리의 주소 번지를 기억
            this는 메소드(함수)가 실행될 때, 그 메소드를 호출한 객체를 가리키는 키워드이다. (런타임 바인딩) 
                - 함수가 선언될 때가 아니라 실제 누가(객체) 호출했느냐에 따라 this가 동적으로 결정
                - 객체 내부의 메소드(함수)에서 객체의 속성에 접근할 때 사용한다.
                - 호출자 중심: this는 언제나 "지금 나를 부른 녀석(객체)"
                - 소속 확인: 객체의 품 안에서 그 객체의 일을 할 때, "(객체의)내 것"을 가리키기 위해 쓴다.
                ※ [꿀팁] 코드에 점(.)이 없으면? this는 무조건 세상에서 가장 큰 객체인 window를 가리킨다!
        
        객체 대입과 참조 주의
            - 객체의 메모리 주소번지를 다른 참조변수에 대입하여 저장하면, 
                결과적으로 두 변수가 같은 객체 메모리에 접근하게 됩니다.
            - 이 때문에 어느 한 참조변수로 속성값을 변경하면, 
                또 다른 참조변수로 객체 메모리에 접근하더라도 이미 변경된 값을 똑같이 공유하여 사용하게 됩니다.

            원시 타입 (Primitive Type): 
                - 값을 독립적으로 복사합니다. 
                - 한쪽을 수정해도 다른 쪽에 영향이 없습니다.
                - 함수 매개변수로 값을 넘길 때도 원시 타입은 값이 넘어간다. 
                    동작: 값이 복사되어 전달됩니다.
                    특징: 함수 내부에서 변수 값을 바꿔도, 함수 바깥의 원본 변수는 그대로 100입니다.

            참조 타입 (Reference Type): 
                - 주소(열쇠)를 복사합니다. 
                - 한쪽을 수정하면 다른 쪽도 동시에 바뀝니다.
                - 얕은 복사 (Shallow Copy)정의: 
                    겉 껍데기(1단계)만 복사하고, 내부 객체는 주소를 그대로 공유합니다.
                    현상: 복사본의 내부 객체를 바꾸면 원본도 같이 바뀝니다.
                    방법: Object.assign() 또는 스프레드 연산자 {...bag}
                - 깊은 복사 (Deep Copy)정의: 
                    내부에 있는 중첩 객체까지 전부 독립된 새 창고로 완전히 복사합니다.
                    현상: 복사본을 아무리 수정해도 원본에 아무 영향이 없습니다.
                    방법: JSON.parse(JSON.stringify(obj)) 또는 lodash 라이브러리
                - 함수 매개변수로 값을 넘길 때도 참조 타입은 주소가 넘어갑니다.
                    동작: 주소(열쇠)가 복사되어 전달됩니다.
                    특징: 함수 내부에서 객체의 속성을 바꾸면, 함수 바깥의 원본 객체도 같이 바뀝니다.

    생성자 함수 (Constructor Function)
        생성자 함수란?
            정의: 
                동일한 속성과 구조를 가진 객체를 여러 개 효율적으로 생성하기 위한 특수한 함수입니다.
            특징: 
                일반 함수와 달리 new 연산자(키워드)와 함께 호출하여 사용합니다.
            
            생성자 함수 자체는 평범한 함수(코드 덩어리)일 뿐이지만, 
                = 붕어빵 틀 (자바에선 클래스(class))
            new 키워드가 붙은 함수가 실행되는 순간 생성자 함수가 호출되어 메모리에 새로운 객체(Object)가 만들어져 반환된다. 
                = 붕어빵 (자바에선 인스턴스(instance))

        기본 문법 및 구조
            일반 함수와 달리 반환문(return)을 명시하지 않습니다.
            함수 내부에서 this 키워드를 사용하여 생성될 객체의 속성과 메서드를 정의합니다.

            생성자 함수 정의
                function 생성자함수명(매개변수1, 매개변수2) {
                    // 속성(Property) 정의
                    this.속성명1 = 매개변수1;
                    this.속성명2 = 매개변수2;

                    // 메서드(Method) 정의
                    this.메소드명 = function() {
                        // 실행할 코드
                    };
                }
            
            생성자 함수 호출 (객체 생성)
                let 객체참조변수명 = new 생성자함수명(인수1, 인수2);
                    new 생성자함수명(인수1, 인수2);가 실행되는 순간 생성자함수가 호출된다.
            
            대문자 출발: 
                일반 함수와 구분하기 위해 생성자 함수의 이름은 보통 대문자로 시작하는 것이 관례입니다. (파스칼 케이스, PascalCase)

            new의 역할: 
                new 키워드를 빼고 호출하면 일반 함수로 동작하여 this가 전역 객체를 가리키므로 반드시 붙여야 합니다.
                new 키워드를 사용하지 않으면 this가 객체가 아닌 전역 객체(window 또는 undefined)를 가리키게 되어 심각한 오류가 발생하므로, 반드시 new를 붙여야 합니다.
            
            class와의 차이점
                메서드를 만들 때 객체가 생성될 때마다 메모리에 메서드 함수가 매번 새로 만들어집니다. (메모리 비효율이 생길 수 있어 보통 프로토타입을 연계해 사용)

    클래스 (Class)
        Class란?
            정의:
                객체 메모리를 생성하는 규칙을 더 명확한 형태로 작성하는 설계도입니다.
            특징:
                일반 생성자 함수와 달리 함수 내부가 아닌 class 블록 안에 constructor(생성자 함수)를 내장하여 객체의 구조를 정의합니다.
            비유:
                클래스 자체는 객체를 찍어내기 위한 붕어빵 틀입니다. (자바의 클래스 개념과 동일)
                new 키워드를 붙여서 호출하는 순간 메모리에 새로운 붕어빵(인스턴스/객체)이 만들어져 반환됩니다.
            문법적 설탕 (Syntactic Sugar): 
                기존의 프로토타입(Prototype) 기반 객체 생성 방식을 보기 좋고 쓰기 편하게 만든 표준 문법입니다
        
        기본 문법 및 구조
            생성자 함수와 마찬가지로 반환문(return)을 명시하지 않습니다.
            클래스 내부의 constructor 안에서 this 키워드를 사용하여 생성될 객체의 속성을 정의합니다.
            메서드(함수)를 정의할 때는 function 키워드를 생략하고 클래스 블록 안에 바로 작성합니다.

            클래스 정의
                class 클래스명 {
                    // 생성자 함수 (속성 정의)
                    constructor(매개변수1, 매개변수2) {
                        this.속성명1 = 매개변수1;
                        this.속성명2 = 매개변수2;
                    }
                    
                    // 메서드(Method) 정의 - function 키워드 생략
                    메소드명() {
                        // 실행할 코드
                    }
                }
            
            클래스 객체 생성
                let 객체참조변수 = new 클래스명(인수1, 인수2);
                    new 클래스명(인수1, 인수2); 가 실행되는 순간 생성자 함수가 호출된다.
            
            대문자 출발:
                생성자 함수와 마찬가지로, 일반 함수/변수와 구분하기 위해 클래스의 이름은 보통 대문자로 시작하는 것이 관례입니다. (파스칼 케이스, PascalCase)

            new의 역할:
                클래스는 new 키워드 없이 호출하면 문법 에러(TypeError)가 발생하도록 자바스크립트 엔진 자체에서 안전장치가 되어 있습니다. 반드시 new를 붙여서 호출해야 합니다.

            호이스팅 불가 (순서 주의):
                함수는 선언하기 전에도 호출할 수 있지만(호이스팅), 클래스는 반드시 코드 위에서 먼저 정의되어 있어야만 아래에서 new로 호출할 수 있습니다.
            
            생성자 함수와의 차이점:
                메서드가 자동으로 프로토타입(Prototype)에 등록되어, 모든 객체가 하나의 메서드를 공유하므로 메모리가 더 효율적입니다.

        String 객체
            - 특정 문자열을 저장해 놓고, 문자열에서 특정 부분의 문자열을 잘라낸다던지
                특정 문자열을 변경한다던지 등의 문자열을 관리하는 메소드를 가지고 있는 객체
            - 컴퓨터 RAM의 특정 영역에 String 객체 메모리를 생성하면서 문자열 자체를 저장
                그리고 그 특정 영역의 주소번지가 변수명 메모리에 저장
            - String 객체 메모리 영역안에서 각 문자는 각각 위치번호 index를 가진다
                (공백도 위치 번호 index를 갖는다.)
            
            String 객체 메모리 생성 방법 2가지
                방법1. "" 또는 '' 기호로 감싸서 "문자열" 형태로 작성하는 문법
                
                방법2. new 키워드를 이용해서 String 이라는 생성자를 사용해서
                    new String('저장할 특정 문자열'); 형태로 작성하는 방법
            
            String 객체 메모리를 생성하면 제공하는 메소드 및 속성 종류
                1. charAt(index) 메소드
                    - 전체 저장된 문자열에서 특정 문자의 index 번호 위치에 해당하는 문자를 반환 하는 메소드

                2. indexOf("찾을 문자열") 메소드
                    - 전체 문자열에서 왼쪽부터 오른쪽 방향으로 "찾을 문자"와 일치하는 문자열을 찾아
                        제일 먼저 일치하는 문자열의 첫번째 문자 index 위치 번호를 반환 하는 메소드
                        만약 찾을 문자열이 없으면 -1을 반환한다.

                3. lastIndexOf("찾을 문자열") 메소드
                    - 전체 문자열에서 오른쪽(뒤쪽)에서 부터 왼쪽(앞쪽) 방향으로 찾을 문자열을 찾아
                        제일 먼저 일치하는 문자열의 첫번째 문자 index위치 번호를 반환하는 메소드
                        만약 찾을 문자가 없으면 -1을 반환
                
                4. match("찾을 문자열") 메소드
                    - 전체 문자열에서 왼쪽에서 오른쪽 방향으로 찾을 문자열과 일치하는 문자열을 찾아
                        제일 먼저 일치하는 문자열을 찾으면, 찾은 문자열 자체를 반환하는 메소드
                        만약 찾을 문자열이 전체문자열에서 포함되어 있지 않으면 null을 반환
                
                5. replace("원본 문자열", "새 문자열") 메소드
                    - 전체 문자열에서 특정 "원본 문자열" 부분만 "새 문자열"로 변경해서 반환하는 메소드
                        왼쪽에서 오른쪽 방향으로 "원본 문자열"을 찾아 변경한 뒤, String 객체 메모리 주소 자체를 반환
                
                6. search("찾을 문자열") 메소드
                    - 전체 문자열에서 왼쪽에서 오른쪽 방향으로 "찾을 문자열"과 일치하는 문자열을 찾아
                        제일 먼저 일치하는 문자열의 시작 문자의 index 위치를 반환
                
                7. slice(a, b) 메소드
                    - 전체 문자열에서 왼쪽부터 a개의 문자를 잘라내고, b 번째 문자 이후의 문자를 자른 후 남은 문자열을 반환하는 메소드
                    - a 남기고 싶은 문자열의 첫번째 문자 인덱스, b 남기고 싶은 문자열의 마지막 문자 인덱스
                
                8. substring(a, b) 메소드
                    - 전체 문자열에서 a index 위치의 문자부터 b index 위치 직전 index 구간의 문자까지의 특정 문자열을 잘라서 반환 하는 기능의 메소드
                    - slice(a, b) 메소드와 기능이 비슷하지만 중요한 차이점이 있음
                        차이점 1. 음수값이 들어가면 자동으로 0 으로 변환됨 (slice 메소드와 다른 점)
                        차이점 2. a, b 값 중 더 작은 값이 문자열을 자를 시작 위치, 큰 값이 끝 위치로 자동으로 변경 (적는 순서 상관 없음)

                    * 참고. 왼쪽에서 오른쪽 방향으로 찾을 경우 0 1 2 3 4 5 순서이지만
                    오른쪽에서 왼쪽으로 찾을경우 -5 -4 -3 -2 -1 순서이다.
                
                9. substr(a, 길이) 메소드
                    - 전체 문자열에서 특정 범위 (a 부터 지정한 길이 만큼의 문자열)를 추출해서 반환하는 기능의 메소드
                    - 첫번째 매개변수 a는 문자열에서 자르기를 시작할 index 위치 번호
                    - 두번째 매개변수 b는 자를 문자열의 길이 (몇 글자를 가져올건지) 넣기
                    - 원본 전체 문자열은 변경되지 않고 잘라온다.
                
                10. split("자를 기준 토큰 문자") 메소드
                    - 전체 문자열에서 인수로 전달한 '자를 기준 토큰 문자'를 기준으로 각 문자열을 나누고
                        새로운 배열을 생성해서 나눈 각 문자열을 저장한다.
                        생성된 새로운 배열 주소 자체를 반환하는 기능의 메소드
                
                11. toLowerCase() 메소드
                    - 전체 문자열에서 영문 대문자들을 모두 소문자로 변경한 후
                        변경된 전체 문자열을 반환 하는 기능의 메소드
                
                12. toUpperCase() 메소드
                    - 전체 문자열에서 영문 소문자들을 모두 대문자로 변경한 후
                        변경된 전체 문자열을 반환 하는 기능의 메소드
                
                13. length 속성
                    - 전체 문자열에 포함된 문자들의 총 개수 하나를 반환하는 속성
                    
                14. concat("연결할 새 문자열") 메소드
                    - 전체 문자열에 "연결할 새 문자열"을 결합해서 하나의 전체 문자열을 반환하는 기능의 메소드
                        "전체문자열".concat("연결할 새 문자열");
                            => "전체문자열연결할 새 문자열" 
                
                문자의 아스키 코드 (ASCII Code) 값이란?
                    - 컴퓨터가 문자(알파벳, 숫자, 기호 등)를 숫자로 표현하는 표준 체계
                        즉, 각 문자마다 고유한 숫자(아스키 코드 값)가 지정되어 있으며,
                        컴퓨터는 이 숫자를 이용해 문자를 저장하고 처리한다.
                        참고. 아스키코드표.png 파일 참고
                
                15. charCodeAt( index ) 메소드
                    - 전체 문자열에서 매개변수로 전달한 index 위치 문자의 아스키코드값 (10 진수 값)을 반환하는 메소드
                
                16. fromCharCode(아스키코드값) 메소드
                    - 아스키코드값에 해당하는 문자를 반환
                
                17. trim() 메소드
                    - 전체 문자열의 앞 뒤 공백 문자열을 제거한 후 제거한 전체 문자열 반환
                        단 전체 문자열에서 중간 공백이 있더라도 제거하지 않는다.
                
                18. include() 메소드
                    - 메소드의 매개변수로 전달되는 특정문자열이
                    전체 문자열에 포함되어 있느냐?라고 물어보는 메소드
                    만약 포함되어 있으면 true반환하고, 미포함되어 있으면 false를 반환

배열 객체 메모리 (Array)
    - 하나의 메모리에 칸을 나누어서 하나 이상의 데이터를 저장할 전체 메모리공간
    - [1,  2,  3,  4];  <--- 하나의 배열 메모리(Array) 공간

    이때  각 칸에 저장된 1  또는 2 또는 3또는 4 등의 데이터를 요소라고 부른다

    - 배열 메모리는 각 칸의 데이터에 접근하거나  저장된 데이터를 불러오거나
        각 칸에 저장된 값을 변경하기 위해  각 칸  위치에 번호가 0 부터 ~ 1씩 증가하면서
        붙게 되는데.. 이번호를 index라고 부릅니다.
        [ 1,  2,  3,  4 ]; <- 하나의 배열 메모리 전체 공간
          0   1   2   3    <- index

    - 배열 메모리의 각 칸에 저장된 데이터(요소)는 index를 사용하여 각요소에 접근하며
        배열 메모리에 어떤 데이터유형(문자열, 숫자, 객체, 다른배열)이든 추가 저장, 삭제할 수 있습니다.

    - 자바스크립트 배열메모리는 동적배열로 , 크기가 (칸의 갯수가)자동으로 조절됨

    - 자바스크립트 배열메모리(Array)다양한 내장메소드(함수)와 속성(변수)등을 제공함
        예)  length 속성,  push()메소드, shift()메소드, unshift()메소드 등.......
    
    ----------------------------------------------------------------------------------

    배열 메모리 생성 방법 2가지

        방법1.  리터털 표기법  [  ] 대괄호 이용
            let  배열_메모리의_주소번지가 저장될 참조변수 = ["저장할값1", 저장할값2, 저장할값3];
                    | 0x16 |                               0          1         2      index

                    예)   let colors = ["Red", "Green",  "Blue"];
                                         0        1        2      index

        방법2.  Array 생성함수(생성자)를 이용
            let  배열_메모리의_주소번지가 저장될 참조변수 = new Array("저장할값1", "저장할값2");
                    | 0x17 |                                        0           1       index

                예)   let colors  = new Array("Red", "Green","Blue");
                                                0      1       2     index

            단점 : 과도한 new키워를 사용해야 하므로, 코드가 다소 장황해 질수 있습니다. 혼동 가능성 있음
                예) 만약 하나의 숫자인자를 전달하면, 해당 숫자를 길이로 가지는
                    비어있는 칸의 배열이 생성됩니다.
                    예를 들어 new Array(3) 은 길이가 3인 비어 있는 배열을 생성하게됨

    배열 생성 방법 요약

        1. 리터럴 표기법 [] 은 배열을 더 쉽고 빠르게 만들수 있는 방법.
            코드가 간결하고 가독성이 띄어납니다. <- 현업에서 사용
        
        2. Array 생성자는 보다 명시적인 배열생성방법이지만,
            사용시 주의가 필요하며 코드가 다소 복잡해 질수 있습니다.

        결론 : 일반적으로 리터럴 표기법 [] 으로 배열 메모리를 생성해서 사용하는 것을 더 권장합니다.

    ----------------------------------------------------------------------------------

    생성된 배열 메모리의 각 index 위치 번호의 칸에 저장된 요소(값, 데이터)을 불러와 사용하는 방법

        방법. 배열_메모리의_주소가 저장된 변수명[index];

            예.  let colors = ["Red", "Green", "Blue"];
                        0        1       2    index

                colors[0];  //"Red"

                colors[1];  //"Green"

                colors[3];  // 이경우는 생성한 배열 메모리에 존재하지 안는
                            // 배열의 index위치에 접근하므로 배열을 참조하는 범위 벗어남
    
    변수 - 하나의 값을 저장할 한칸의 메모리 공간 - 단독주택 메모리
    배열 - 하나의 이상의 값을 저장할 메모리 공간 - 한동 짜리 빌라 메모리

    배열에 저장된 원본 데이터를 변경하는 메소드들을 파괴적 메소드들이라 부른다

        배열객체에서 제공하는 push()메소드
            - 배열메모리의 가장뒤에 새로운 데이터를 추가시킬때 사용하는 메소드
            - 배열.push(새 데이터);

        배열객체에서 제공하는 pop()메소드
            - 배열메모리의 가장뒤에 저장된 데이터만 추출(가져옴, 잘라냄)하는 메소드
            - 배열.pop();

        배열객체에서 제공하는 unshift()메소드
            - 배열메모리의 가장앞에 새로운 데이터를 동적으로 추가 시켜 한칸을 늘리는 기능의 메소드
            - 배열.unshift(새 데이터);

        배열객체에서 제공하는 shift()메소드
            - 배열메모리의 가장앞에 저장된 데이터만 추출(가져옴, 잘라냄)하는 메소드
            - 배열.shift();

    배열 객체 메모리가 제공하는 forEach()메소드
        - 배열 메모리에 저장된 전체 요소의 갯수만큼 반복하는데
            배열 메모리에 저장된 요소(데이터)를 하나씩 순회하면서 요소마다 콜백함수function을 호출하여 사용하는 메소드

            * 콜백 함수(Callback Function)는 다른 함수의 인자(매개변수)로 전달되어 특정 시점에 내부에서 호출되는 함수
                자바스크립트는 함수를 일반 값처럼 다룰 수 있는 일급 객체(First-Class Object)의 특징을 가집니다. 
                그렇기 때문에 함수를 변수에 담거나, 다른 함수의 파라미터로 넘겨주는 구조가 가능합니다

                주요 사용 목적
                    비동기 처리 구현: 
                        MDN Web Docs에 명시된 것처럼, 서버에서 데이터를 받아오거나 타이머가 작동하는 등 작업이 끝날 때까지 기다리지 않고 다음 코드를 실행해야 할 때 사용합니다.
                    코드의 재사용성과 유연성: 
                        동일한 메인 함수를 실행하더라도 어떤 콜백 함수를 넘겨주느야에 따라 내부 동작을 다르게 바꿀 수 있습니다.
                    이벤트 기반 처리: 
                        사용자가 버튼을 클릭하는 등의 특정 '이벤트'가 발생했을 때만 실행되도록 동작을 예약할 수 있습니다.
                    
                    예) 비동기 타이머 (setTimeout)
                            일정 시간이 지난 후에 콜백 함수를 호출하도록 예약하는 대표적인 비동기 함수입니다.
                                setTimeout(function() {
                                    console.log("3초가 지나 콜백 함수가 실행되었습니다.");
                                }, 3000);

                        배열 메서드 (forEach, map)
                            배열의 각 요소를 순회하면서 지정한 콜백 함수를 반복 실행합니다.
                                const numbers = [1, 2, 3];

                                numbers.forEach(function(num) {
                                    console.log(num * 2); // 2, 4, 6 순차 출력
                                });

    문법
        const 배열명 = [ 데이터1, 데이터2, 데이터3 ];

        배열.forEach( function( 현재 처리중인 배열 요소를 받을 매개변수(필수),
                                    현재 처리중인 요소의 index를 받을 매개변수,
                                    foreach 메소드를 호출한 배열 메모리 주소 자체를 받을 매개변수 )
            {
                반복 실행할 코드 작성 할 영역
            }, this/this.속성명 );
        
        배열.forEach( ( 요소, 인덱스, 원본배열자체 ) => { 
            반복시 구현할 코드 작성; 
        } );

        this 자리에는 function 내부에서 사용할 객체나 배열을 넣거나
        this.속성명 처럼 콜백함수 function 내부에서 this로 사용할 값 (선택)


    간단한 문법
        배열.forEach( function( 요소 ){ 반복시 구현할 코드 작성 }, this.속성명 );

        배열.forEach( 요소 => 반복시 구현할 코드 작성 );

    배열 객체 메모리가 제공하는 length 속성
        - 배열의 크기(배열에 저장된 데이터/요소의 총 개수)를 구하는 속성
        - 메소드(함수)가 아닌 속성(Property)이므로 뒤에 소괄호 ()를 붙이지 않고 사용합니다.

            배열.length
                배열의 크기 (값이 몇개 있는지) 구함

    배열 객체 메모리가 제공하는 map() 메소드
        - 배열의 각요소에 대해 주어진 콜백함수function(){}를 호출하고, 그 결과로 새로운 배열메모리를 생성해서 새로운 배열 메모리 주소번지 자체를 반환하는 메소드
        - 이 메소드는 배열에 저장된 원본데이터를 변경하지 않고 계산에 의해 새로운 배열에 넣어 새로운 배열 메모리 자체의 주소를 반환합니다.
            
            배열.map( function ( 요소, 인덱스, 원본배열자체 ){
                return 각 요소를 가공한 새로운 값;
            }, thisArg/thisArg.속성명 );
            * 여기서 thisArg는 배열.map에서 계산을 수행할때 사용할 객체나 배열 혹은 속성을 받는다는 뜻

            배열.map( function( 요소 ) { return 계산식; });

            배열.map( 요소 => 계산식 );
                ex) 배열.map( n => n * 2 );
                    map(콜백) (콜백은 화살표 함수 (n => ...))
                        모든 값을 변환 → 새 배열 (개수 같음)
                        원본 배열은 그대로 두고 '새 배열'을 돌려줌
    
    배열 객체가 제공하는 find() 메소드
        - 배열의 각 요소에 대해 콜백함수 function을 실행하여, 
            요소 중 조건을 만족하는 첫 번째 요소를 반환한다.
        - 조건을 만족하는 요소가 없다면? undefined를 반환하는 기능의 메소드
        - 원본 배열에 저장된 값(요소)는 변경하지 않는다

            배열.find( function( 요소, 인덱스, 원본배열자체 ){
                return 요소에 대한 조건; // 요소에 대한 조건 (=조건식)이 true이면 해당 요소를 즉시 반환
            });
    
    배열 객체가 제공하는 filter() 메소드
        - 배열의 각 요소에 대해 주어진 콜백함수를 실행하여, 조건을 만족하는(true를 반환하는) 요소들만 따로 모은 새로운 배열을 생성하여 반환하는 메소드
        - 이 메소드는 배열에 저장된 원본 데이터를 변경하지 않고, 조건에 맞는 요소만 선별하여 새로운 배열 메모리 자체의 주소를 반환

            배열.filter( function ( 요소, 인덱스, 원본배열자체 ){
                return 요소에 대한 조건식; // 조건식이 true인 요소만 새 배열에 포함됨
            }, thisArg );

            배열.filter( function ( 요소 ) { return 조건식; });

            배열.filter( 요소 => 조건식 );
                ex) 배열.filter( n => n > 2 );
                    filter(콜백) (콜백은 화살표 함수 ( n => ... ))
                        조건에 맞는 값만 선별 → 새 배열 (개수 줄 수 있음)
                        원본 배열은 그대로 두고 '새 배열'을 돌려줌
    
    배열 객체가 제공하는 slice(index) 메소드
        - 원본배열에서 지정한 범위의 요소를 '추출'하여 새로운 배열을 반환하는 메소드.
        - 원본 배열에 저장된 값(요소)는 변경하지 않는다.

            배열.slice( 시작 인덱스, 끝 인덱스 );
                - 시작 인덱스: 몇 번째 요소 부터 추출할지 지정 (필수)
                - 끝 인덱스: 어디까지 추출할지 지정 (선택, 특징: 지정한 위치 '직전'까지 추출)
                    생략하면 마지막 요소까지 추출
    
    배열 객체 메모리가 제공하는 reduce() 메소드
        - 배열의 각 요소에 대해 주어진 콜백함수를 실행하며, 하나의 누적된 최종 결과값(원시값, 객체, 배열 등 모두 가능)을 반환하는 메소드
        - 합계 구하기, 평균 구하기, 데이터 구조 변환 등 배열을 하나의 값으로 압축할 때 가장 강력하게 많이 쓰입니다. 원본 배열은 변경하지 않습니다.

            배열.reduce( function ( 누적값, 요소, 인덱스, 원본배열자체 ){
                return 다음 누적값으로 전달할 계산식;
            }, 초기값 ); // 초기값을 생략하면 배열의 첫 번째 요소가 초기값이 됨

            배열.reduce( (누적값, 요소) => 계산식, 초기값 );
                ex) 배열.reduce( (sum, n) => sum + n, 0 );
                    reduce(콜백, 초기값) (콜백은 화살표 함수)
                        모든 값을 순회하며 누적 계산 → 최종 값 하나 반환 (숫자, 객체 등)
                        원본 배열은 그대로 두고 '최종 결과값'만 돌려줌

    배열 객체가 제공하는 some() / every() 메소드
        - 배열의 요소들이 특정 조건을 만족하는지 확인하여 보안관처럼 true 또는 false(불리언 값) 하나만 반환하는 메소드입니다.
        - some()은 조건에 맞는 게 하나라도 있으면 true, every()는 모두 맞아야 true를 반환합니다. 원본 배열은 변경하지 않습니다.

            배열.some( 요소 => 조건식 );  // 하나라도 맞으면 true (나머지 순회 중단)

            배열.every( 요소 => 조건식 ); // 모두 맞아야 true (하나라도 틀리면 중단)
                ex) 배열.some( n => n < 0 ); // 음수가 하나라도 있는가?
                    조건 만족 여부 체크 → 논리값(true/false) 반환
                    원본 배열은 그대로 두고 '참/거짓' 결과만 돌려줌

    이외에도 배열 정렬을 위한 sort()나 배열을 합치는 concat() 등
