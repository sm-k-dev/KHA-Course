컴퓨터 RAM은 데이터를 잠깐 저장하는 부품. 
    내부에는 수 많은 칸(셀)으로 나뉨. 칸 하나엔 2진수만 저장. 
    칸 하나의 가장 작은 단위 비트(bit)
    비트 8개 = 바이트 (byte) = 한 칸의 기본 크기
    각 칸엔 주소(ex. 0x006, 주소는 16진수)가 붙어있다.
        비트 > 바이트 > KB > MB > GB > TB (1024배씩 커짐)

변수: 이름이 붙은 저장 공간. 공간에 값을 담고, 이름으로 꺼내쓴다.
    컴퓨터 메모리 (RAM)의 한 공간.
    변수를 만들면 이 칸 중 한 곳을 차지 > 이름을 붙이고 > 값을 저장

    let 변수명 = 값; // 변수 바뀌어도 되는 값
        let 예약어로 변수 메모리를 만들고 = 대입 연산자로 데이터를 저장
        숫자는 그대로, 문자열은 따옴표로 감싸서 변수메모리에 저장
            ex) let age = 20;
                let data = "한국";
        변수는 값을 하나밖에 저장하지 못 한다.
        let은 처음 변수 만들 때 한 번 만 쓴다.
        변수명은 고유값이기에 중복되면 안 된다.
        변수명 규칙     이름에는 문자, 숫자, 특수기호(_와 $ 만) 만 사용 가능 
                    숫자로 시작하면 안된다 (영문, _ , $로 시작)
                    하이픈 (-)이나 띄어쓰기 사용 불가
                    예약어 사용 불가
                    권장 camelCase (카멜 표기법)
    
    const 상수명 = 값; // 상수 바뀌면 안되는 값
    
    console.log("출력하고 싶은 값");

    자료형 - 값에도 종류가 있다. 값이라도 성격이 다르다. 이런 값의 종류를 자료형(Data Type)이라고 한다.
            숫자 값은 계산 할 수 있지만, 글자 값은 계산 할 수 없다. 대신 이어 붙일 수 있다.

연산자
    값을 계산하거나 비교할 때 쓰는 기호
    계산하기 (더하기/빼기), 비교하기 (크다/같다), 판단묶기(그리고/또는)
        - 연산자 좌/우에 오는 값들을 피연산자 라고 한다.
    
    산술: 계산 (숫자)
    비교: 두 값 비교 (참/거짓)
    논리: 여러 조건 묶기 (참/거짓)
    삼항: 조건으로 둘 중 선택

    복합 연산자
        +=
        -=
        *=
        /=
        %=
            예) hp += 10 은 hp = hp + 10
                hp -= 20 은 hp = hp - 20
                gold *= 2 는 gold = gold * 2
    
    비교 연산자
        > 크다
        < 작다
        >= 크거나 같다
        === 같다
        !== 다르다
    
    논리 연산자
        && 그리고 (and) 둘 다 참 이어야 참
        || 또는 (or) 하나만 참이어도 참
        ! 아님 (not) 참 <> 거짓 뒤집기
    
    삼항 연산자
        조건 ? 참일 때 출력할 값 : 거짓일 때 출력할 값

                    break;//마지막 default 자리에 적는 break는 생략 가능 하다.
