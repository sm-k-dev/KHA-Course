컴퓨터 RAM은 데이터를 잠깐 저장하는 부품. 
    내부에는 수 많은 칸(셀)으로 나뉨. 칸 하나엔 2진수만 저장. 
    칸 하나의 가장 작은 단위 비트(bit)
    비트 8개 = 바이트 (byte) = 한 칸의 기본 크기
    각 칸엔 주소(ex. 0x006, 주소는 16진수)가 붙어있다.
        비트 > 바이트 > KB > MB > GB > TB (1024배씩 커짐)

연산자
    값을 계산하거나 비교할 때 쓰는 기호
    계산하기 (더하기/빼기), 비교하기 (크다/같다), 판단묶기(그리고/또는)
        - 연산자 좌/우에 오는 값들을 피연산자 라고 한다.

    비교: 두 값 비교 (참/거짓)
    논리: 여러 조건 묶기 (참/거짓)
    삼항: 조건으로 둘 중 선택

함수
    실행할 코드들을 하나의 이름으로 선언해 두고, 필요할 때 호출해서 실행하는 재사용 가능한 코드 블록입니다.
        매개변수 (Parameter): 함수를 정의할 때 외부에서 받을 값을 담는 변수 (예: 매개변수1)
        인수 (Argument): 함수를 호출할 때 함수에 실제로 전달하는 값 (예: 인수1)

    함수를 만드는 방법 3가지

        함수 선언문 (function declaration) 으로 함수를 만들경우, 
            함수 호이스팅이 발생, 코드 작성 순서상 호출문이 선언문보다 위에 있어도 정상 작동

            function 함수명 ( 매개변수1, 매개변수2 ) {
                실행할 코드;
                return 반환값;
            }

            함수명 ( 인수1, 인수2 ); <- 함수 호출 구문


        함수 표현식 (function expression) 으로 함수를 만들경우, 
            변수에 함수를 할당하는 방식.
            변수 호이스팅 규칙을 따르므로 선언 전 호출 시 에러가 발생.
            안전성을 위해 const를 주로 사용

            익명 함수 / 무명 함수
                const 상수명 = function ( 매개변수1, 매개변수2 ) {
                    실행할 코드;
                    return 반환값;
                };

            기명 함수
                const 상수명 = function 함수명 ( 매개변수1, 매개변수2 ) {
                    실행할 코드;
                    return 반환값;
                };
            
            상수명( 인수1, 인수2 ); <- 함수 호출 구문

        
        화살표 함수 (arrow function, =>)
            익명 함수를 축약한 형태.
            매개변수가 1개면 ( ) 소괄호는 생략 가능하다.
            본문이 한줄이면 return과 { } 중괄호 생략 가능하다.
                화살표 함수에서 { } 를 생략하면 화살표 다음에 오는 코드는 return문으로 처리된다
            치명적 제한: 문법만 짧아진 것이 아니라 this 바인딩이 다르게 작동, argument 객체를 사용할 수 없다.

            const 상수명 = 매개변수 => {
                실행할 코드;
                return 반환값;
            };

            const 상수명 = ( 매개변수1, 매개변수2 ) => {
                실행할 코드;
                return 반환값;
            };

            const 상수명 = 매개변수 => 반환값;

            const 상수명 = ( 매개변수1, 매개변수2 ) => 반환값;
            
            상수명( 인수1, 인수2 ); <- 함수 호출 구문
        
                * 함수 표현식으로 함수를 정의할때는 const키워드를 주로 사용한다.
                var, let키워드를 사용해도 문제없지만, const키워드로 정의하는 것이 좋습니다.
                보통 함수는 일관된 목적을 가진 코드 집합이라서 재정의 해서도, 재할당해서도 안되는 경우가 많기 때문이다.
        
    함수의 반환과 종료
        return; 
            반환값 없이 함수를 그 즉시 강제 종료 시키고 싶을 때 사용 (조기 리턴 패턴에 자주 사용)
        return 반환값;
            함수를 호출한 자리로 결과값을 돌려주고 함수를 즉시 종료
        반환값이 없는 함수
            return문이 아예 없거나 값 없이 return;만 적힌 함수를 호출하면, 
            자바스크립트는 내적으로 undefined를 반환한 것으로 처리
    
    변수 키워드와 호이스팅 (Scope & Hoisting) - 함수 호이스팅, 변수/상수 호이스팅
        함수의 동작을 완벽히 이해하려면 변수의 호이스팅 매커니즘을 먼저 알아야 한다.

        호이스팅(Hoisting)
            코드가 실행되기 전, 자바스크립트 엔진이 선언문들을 최상단으로 끌어올려 먼저 해석하는 현상
        
        함수 선언문 호이스팅
            선언과 동시에 함수 내용 전체가 메모리에 등록된다.
            선언문 위에서 호출해도 정상 실행된다.
        
        var (함수 스코프)
            블록 { } 을 무시한다.
            선언문 위에서 호출해도 에러가 나지 않고 undefined로 초기화 되어 출력 (남용 금지)
        
        let / const (블록 스코프)
            블록 { } 내부에 갇힌다.
            let, const도 사실 호이스팅은 일어난다. 
            다만, 초기화되기 전까지 접근할 수 없는 TDZ (Temporal Dead Zone, 일시적 사각지대)에 빠지기 때문에 브라우저가 '호이스팅이 안 되어서 에러가 난 것'처럼 작동하게 만든다.
            결과적으로 선언 전 호출 시 에러가 나므로 '선언 후 사용' 규칙을 강제
    
    전역 스코프 오염 방지 기술
        하나의 웹페이지에서 모든 코드가 변수명을 공유하면 이름이 겹쳐 충돌하는 스코프 오염이 발생
        
        IIFE (즉시 실행 함수)
            그 자리에서 실행되고 메모리에서 사리지는 이름 없는 함수

            함수들은 프로그램이 실행되면 변수명 등을 프로그램 실행이 끝나기 전 까지 차지한다.
            하지만 한번만 쓸 함수들이 변수명을 차지해 버리면 다음에 그 변수명을 사용 할 수 없게 된다.
                이것을 스코프 오염이라고 한다.

            전역 스코프 오염을 방지하기 위해 딱 한번만 쓸 코드들을 블록 스코프로 묶는데, 블록을 빠져나오면 변수명등은 리셋이 된다 (변수의 유효 범위를 제한, 전역 공간을 보호). 
                (블록으로 묶는 행위를 거친 객체를 함수라고 부른다.)
                함수를 괄호()로 감싸고 뒤에 소괄호()를 붙여서 만들면 이름 없이 그 자리에서 바로 실행되고 끝난다.
                    // 일반 익명 함수 IIFE
                    ( function() {
                        실행할 코드;
                    } )();

                    // 화살표 함수 IIFE 
                    (() => {
                        실행할 코드;
                    })();
                
                기명함수로 IIFE를 만들었을때
                    작성시 이미 한번 실행 했기때문에 식별자로 (함수명) 다시 호출하면 오류가 발생한다.
        
            ES6+ (최신 자바스크립트 버전)
                블록스코프 (let, const)
                    함수를 만들지 않고, 그냥 중괄호 {} 블록만 만들어도 변수가 오염되는 것을 방지

            모듈 (Module) 시스템
                요즘은 파일 단위 (import / export)로 코드를 나누어 개발, 파일 내에 선언한 변수가 자동으로 격리 => 전역 공간을 오염시키지 않는다.

배열
    배열이름 = [];

    배열이름.push("값");
        마지막에 값 추가
    배열이름.pop();
        마지막 값 삭제
    배열이름.unshift("값");
        제일 앞에 값 추가
    배열이름.shift();
        제일 앞 값 삭제
    
    배열이름.length
        배열의 크기 (값이 몇개 있는지) 구함
    
    배열.map(n => 계산식);
        ex) 배열.map(n => n * 2);
            map(콜백) (콜백은 화살표 함수 (n => ...))
                모든 값을 변환 → 새 배열 (개수 같음)
                원본 배열은 그대로 두고 '새 배열'을 돌려줌

    배열.filter(n => 조건식);
        ex) 배열.filter(n => n > 2);
            filter(콜백) (콜백은 화살표 함수 (n => ...))
                조건에 맞는 값만 선별 → 새 배열 (개수 줄 수 있음)
                원본 배열은 그대로 두고 '새 배열'을 돌려줌

객체
    여러 개의 값을 하나의 참조값으로 관리하는 참조형 데이터.
    객체 안에는 속성(Property)과 메소드(Method)를 작성할 수 있다.

    객체? 현실에 존재하는 자신만의 값 + 기능 을 가진 모든 사물이나 사람 등을 객체라고 한다.
    객체 모델링? 현실에 존재하는 객체의 값과 기능을 추출해서 설계하는 작업.

    객체 (Object) - 여러 값을 하나의 구조로 묶어서 관리하는 참조형 데이터
    속성 (Property) - 객체 안에 저장된 데이터
    메소드 (Method) - 객체 안에 속성값으로 저장된 함수 
        객체 내부의 함수 = 메소드
        객체 외부의 함수 = 함수
    Key - 속성 이름
    value - 속성에 저장된 값
    참조값 (Reference) - 객체가 생성된 메모리 위치를 가리키는 값

    객체 생성 방법
        1.  let 객체참조변수명 = new Object();
                new Object();로 생성된 객체 메모리의 주소가 객체참조변수명 메모리에 저장된다.
                
                new 뒤에오는 함수의 객체를 새로 생성하겠다는 예약어
                Object() 오브젝트 생성 함수

                객체 안에 속성과 메소드를 정의 하는 방법

                    객체참조변수명.속성명 = 값;
                    객체참조변수명.메소드명 = function 함수명(){ 실행코드; };

        2. let 객체참조변수명 = {
                                속성명: 값,
                                메소드명: function () { 실행할 코드; };
                            };
    
    객체 호출 방법
        1. 점 표기법으로 속성 이나 메소드 사용
            객체참조변수명.속성명; <- 값을 얻을 수 있다.
            객체참조변수명.속성명 = 새값; <- 객체에 저장된 기존 값을 새 값으로 변경 할 수 있다.
            객체참조변수명.새속성명 = 값; <- 객체 메모리 { } 내부에 새속성명: 값; 한쌍을 추가할 수 있다.
            객체참조변수명.메소드명(); <- 객체 안의 메소드를 호출
            delete 객체참조변수명.속성명; <- 객체에 저장된 속성을 삭제

        2. 대괄호 표기법으로 속성 이나 메소드 사용
            대괄호 표기법 사용 이유 - 하이픈을 포함하는 속성명 or 메소드명이 있다면 [] 표기법으로만 사용 할 수 있다.

            객체참조변수명["속성명"]; <- 속성명에 관한 값을 얻어 올 수 있다. 속성명은 반드시 ""로 감싸야 한다. 객체 {} 내부에 "속성명: 값" 중에서 "값"을 가져오는 문법
            객체참조변수명["속성명"] = 새값 <- 객체 {} 내부에 "속성명: 값" 중에서 "값"을 변경하는 문법
            객체참조변수명["새속성명"] = 값; <- 객체 메모리 { } 내부에 새속성명: 값; 한 쌍을 추가할 수 있다.
            delete 객체참조변수명["속성명"]; <- 객체에 저장된 속성을 삭제

            메소드는 대괄호 표기법으로 사용 할 수 없다.
    
    객체 중첩하기
        { } 객체 안에 "속성명: 값" 에서 "값" 자리에 { }개체를 포함 시킬 수 있다.

            객체명 {
                속성명1: 값1,
                속성명2: {
                    속성명3: 값3,
                    속성명4: 값4,
                    메소드명: function() { 코드; }
                }
            };
        
        사용할때
            객체명.속성명2.속성명3
            객체명.속성명2.메소드명();
    
        this 이해하기
            this는 해당 객체가 저장된 참조값(주소번지)을 가리키는 포인터. 
            this는 메소드(함수)가 실행될 때, 그 메소드를 호출한 객체를 가리키는 키워드이다. (런타임 바인딩) - 함수가 선언될 때가 아니라 실제 누가 호출했느냐에 따라 this가 동적으로 결정
            객체 내부의 메소드(함수)에서 속성에 접근할 때 사용한다.
            - 호출자 중심: this는 언제나 "지금 나를 부른 녀석"
            - 소속 확인: 객체의품 안에서 그 객체의 일을 할 때, "내 것"을 가리키기 위해 쓴다.
