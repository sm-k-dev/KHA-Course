### 1. 정확한 정의

DOM 요소는 문서의 노드 객체이고, `$(selector)`는 선택된 요소를 감싼 **jQuery 객체**를 반환한다. 두 객체는 같은 타입이 아니다.

### 2. 용어를 구분해야 하는 이유

`document.querySelector("#x")`와 `$("#x")`는 같은 것을 반환하지 않는다. 전자는 DOM 요소 또는 null, 후자는 jQuery 컬렉션 객체다.

### 3. 새로운 상황에 적용

`$("#x").length`가 0인 경우와 `document.querySelector("#x") === null`인 경우를 비교한다.

## 1. jQuery 선택자·이벤트

**정의** — jQuery는 DOM 탐색·조작·이벤트·Ajax 등을 간결하게 처리하는 JavaScript 라이브러리다.

**목적과 책임** — 레거시 웹 화면을 읽고 수정할 수 있게 한다.

**구별해야 할 개념 / 흔한 오해** — jQuery는 언어도 브라우저 표준 DOM 자체도 아니다. $() 결과는 일반 DOM 노드와 다르다.

**실행·처리 흐름** — 선택자 → jQuery 객체 → 메서드 호출 → DOM 변경

**직접 구현·검증** — 동일한 클릭 동작을 jQuery와 addEventListener로 각각 구현. 실행 결과를 캡처하거나 테스트 로그로 남기고, 예상과 실제 결과가 다르면 이유를 기록한다.

### 깊이 이해하기 — 개념의 경계와 설계 판단

jQuery는 DOM 탐색·이벤트·Ajax를 간편하게 다루도록 만든 JavaScript 라이브러리다. 브라우저 표준 DOM API와 구별되며 최신 프로젝트에서 필수 의존성은 아니다.

### 직접 읽고 구현하는 독립 예제

```js
// jQuery가 로드된 페이지에서 실행
$("#items").on("click", "button.remove", function(){
  $(this).closest("li").remove();
});
```

**코드 읽기 순서:** 입력·전제조건을 확인하고, 어느 객체/계층이 무엇을 담당하는지 표시한 다음, 정상 경로와 실패 경로를 각각 따라간다. 코드 조각은 문맥상 필요한 클래스·import·설정이 생략될 수 있으며, 실행 전 직접 보완한다.

### 실행 검증 체크포인트

동적으로 생성한 li의 버튼도 삭제되는지 확인한다.

### 스스로 작성할 변형 실습

동일 기능을 addEventListener와 closest로 다시 작성한다.

# 핵심 개념을 오해 없이 이해하기 위한 기초 연결

## 필수 기초 연결: DOM 선택과 이벤트 처리의 주체

jQuery는 브라우저 DOM API를 감싼 라이브러리다. `$('#id')`는 **jQuery 객체**를 반환하며 DOM 요소 그 자체와 같지 않다. `$('#id')[0]`으로 첫 DOM 요소를 얻을 수 있다. `.on('click', handler)`는 이벤트 핸들러를 등록하며 서버의 HTTP 요청을 자동으로 만들지는 않는다.

```javascript
const $button = $('#save');
console.log($button.length); // 요소 없으면 0: jQuery 선택 결과의 원소 수
$button.on('click', () => console.log('클릭'));
```

**검증:** 선택 결과 0개와 JavaScript `null`의 차이를 확인한다. `.length === 0`은 매칭 요소가 없다는 뜻이다. 이 경우 `$button` 변수 자체가 null이라는 뜻이 아니다.

### 경계 1. DOM 요소 / jQuery 객체

**흔한 오해:** “$(element)는 DOM 요소 자체다”

**정확한 구분:** document.querySelector는 DOM 요소를 반환하고 $(...)는 선택된 요소들을 감싼 jQuery 객체를 반환한다. API 집합이 달라서 .text()와 .textContent를 구분해야 한다.

**코드·명령 해석:**

```text
const node = document.querySelector("#title");
const wrapped = $("#title");
node.textContent = "A";
wrapped.text("B");
```

**확인 방법:** wrapped[0] === node를 확인한다.

**직접 구현:** DOM 요소와 jQuery 객체 사이를 변환해 같은 텍스트를 수정하라.

**면접 점검:** “DOM 요소 / jQuery 객체”의 각 용어를 각각 정의하고, 위 코드에서 어느 계층·시점·값에 해당하는지 60초 안에 설명해 보자.


### 경계 2. 이벤트 등록 / 이벤트 실행

**흔한 오해:** “click(handler)는 클릭을 즉시 실행한다”

**정확한 구분:** 이벤트 리스너 등록은 미래 이벤트 발생 시 실행할 함수를 전달하는 것이다. 함수 호출 결과를 전달하면 의도치 않게 즉시 실행될 수 있다.

**코드·명령 해석:**

```text
$("#save").on("click", () => console.log("clicked"));
```

**확인 방법:** 페이지 로드 시 로그가 출력되는지, 클릭 후 출력되는지 구분한다.

**직접 구현:** 동적으로 추가된 버튼에 이벤트 위임을 적용하라.

**면접 점검:** “이벤트 등록 / 이벤트 실행”의 각 용어를 각각 정의하고, 위 코드에서 어느 계층·시점·값에 해당하는지 60초 안에 설명해 보자.


### 경계 3. AJAX 성공 콜백 / HTTP 성공

**흔한 오해:** “success는 네트워크만 연결되면 호출된다”

**정확한 구분:** HTTP 성공 상태와 네트워크 성공은 다르다. jQuery ajax의 성공·실패 분기는 상태 코드, 파서 오류 등의 영향을 받는다.

**코드·명령 해석:**

```text
$.ajax({url:"/api/users", dataType:"json"}).done(data=>console.log(data)).fail((xhr)=>console.log(xhr.status));
```

**확인 방법:** 404, 500, JSON 파싱 실패를 각각 구분한다.

**직접 구현:** 에러 본문을 사용자에게 그대로 출력하지 않는 처리를 추가하라.
