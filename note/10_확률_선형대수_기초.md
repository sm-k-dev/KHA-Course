## 1. 확률 기초

**정의** — 어떤 사건이 일어날 가능성을 0부터 1 사이의 수로 나타낸다. `P(A)`는 사건 A가 일어날 확률이다.

- 여사건: `P(not A) = 1 − P(A)`
- 두 사건이 독립이면 `P(A and B) = P(A) × P(B)`

### 1.1 조건부 확률

**정의** — B가 일어났다는 조건에서 A가 일어날 확률이다.

```
P(A | B) = P(A and B) / P(B)
```

### 1.2 베이즈 정리

사전에 가진 믿음을 새 증거로 갱신한다.

```
P(A | B) = P(B | A) × P(A) / P(B)
```

**예**: 어떤 스팸 필터가 있다. 전체 메일의 1%가 스팸(`P(스팸)=0.01`)이다. 스팸 메일에 "무료"가 들어 있을 확률은 0.9(`P(무료|스팸)=0.9`), 일반 메일에 들어 있을 확률은 0.05(`P(무료|정상)=0.05`)다. "무료"가 들어 있을 때 스팸일 확률은?

```
P(무료) = 0.9×0.01 + 0.05×0.99 = 0.009 + 0.0495 = 0.0585
P(스팸|무료) = 0.009 / 0.0585 ≈ 0.154
```

"무료"가 들어 있어도 스팸일 확률은 15% 정도다. 사전 확률(1%)이 낮으면 증거가 강해도 결과가 크게 바뀌지 않는다. 이 직관이 모델 평가에서 **정밀도(precision)**가 기준율에 따라 달라지는 이유다.

## 2. 확률 분포

| 분포 | 쓰는 상황 | 핵심 값 |
|---|---|---|
| 이항 분포 | 성공/실패를 n번 시행 | `P(k) = C(n,k) p^k (1−p)^(n−k)` |
| 정규 분포 | 키, 측정 오차, 평균 주변 값 | 평균 μ, 표준편차 σ |

**예**: 동전을 10번 던져 앞면이 정확히 5번 나올 확률은 `C(10,5) × 0.5^10 = 252 / 1024 ≈ 0.246`이다.

## 3. 벡터와 내적

**정의** — 벡터는 숫자를 순서대로 모은 것이다. 임베딩(53장)은 문장을 고차원 벡터로 바꾼 것이다.

두 벡터 `a = (a1, a2, …)`, `b = (b1, b2, …)`의 **내적**은 다음과 같다.

```
a · b = a1·b1 + a2·b2 + …
```

**노름(길이)**: `|a| = √(a·a)`

**코사인 유사도**: 방향이 얼마나 같은지 본다. 값의 범위는 −1에서 1이다. 길이에 영향을 받지 않는다.

```
cos(a, b) = (a · b) / (|a| × |b|)
```

RAG에서 질문 벡터와 문서 벡터의 코사인 유사도가 높은 문서를 찾는다. 53장의 검색 평가가 이 계산을 쓴다.

## 4. 행렬 곱

2×2 행렬 `A`와 `B`의 곱은 `A`의 행과 `B`의 열의 내적으로 만든다.

```
A = [1 2]    B = [5 6]    A×B = [1·5+2·7  1·6+2·8] = [19 22]
    [3 4]        [7 8]           [3·5+4·7  3·6+4·8]   [43 50]
```

신경망의 한 층은 "행렬 곱 + 편향 + 활성 함수"다. 임베딩 모델도 같은 계산을 대량으로 한다.

## 5. 검증 코드

```java
public class LinearAlgebraCheck {
    static double dot(double[] a, double[] b) {
        double s = 0;
        for (int i = 0; i < a.length; i++) s += a[i] * b[i];
        return s;
    }
    static double norm(double[] a) { return Math.sqrt(dot(a, a)); }
    static double cosine(double[] a, double[] b) { return dot(a, b) / (norm(a) * norm(b)); }

    static double[][] matmul(double[][] a, double[][] b) {
        double[][] c = new double[a.length][b[0].length];
        for (int i = 0; i < a.length; i++)
            for (int j = 0; j < b[0].length; j++)
                for (int k = 0; k < b.length; k++)
                    c[i][j] += a[i][k] * b[k][j];
        return c;
    }

    public static void main(String[] args) {
        double[] a = {1, 2, 3};
        double[] b = {4, 5, 6};
        System.out.println("dot = " + dot(a, b));                 // 32
        System.out.println("norm(a) = " + norm(a));               // 3.7416...
        System.out.printf("cos(a, 2a) = %.4f%n", cosine(a, new double[]{2, 4, 6})); // 1.0000 (방향만 같음)
        System.out.printf("cos(a, b) = %.4f%n", cosine(a, b));    // 0.9746
        double[][] c = matmul(new double[][]{{1, 2}, {3, 4}}, new double[][]{{5, 6}, {7, 8}});
        System.out.println(java.util.Arrays.deepToString(c));     // [[19.0, 22.0], [43.0, 50.0]]

        // 베이즈: P(스팸|무료)
        double pFree = 0.9 * 0.01 + 0.05 * 0.99;
        System.out.printf("P(스팸|무료) = %.3f%n", 0.9 * 0.01 / pFree); // 0.154

        // 이항: P(동전 10번 중 앞면 5번)
        double binom = 252 * Math.pow(0.5, 10);
        System.out.printf("P(5/10) = %.3f%n", binom);             // 0.246
    }
}
```

**실행 결과 (확인함)**

```
dot = 32.0
norm(a) = 3.7416573867739413
cos(a, 2a) = 1.0000
cos(a, b) = 0.9746
[[19.0, 22.0], [43.0, 50.0]]
P(스팸|무료) = 0.154
P(5/10) = 0.246
```
