# 학습·면접 점검표

이 표는 **학습 완료 표시용**이며, 교재가 읽혔다는 이유로 자동 통과하지 않는다.

| 점검 항목 | 통과 기준 | 결과 |
|---|---|---|
| 정의 | 핵심 용어를 30초 안에 정확한 용어로 설명 | ☐ |
| 역할 | 담당하는 일과 담당하지 않는 일을 설명 | ☐ |
| 관계 | 인접 개념과 차이 1개 이상 설명 | ☐ |
| 흐름 | 요청·데이터·호출 흐름을 그림으로 재현 | ☐ |
| 코드 | 예제 없이 작은 기능을 직접 작성 | ☐ |
| 검증 | 정상·예외 케이스와 실행 로그 제시 | ☐ |
| 응용 | 요구사항 하나를 바꿔 코드 개선 | ☐ |

## 답변 템플릿

> **정의:** X는 무엇이다. **목적:** Y 문제를 해결한다. **책임:** Z를 담당한다. **비교:** A와 달리 B는 ... **예:** 내가 작성한 코드에서는 ...

정의가 불명확할 때 예제부터 암기하지 않는다. 반대로 정의만 외우고 코드를 작성하지 않은 상태도 학습 완료로 표시하지 않는다.
