sql 쿼리 - 윈도우에선 대소문자 구분 안 함 / 리눅스에선 대소문자 구분 함

DB명을 적을때
    표준으론 아무것으로도 감싸지 않는다.
    MySQL / MariaDB - 백틱(``)으로 감싸거나 아무것도 쓰지 않는다.
    postgreSQL / Oracle - 더블쿼트("")로 감싸거나 아무것도 쓰지 않는다.
    싱글쿼트('')는 쓰지 않는다.

싱글쿼트(''): SQL 안에서 문자열 값을 표현할 때 사용
더블쿼트(""): 데이터베이스 객체 이름 (DB 명, 테이블명, 컬럼명)을 지정할 때 사용

실행하고 싶은 SQL 한줄만 실행하고 싶을때
    - 실행할 SQL 라인에 커서를 두고 ctrl + 엔터
    - 실행할 SQL 을 드래그로 선택해서 위의 번개 아이콘 클릭
    
mysql -u root -p
    엔터를 누르면 아래에 패스워드를 입력할 곳이 생긴다
    -u 는 유저를 선택
    -p 는 패스워드를 입력하겠다라는 뜻

show databases;
    현재 DBMS 서버에 만들어져 있는 데이터베이스 목록 보기
    아니면 왼쪽 navigator 창에서 Schemas를 누르면 된다.

create schema 'DB이름';
    DB이름 으로 데이터베이스 만들기

use 데이터베이스명;
    사용할 데이터 베이스 선택

show tables;
    데이터베이스에 있는 모든 테이블을 보겠다

desc 테이블명;
or
desc db명.table명;
    테이블명 에 설정된 컬럼에 대한 정보를 보겠다
    원칙적으로 데이터베이스_이름.테이블_이름 형식을 사용해야 하지만
    대부분 데이터베이스_이름은 생략한다.

select      열_이름 (or *)
            , 열_이름 as 별칭
            , 열_이름 별칭
from        테이블명
[where      조건식]
[group by   열_이름]
[having     조건식]
[order by   열_이름 ASC/DESC]
[limit      숫자];
    테이블명에 있는 모든 데이터 중 조건값에 맞는 행의 모든 열 데이터를 보겠다.
    대괄호에 묶인 부분은 생략 가능하다.
    
create index idx_인덱스를_만들_컬럼_명 
          on 인덱스를_만들_테이블명(인덱스를_만들_컬럼명);
    인덱스 생성 문법

create view 뷰를만들_테이블명_view
  as select *
       from 뷰를만들_테이블명;
    뷰 생성 문법

delimiter //
    create procedure 생성할_스토어드_프로시저_명()
    begin
        프로그래밍할 SQL문장1;
        프로그래밍할 SQL문장2;
        ...
    end // 
delimiter ;
    스토어드 프로시저 생성 문법

call 호출할_프로시저_명();
    스토어드 프로시저 개체를 호출해서 실행하기 위한 문법
