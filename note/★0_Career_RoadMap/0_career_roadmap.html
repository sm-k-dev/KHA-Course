Agent 트랙 검증 기준

  • LLM·RAG: 구조화 출력, 검색 근거, 평가 데이터, 비용·지연 → 환각·권한 누출·실패율 측정
  • Single Agent: 도구 스키마, 상태, 계획, 오류 처리 → 읽기 전용 도구 호출 재현
  • Loop: 실행 → 관찰 → 평가 → 수정, 종료·재시도·예산 → 무한 반복과 중복 실행 차단
  • Harness: 격리, 최소 권한, 승인, 감사 로그, 복구 → 금지 작업 거부와 승인 흐름 입증
  • Sub/Multi-Agent: 역할 위임, 오케스트레이션, 상태 전달 → Single Agent 대비 정확도·비용·복잡도 비교
  • AI Security: Prompt Injection, 데이터 유출, 공급망, 위협 모델 → 공격·방어 테스트 기록

Multi-Agent는 무조건 고급 구조가 아닙니다. 비교 결과에 따라 채택합니다.

  • 신규 확장: 아래 1–5단계. 단계별 변경 이력과 측정 결과를 기록

원칙: 면접에서 직접 설명할 수 있는 범위만 포트폴리오에 적습니다.

  1. 1단계 · Spring Boot 전환 + 화면 연결: REST API, 인증·인가, SQL/JPA, 테스트, API 계약, React 화면 연결

4. 전공 관점: 네트워크·보안

네트워크는 별도 직무가 아니라 문제를 계층별로 진단하는 관점으로 씁니다. 학습 깊이는 원인 분석이 가능한 실습 수준으로 제한하고, 네트워크 자격증 과정을 따로 쌓지 않습니다.

  • 실습 수준: TCP/IP, DNS, TLS, 라우팅, 방화벽. 패킷과 설정으로 원인을 말할 수 있어야 합니다.
  • 개념과 판단: IDS/IPS, SIEM, VPN, Zero Trust
  • 적용 대상: Spring Boot API 보안, AWS VPC·IAM·Security Group, 관측성, AI Agent의 도구 접근·SSRF 방어·샌드박스
  • 진단 순서: 진단 → 핵심 복습 → 패킷·구성 실험 → Backend·Cloud·AI Security 적용
  • 안전 원칙: 패킷 캡처, 포트 스캔, 공격 재현은 본인 소유이거나 명시적 허가를 받은 환경에서만 합니다.

5. 학습 원칙과 시간

  1. 정의 → 원리 → 구현 → 개념의 경계 → 시스템 연결 → 설명·응용 순서로 공부합니다.
  2. 챕터 시작 전 노트를 덮고 2–3분 설명해 선수 지식을 확인합니다. 이미 아는 내용은 압축합니다.
  3. 코드, 테스트, 실험, 측정값으로 이해를 입증합니다. AI가 만든 결과물은 직접 검증합니다.
  4. 보안, 테스트, 운영은 후반에 몰아서 하지 않고 처음부터 필요한 최소 수준을 적용합니다.
  5. 월마다 코드, 테스트, 실험 결과, 회고 4종을 보관합니다. 3개월마다 진도, 취업 우선순위, 학습 시간을 보고 재계획합니다.
  6. 기술 이름이나 수료증보다 스스로 설계하고 문제를 해결한 증거를 남깁니다.
  7. AI에게 시키되, 생성된 코드는 한 줄씩 직접 읽습니다. 과정을 단계별로 설명하게 해서 이해를 확인하고, 정의와 개념의 경계를 말로 설명할 수 있을 때 넘어갑니다.
  • 학습 시간: 주 15–22시간을 기준선으로 삼고, 학원·업무·면접 기간에는 줄입니다.
  • STEM: 수학 우선, 주 1–2시간 (2장 표의 STEM 열 참고). 정보처리기사·지원 기간은 0시간입니다.
  • CS 기본기 점검: M02–M03, M07, M12 월 말에 면접 질문을 노트 없이 2분 안에 설명하는지 확인합니다. 막히면 그 주제를 한 번 더 실습합니다.

6. 공개와 기록

  • GitHub README 정리, 기술 글 분기 1편 (M06 이후 상시)
  • 학원 수업 원본, 비공개 코드, 라이선스가 불분명한 자료는 공개하지 않습니다.
  • API 키, 비밀번호, 개인정보는 기록과 공개물에 넣지 않습니다.
  • 실행한 환경과 버전, 테스트 결과를 사실대로 적고, AI 도움을 받은 범위와 직접 검증한 범위를 구분합니다.

7. 아직 열려 있는 항목

  • Advanced Diploma 과목 목록: 2026-11-24 폴더 기준으로 반영했다. CCNP Routing, CCNP Switch, CCNP Security, Cyber Security resources, Enterprise VoIP. 과목 안의 세부 주제는 자료를 열어 확인한다.
  • 성적표 대조: 호주 과목 목록은 검색 결과 기준입니다. 실제 이수 과목으로 확인합니다.
  • 정보처리기사 필기 접수일: 면접 일정과 겹치지 않도록 확정합니다.
  • 교재 예제 실행 검증: 실행 범위는 장마다 다릅니다. 실행한 항목은 각 장 본문에 '확인함'으로, 나머지는 '미실행'으로 표시합니다. 실행 전에는 '검증 완료'로 표시하지 않습니다.
  • AI 트랙(M17–M24): AI 도구 제품 사용법은 별도 가이드에서 다룹니다. 이 로드맵은 원리, 설계, 검증, 운영에 집중합니다.
