# 커리어 목표

> 개정: 2026-11-20 · 로드맵(0_career_roadmap.html)과 맞춘 최종본

## 1. 목표 한눈에

- **입사 목표 (2027):** 백엔드 중심 풀스택 개발자. Java/Spring Boot 백엔드를 깊게 하고, React/TypeScript로 실제 화면까지 구현한다.
- **장기 정체성:** AI Engineer. AI 시스템을 안전하게 설계·구현·검증·운영한다.
- **한 줄 정의:** 백엔드 중심 풀스택 개발자로 입사해, Cloud/DevOps·AI 파이프라인·보안 역량을 쌓아 AI Engineer로 확장한다.
- **기반:** 호주 IT Network Security 학사·디플로마 과정, 학원 과정, 세미프로젝트(NEXORA/SentinelOps).
- **태도:** 'AI 내성'은 대체 불가능을 보장하는 말이 아니라, 변화에 적응하는 기술적 자립성을 뜻한다.

## 2. 기술 축

- **Backend (중심):** Java, Spring Boot, REST, JPA, SQL, 트랜잭션, 동시성, 테스트
- **Frontend (화면 구현):** React, TypeScript, fetch/Ajax, JSON, 인증 토큰, CORS. 백엔드를 보조하는 수준이 아니라 실제 화면을 만들 수 있어야 한다.
- **AI Application / Agent (차별화):** LLM API, RAG, 평가, Tool Calling, Single/Sub/Multi-Agent, Loop/Harness
- **Cloud / DevOps (운영):** Linux, Docker, AWS, CI/CD, 로그·메트릭·트레이싱. 직접 배포하고 관측·복구한다.
- **Data (AI 파이프라인 범위):** 수집·정제·임베딩 갱신·평가 데이터 구성까지만 직접 한다. Data Engineer는 목표가 아니다.
- **Security (횡단):** 인증·인가, TLS, IAM, VPC, OWASP, Secret 관리, Prompt Injection, Agent 권한 통제

**균형:** 모든 축을 같은 깊이로 하지 않는다. 백엔드와 시스템 설계에 가장 깊이 투자하고, 나머지는 작동하는 결과물을 만들 수 있을 정도로 한다.

## 3. 기반 역량

- **CS:** 컴퓨터 구조, 메모리, 자료구조·알고리즘, OS/JVM, 네트워크, DB, 분산 시스템. 필요한 부분은 실험으로 확인한다.
- **Software Engineering:** OOP, 설계 원칙, API 계약, 테스트, 리팩터링, 장애 분석
- **AI Literacy:** 모델의 불확실성, 컨텍스트, 데이터·권한 경계, 비용·지연·품질 평가. 제품 사용법은 별도 AI 가이드에서 다룬다.
- **STEM:** 수학 우선 (확률·통계, 선형대수 기초), 주 1–2시간. 물리·화학·생물·지구과학은 취업 전 계획에서 제외한다.
- **커뮤니케이션:** 기술적 선택의 이유, 대안, 실패와 개선을 문서·발표·면접에서 설명한다.

## 4. 성장 단계와 취업

**단기 (2026년 말 ~ 2027년)**
- 2026.12.04 학원 수료. 포트폴리오, 테스트, README, 기술 면접을 우선한다.
- 2026.12.07 M01 시작. 입사 지원서 발송도 같은 달에 시작한다.
- 2027.01–02 정보처리기사 필기 1회 응시, 코딩테스트, CS·Java·Spring·SQL·React 면접 준비. 면접 일정은 시험과 겹치지 않게 조율한다.
- 2027.05–06 입사 목표 (보장 아님). 필요하면 하반기 지원으로 조정한다.
- 학원 연계 조건과 과거 경력 증빙은 별도로 확인한다.

**중기 (약 1~3년)**
- 백엔드 신뢰성, 클라우드 배포·관측
- AI 입력용 데이터 파이프라인
- LLM/RAG 기능을 실제 서비스에 적용

**장기 (약 3~5년)**
- 통제 가능한 에이전트와 AI Security까지 설계하는 AI Engineer로 확장한다.
- 조직, 시장, 실무 경험에 따라 전문화 방향을 다시 평가한다.

## 5. 경험과 포트폴리오

- 과거 웹 개발 경험 (HTML, JavaScript, jQuery, AJAX, JSP, Java, Spring, Oracle)은 **기반 경험**으로 기록하고, 현재 숙련도와 구분한다.
- 호주 학사 학습 배경은 기반 전문성으로 명시한다. 부족한 부분만 복습하고, 클라우드 네트워크·백엔드·AI Agent 보안으로 연결한다. 수강 경험 자체를 현업 숙련도로 단정하지 않는다.
- **NEXORA / SentinelOps**는 핵심 포트폴리오다. 기존 구현과 신규 개발, 개인 기여와 팀 기여를 분리한다.
- SentinelOps는 **AI Security & Reliability Platform**으로 점진 확장한다. AI가 필요 없는 기능에는 AI를 넣지 않는다.

## 6. 네트워크·보안 활용

- **관점으로 쓴다.** 네트워크는 별도 직무가 아니라, 문제를 계층별로 진단하는 관점이다.
- **깊이:** TCP/IP, DNS, TLS, 라우팅, 방화벽은 패킷과 설정으로 원인을 말할 수 있는 실습 수준. IDS/IPS, SIEM, VPN, Zero Trust는 개념과 적용 판단까지.
- **적용:** Spring Boot API 보안 → AWS VPC·IAM·Security Group → 관측성 → AI Agent의 도구 접근·SSRF 방어·샌드박스 순서로 적용한다.
- **범위:** 자격증 과정 전체를 다시 쌓지 않는다. 백엔드 취업과 프로젝트에 직접 연결되는 기술을 우선한다.

## 7. 학습·검증 원칙

1. 정의 → 원리 → 구현 → 개념의 경계 → 시스템 연결 → 설명·응용 순서로 공부한다.
2. 챕터 시작 전 노트를 덮고 2–3분 설명해 선수 지식을 확인한다. 이미 아는 내용은 압축한다.
3. 코드, 테스트, 실험, 측정값으로 이해를 입증한다. AI 산출물은 직접 검증한다.
4. 보안, 테스트, 운영은 후반에 몰지 않고 처음부터 필요한 최소 수준을 적용한다.
5. 학습량은 취업 준비와 실제 업무를 우선해 조절한다. 3개월마다 계획을 재평가한다.
6. 수료증보다 **스스로 설계하고 문제를 해결한 증거**를 남긴다.

## 8. 최종 성취 기준

요구사항을 설명하고, 안전한 API와 데이터 흐름을 설계하며, 테스트·배포·장애 진단까지 수행한다. AI 기능의 정확도·비용·지연·위험을 측정하고, 에이전트의 권한·반복·승인·감사를 통제할 수 있다. 구현 근거와 트레이드오프를 타인에게 명확히 전달한다.
