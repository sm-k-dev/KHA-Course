지역 저장소를 원격 저장소에 연결하기
    로컬에 깃허브 레포지토리랑 연결할 디렉토리를 생성한다.
        git init (폴더명)
        cd (폴더명)
        파일생성

        git add (파일명)
        git commit -m "message"
        git log

    원격 저장소에 연결하기
        지역 저장소와 원격 저장소를 연결하려면 원격 저장소의 HTTPS 주소를 알아야 한다.
        git remote add origin (원격 저장소 HTTPS 주소)
        git remote -v
            원격 저장소에 제대로 연결됐는지 확인
        경로가 잘못 되었다면 수정할때
            git remote set-url origin (원격 저장소 HTTPS 주소)
        아예 경로를 삭제 하고 새로 add 하려면
            git remote remove origin

    지역 저장소와 원격 저장소 동기화 하기
        처음으로 원격 저장소에 커밋 올리기
            git branch -M main
                간혹 저장소의 main 브랜치 명이 main이 아닐때 main으로 맞춰주는 명령어
            git push -u origin main
                지역 저장소의 브랜치를 origin (원격저장소)의 main 브랜치로 푸시하는 명령어
                -u 옵션은 지역 저장소의 브랜치를 원격 저장소의 브랜치에 연결하기 위한것으로 처음에만 사용
                -u나 main 브랜치 이름 없이 간단히 푸시 가능

    원격 저장소에 파일 올리기 - git push
        파일 생성
        git add 파일명
        git commit -m "커밋 메세지"
        git push

    원격 저장소에서 커밋 내려받기 - git pull
        git pull origin main

깃허브에 SSH 원격 접속하기
    SSH 원격 접속이란
        Secure Shell의 줄임말
        보안이 강화된 안전한 방법으로 정보를 교환하는 방식
        기본적으로 프라이빗 키 (private key)와 퍼블릭 키 (public key)를 한 쌍으로 묶에서 컴퓨터를 인증한다.
    
    SSH키 생성하기
        터미널 창에서 홈 디렉토리로 이동
        ssh-keygen 입력
            - SSH키가 저장되는 디렉토리 경로가 표시되면서 파일이름을 입력하라고 뜬다.
        파일 이름은 입력하지말고 enter 누른다.
        그 후에 enter를 두번 더 누르면 SSH 접속을 위한 비밀번호가 만들어진다.
            화면에 몇가지 파일 경로가 표시되는데
                id_rsa = 프라이빗 키
                id_rsa.pub = 퍼블릭 키
        
        만들어진 키가 .ssh 디렉토리에 저장되어 있는지 확인
            cd .ssh
            ls -la

            그럼 폴더안에 id_rsa / id_rsa.pub 파일이 만들어져 있다.
    
    깃허브에 퍼블릭 키 전송하기
        SSH로 접속하려면 퍼블릭키를 깃허브에 올려야 한다.
            clip < ~/.ssh/id_rsa.pub 명령어로 내용을 복사 한다.
            깃 허브에 로그인 한다
            오른쪽 위 사용자 아이콘 클릭
            settings > Access 카테고리 > SSH and GPG keys 선택 > New SSH key 버튼 클릭
            title에 알아보기 쉽게 이름을 정하고 Key 항목에 복사한 퍼블릭 키 값을 붙여 넣는다.
            Add SSH key 를 클릭
    
    SSH 주소로 원격 저장소 연결하기
        연결할 원격 저장소의 SSH 주소를 복사한다.
        연결할 지역 저장소를 git 설정을 한다 (git init)
        git remote add origin 복사한 SSH주소
        git remote -v 로 확인

서로 다른 컴퓨터에서 원격 저장소 함께 사용하기
    원격 저장소 복제하기 - git clone
        원격 저장소에 담긴 내용 전체를 지역 저장소로 가져오는걸 복제한다, clone 또는 cloning 이라고 한다.
        클로닝을 할 디렉토리로 이동한다.
        git clone (원격 저장소 주소)
            - git clone (원격 저장소 주소) (디렉토리명)
                디렉토리명으로 지역 저장소 생성함과 동시에 클로닝
    
    A 지역 저장소에서 작업하고 올리기
        작업을 마친후 git add . / git commit -m "message" 하고
        git push 한다.
    
    B 지역 저장소에서 내려받아 작업하기
        작업을 시작하기전에 git pull 로 코드를 새로 내려 받고 작업을 시작한다.

원격 브랜치 정보 가져오기
    원격 main 브랜치
        작업을 시작하기전에 git status를 확인해서 지역 저장소와 원격 저장소의 버전을 체크해주는 버릇
            git status
    
    원격 브랜치 정보 가져오기 - git fetch
        페치(fetch)는 불러오다, 가져오다 라는 뜻
        git fetch 는 원격 저장소의 정보를 가져오는 명령어
        팀 작업을 할 때 다른 사람이 원격 저장소에 커밋한 내용을 무조건 내 지역 저장소에 합치지 않고 원격 저장소에서 수정한 내용을 가져와 훑어본 후에 필요할때만 내 지역 저장소에 합친다.

        하지만 git log 로 살펴보면 HEAD -> main 만 보이고, 원격 저장소의 origin/main은 보이지 않는다. 원격 저장소의 최신 커밋 정보를 가져왔지만 아직 지역 저장소에 합치지 않아서이다.

        git status로 원격 저장소와 내 로컬 저장소의 버전의 차이를 확인한다.
        git fetch로 원격 저장소의 정보를 가져온다
        git diff HEAD origin/main 으로 최신 커밋과 원격 저장소에서 가져온 커밋의 차이를 살펴본다.

        원격 저장소의 커밋을 확인하고 저장소에 합치려면 merge 명령어
        git merge origin/main

        다시 git log --oneline 살펴보면 새 커밋이 지역 저장소에 반영된 것을 확인 할 수 있다.
