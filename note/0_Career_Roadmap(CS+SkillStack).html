💾 메모리 관리

Code: 프로그램 코드 (읽기 전용)
Data: 전역변수, 정적변수
Stack: 함수 호출, 지역변수 (빠르지만 제한적)
Heap: 동적 할당, 객체 (자유로우나 관리 필요)
적용: 성능 최적화, 메모리 누수 방지

📦 자료구조 6가지

배열: 빠른 조회 (O(1)), 삽입/삭제 느림
연결리스트: 삽입/삭제 쉬움, 조회 느림
스택/큐: 순서가 중요한 작업
트리/그래프: 계층 관계, 경로 탐색
면접: "이 알고리즘의 시간복잡도는?" 대답 가능

⚡ 알고리즘 필수 4가지

정렬: 퀵정렬(O(n log n)), 버블정렬(O(n²))
탐색: 이진탐색(O(log n)), 순차탐색(O(n))
그래프: DFS/BFS, 다익스트라 (최단경로)
동적계획법: 피보나치, 부분집합 합
면접: 코딩 테스트 필수 단골

🖥️ 운영체제 개념

프로세스: 메모리를 할당받은 독립 프로그램
스레드: 프로세스 안의 병렬 작업 단위
멀티스레딩: 응답성 ↑, 복잡성 ↑ (동기화 주의)
적용: 백엔드에서 동시 요청 처리

🌐 네트워크 기초

TCP/IP 7계층: 물리 → 링크 → 네트워크 → 전송 → 세션 → 표현 → 응용
HTTP/HTTPS: 웹 통신 프로토콜
DNS: 도메인 → IP 주소 변환
적용: API 설계, 웹 보안

🔍 빅오(Big-O) 복잡도

O(1): 상수 시간 (배열 인덱싱)
O(log N): 로그 시간 (이진탐색)
O(N): 선형 시간 (반복문)
O(N log N): 대부분의 정렬
O(N²): 중첩 반복 (피해야 함)
적용: 대규모 데이터 처리 성능 예측

💻 MySQL vs ANSI 표준 SQL

MySQL 특화

자동증가: AUTO_INCREMENT
페이징: LIMIT 10 OFFSET 5
JSON: JSON 데이터 타입
편함: MySQL 서버에만 쓰면 됨

ANSI 표준

자동증가: GENERATED ALWAYS AS IDENTITY
페이징: OFFSET 5 ROWS FETCH NEXT 10 ROWS ONLY
이식성: PostgreSQL, Oracle, SQL Server로 이동 가능
취업: 다양한 DB에 빠르게 적응

🎯 면접 준비: "N+1 쿼리 문제를 설명해보세요" → JOIN으로 한 번에 가져오기 vs 루프에서 반복 쿼리. 성능차이 O(1) vs O(n)
🔮 다음 단계: ORM (Object-Relational Mapping) SQL을 완벽히 이해한 후, JPA/Hibernate는 훨씬 쉬워집니다. 단, "자동생성된 쿼리가 효율적인가?"를 항상 의심해야 합니다.

🔄 Spring Framework 레거시 vs Spring Boot 비교

Spring Framework (레거시)

설정: XML 중심 (applicationContext.xml)
뷰: JSP + Jasper.jar
IDE: Eclipse + Spring Tools Suite
배포: WAR → 별도 톰캣 서버
학습: 가파름 (설정이 복잡)
특징: 명시적이지만 보일러플레이트 多

Spring Boot (현대)

설정: YAML/Properties 자동화
뷰: Thymeleaf (권장) / Mustache
IDE: IntelliJ IDEA / VS Code
배포: JAR 자체로 실행
학습: 완만함 (자동 설정)
특징: "배터리 포함" 철학

왜 레거시를 배워야 할까?

• 중견기업: 10년 이상 된 Spring 프로젝트 유지보수
• 면접 질문: "Spring Framework와 Spring Boot의 차이는?"
• 이해도: Boot의 자동화가 뭘 자동화하는지 알아야 함
• 마이그레이션: 레거시 → Boot 전환 경험

학습 전략

✅ 현재: Spring Boot 집중 학습 (당신의 수업)
✅ 병렬: Spring Framework 레거시도 이해하기
✅ 방법: Boot 프로젝트 → XML 설정으로 재구성해보기
✅ 장점: 취업 경쟁력 ↑↑

📌 현재 위치 & 학습 계획 당신이 지금 배우는 부분은 Spring Boot입니다. 동시에 선생님이 언급한 Spring Framework (레거시) 개념도 병렬로 학습하면, 중견기업 취직에 훨씬 유리합니다.

복습 순서: Spring Boot 프로젝트를 만들 때 "이걸 레거시로는 어떻게 구성했을까?"를 계속 의문을 가지면서 공부하세요.
🎯 면접 준비 (Spring 관련 질문):
  1. 기본: "Spring Framework와 Spring Boot의 차이는?" → XML vs YAML, 수동 vs 자동
  2. 실전: "IoC/DI는 뭐고 왜 필요한가?" → 객체 생명주기 관리
  3. 고급: "AOP를 어디에 썼나?" → 로깅, 트랜잭션, 캐싱
  4. 취업용: "레거시 Spring 프로젝트 경험이 있나?" → 유지보수 능력 증명

1️⃣ 프로그래밍 활용능력

Java/JavaScript의 깊이 있는 이해와 알고리즘 해결 능력

• 간단한 알고리즘 손코딩 가능 (정렬, 탐색)
• "왜 이 방법을 택했나?"에 답할 수 있을까?

2️⃣ 프레임워크 통합 능력

Spring Boot 및 Node.js 기반 개발 역량
• IoC/DI, AOP 개념 이해
• REST API 설계 경험
• "Spring이 뒤에서 뭘 하고 있을까?" 이해

3️⃣ 데이터베이스 이해

ACID 원칙 준수하는 SQL 설계 및 NoSQL 활용
• JOIN, Subquery 자유로움
• 정규화 개념 이해 (1NF, 2NF, 3NF)
• "왜 이 쿼리가 느린가?" 분석 가능

4️⃣ 서버 인프라 & DevOps

Linux, Docker, CI/CD 배포 자동화 경험

마이크로서비스 & 고도화된 아키텍처 설계
• Spring 백엔드 + TypeScript/React 프론트엔드
• 실제 배포한 프로젝트 (GitHub 링크 준비)

6️⃣ 문서화 & 커뮤니케이션

Swagger API 문서화 및 Agile 협업 능력

📅 전체 학습 일정 (12주 기준)

📍 1주차

JavaScript + CS: 메모리 구조
async/await 마스터. 클로저가 메모리에서 어떻게 작동하는지 이해.

📍 2-3주차

Java + CS: 자료구조
ArrayList vs LinkedList 성능 비교. HashMap의 해시충돌 처리 이해.

📍 4주차

SQL + CS: 알고리즘
JOIN은 그래프 순회. 인덱스는 B-Tree로 O(log n) 검색.

📍 5-7주차

Spring + CS: 운영체제/멀티스레딩
각 HTTP 요청이 별도 스레드에서 처리. Thread-safe한 코드 작성.

📍 8-9주차

TypeScript/React + CS: 성능 최적화
가상 DOM의 Diffing 알고리즘. 메모이제이션으로 성능 개선.

📍 10-11주차

Python/FastAPI + CS: 비동기 처리
이벤트 루프와 async/await. I/O 대기 시간 활용.

📍 12주차

종합 포트폴리오 + 면접 준비
Spring 백엔드 + React 프론트엔드 완전한 웹앱. GitHub + 블로그 정리.
