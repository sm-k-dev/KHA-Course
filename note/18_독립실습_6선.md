# 직접 구현하는 핵심 실습 6개

> 아래 예제는 강의 원본을 복사하지 않은 독립적인 학습용 코드다. 실행 환경이 필요한 예제는 환경 조건을 먼저 확인한다. 코드는 **검증 완료**로 표시하지 않았다.

## 1. Java 인터페이스·다형성 (JDK 17+)

`NotificationDemo.java`로 저장하고 `javac NotificationDemo.java && java NotificationDemo`를 실행한다.

```java
interface Sender {
    void send(String message);
}
class ConsoleSender implements Sender {
    @Override public void send(String message) {
        System.out.println("CONSOLE: " + message);
    }
}
class NotificationService {
    private final Sender sender;
    NotificationService(Sender sender) { this.sender = sender; }
    void notifyUser(String message) { sender.send(message); }
}
public class NotificationDemo {
    public static void main(String[] args) {
        new NotificationService(new ConsoleSender()).notifyUser("hello");
    }
}
```

예상 출력: `CONSOLE: hello`. `Sender`를 구현하는 `FileSender`를 추가하되 `NotificationService`를 수정하지 않고 교체해 보자. 인터페이스는 계약, Service는 사용, 구현체는 구체 전송을 책임진다.

## 2. SQL JOIN·NULL (MySQL 8 기준)

```sql
CREATE TABLE demo_member (id BIGINT PRIMARY KEY, name VARCHAR(40) NOT NULL);
CREATE TABLE demo_post (id BIGINT PRIMARY KEY, member_id BIGINT NOT NULL,
  title VARCHAR(100) NOT NULL,
  FOREIGN KEY (member_id) REFERENCES demo_member(id));
INSERT INTO demo_member VALUES (1, 'A'), (2, 'B');
INSERT INTO demo_post VALUES (10, 1, '첫 글');
SELECT m.name, p.title FROM demo_member m
LEFT JOIN demo_post p ON p.member_id = m.id
ORDER BY m.id;
```

예상: A의 제목과 B의 `NULL` 제목, 총 2행. `WHERE p.title IS NOT NULL`을 추가했을 때 B가 사라지는 이유를 설명하자. 기존 테이블이 있으면 DROP 등으로 정리한 후 별도 실습 DB에서 실행한다.

## 3. HTML·JS DOM 이벤트 위임 (브라우저)

```html
<ul id="tasks"><li>첫 번째 <button class="remove">삭제</button></li></ul>
<button id="add">추가</button>
<script>
  const tasks = document.querySelector('#tasks');
  document.querySelector('#add').addEventListener('click', () => {
    const li = document.createElement('li');
    li.innerHTML = '새 항목 <button class="remove">삭제</button>';
    tasks.append(li);
  });
  tasks.addEventListener('click', (event) => {
    if (event.target.matches('.remove')) event.target.closest('li').remove();
  });
</script>
```

확인: 동적으로 생성된 항목도 삭제되는가? `event.target`, 버블링, 부모 리스너의 관계를 설명하자. 여기서는 고정 문자열만 `innerHTML`로 사용했으며 외부 입력은 HTML로 직접 삽입하지 않는다.

## 4. Servlet 요청·응답 (Jakarta Servlet 6 API 환경)

```java
import java.io.IOException;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.*;

@WebServlet("/ping")
public class PingServlet extends HttpServlet {
    @Override protected void doGet(HttpServletRequest request,
            HttpServletResponse response) throws ServletException, IOException {
        response.setContentType("text/plain;charset=UTF-8");
        response.getWriter().write("pong");
    }
}
```

Jakarta Servlet 6 호환 컨테이너에 배포해 `/ping` 응답을 확인한다. **Tomcat 9 등 `javax.servlet` 환경에서는 그대로 컴파일되지 않는다.** 컨테이너가 서블릿을 생성·관리하고 요청마다 메서드를 호출한다는 점을 설명하자.

## 5. Spring Boot DI·HTTP API (Spring Boot 3.x 환경)

```java
// 각각 별도 파일 또는 적절한 패키지에 선언
public interface GreetingService { String greet(String name); }

@org.springframework.stereotype.Service
public class DefaultGreetingService implements GreetingService {
    public String greet(String name) { return "안녕, " + name; }
}

@org.springframework.web.bind.annotation.RestController
public class GreetingController {
    private final GreetingService service;
    public GreetingController(GreetingService service) { this.service = service; }
    @org.springframework.web.bind.annotation.GetMapping("/api/greet")
    public String greet(@org.springframework.web.bind.annotation.RequestParam String name) {
        return service.greet(name);
    }
}
```

Spring Boot 애플리케이션과 웹 스타터가 준비된 프로젝트에서 `/api/greet?name=Kim` 요청을 확인한다. 반환 값은 JSON 객체가 아닌 텍스트 응답이 될 수 있으며 Content-Type은 메시지 컨버터 설정에 따른다. 컨트롤러가 구현체를 직접 `new` 하지 않는 이유를 설명하자.

## 6. JPA 검색·페이징 설계 과제

`Post(id, title, createdAt, author)`를 가정한다. 검색어가 없는 경우·제목 검색·작성자 검색·두 조건 동시 검색의 **4가지 경우**를 표로 설계한다. 정렬은 `createdAt DESC, id DESC`로 안정화하고, 1페이지와 마지막 페이지, 빈 결과, 새 게시글 삽입 중 다음 페이지 이동을 검증한다. SQL 로그를 기록하고 `Page`의 count 쿼리 비용과 `Slice`의 대안을 비교한다. 엔티티·리포지토리 코드는 사용 중인 Spring Boot/JPA 버전에 맞춰 직접 작성한다.
