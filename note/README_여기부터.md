# 백엔드 핵심 50 — 정의 이해·면접 연결 개정판

이 개정판은 기존 **17개 영역의 핵심 교재와 혼동 개념 비교**를 보존하면서, 과목별 첫 관문과 각 핵심 단원의 능동 확인을 추가했습니다. 로드맵에 맞춰 빠진 주제를 계속 보강하고 있으며, 1·2순위 보강(람다·스트림, 문자·시간·정규식, 확률·선형대수, JS 비동기, Spring 동작 원리, 로깅·설정, Flyway, 프론트 라우팅·상태, 비동기 Java, 디자인 패턴, 부하 테스트, 파인튜닝 판단)을 포함합니다.

## 핵심 학습 원칙

1. **정의 먼저:** 단어를 모르면 그 단어부터 확인합니다. 쉬운 비유는 보조 수단입니다.
2. **용어 경계:** 비슷해 보여도 다른 개념을 구별합니다. 예: 변수/객체, SQL 0행/숫자 0/NULL, JPA/Hibernate/Spring Data JPA.
3. **실행 추적:** 코드에서 선언 타입, 생성되는 객체, 반환값, 실패 상황을 구분합니다.
4. **입으로 설명:** 정답을 가리고 정확한 용어로 말합니다. 막히면 다시 정의를 확인합니다.
5. **면접 적용:** 정의 → 목적 → 비교 → 예시 → 선택 이유 순서로 답합니다.

## 파일 이름 규칙

- `01`~`52`: 학습 순서대로 붙인 장 파일. 장 안에서 "N장"이라고 하면 이 번호를 가리킵니다.
- `90`~`97`: 실습, 점검표, 원본 연결, 집필 현황 같은 부록 파일입니다. 장 번호가 아닙니다.
- 통합 교재 파일(`00_전체교재_*`)은 장 파일을 나눠 보기 위해 삭제했습니다. 장별 파일만 보면 됩니다.

## 읽기 전 주의

- 각 장 맨 앞의 **학습 전 필수 관문**은 그 과목의 대표 혼동 개념을 집중 훈련합니다.
- 각 `## 번호. 핵심 개념` 끝의 **정의를 읽고 넘어가지 않기**는 기존 설명을 읽는 것과 실제로 설명할 수 있는 것을 구분합니다.
- 모범 답변은 암기용 완성 문장이 아니라 **정확성 점검 기준**입니다.
- 예제의 실행 결과는 사용 환경·버전·설정에 따라 달라질 수 있습니다.
- 각 장 상단의 "추가 장" 문구는 실행 여부를 밝힙니다. **"미실행"**이라고 표시된 코드(Spring Security 설정, Spring 컨테이너 예제 등)는 아직 실행하지 않은 예제입니다. 나머지는 장 상단에 적힌 도구와 범위에서 실행해 확인한 결과입니다.
- 교재의 내용과 학습 설계는 교육용이며 실제 기업 면접의 출제 빈도를 통계적으로 보장하지 않습니다.
