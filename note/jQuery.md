"함수 안에서 이벤트 자체에 대한 상세 정보(어떤 키를 눌렀는지, 마우스 좌표가 어디인지 등)나 브라우저의 기본 동작을 제어해야 할 때"만 매개변수를 받고, 그 외에는 안 받으셔도 됩니다.

이 매개변수는 보통 event를 줄여서 e 또는 evt라고 많이 씁니다.

언제 쓰고 언제 안 쓰는지 아주 명쾌하게 정리해 드릴게요!

    1. 매개변수(e)가 굳이 필요 없는 경우 (안 받아도 됨)
        단순히 "클릭하면 이 코드를 실행해라!" 수준의 작업일 때입니다. 이벤트가 발생했다는 사실 그 자체만 중요하고, 상세 정보는 필요 없을 때죠.
            예시 1: 버튼 누르면 팝업창 열기
            예시 2: 버튼 누르면 글자 색상 바꾸기
            예시 3: 위에서 작성하신 코드 (단순히 index 번호만 알아내서 body 스타일 바꿀 때)
        
        // 그냥 '클릭했다'는 사실만 필요하므로 매개변수(e)를 비워둠
        $("#btn").on("click", function() {
            alert("안녕하세요!");
        });

    2. 매개변수(e)가 반드시 필요한 경우 (꼭 받아야 함)
        이벤트가 일어났을 때, 브라우저로부터 추가 정보를 넘겨받아 써야 할 때입니다. 대표적인 3가지 상황이 있습니다.
        
        ① <a> 태그 이동이나 <form> 제출(submit)을 수동으로 막아야 할 때
            아까 질문하신 return false; 대신, 모던 자바스크립트에서는 매개변수 e를 받아서 e.preventDefault()를 쓰는 것을 권장합니다.

            $("a").on("click", function(e) {
                e.preventDefault(); // ◀ <a> 태그의 링크 이동을 막기 위해 e가 필요함!

                alert("링크 이동을 막고 이 메시지를 띄웁니다.");
            });

        ② 사용자가 키보드로 "무슨 키"를 입력했는지 알아야 할 때 (엔터키 체크 등)
            검색창에 글자를 치고 엔터(Enter)를 눌렀을 때만 검색이 되게 하고 싶다면, 어떤 키를 눌렀는지 브라우저에게 물어봐야 합니다.

            $("#search-input").on("keydown", function(e) {
                // e.key나 e.keyCode를 사용해 어떤 키가 눌렸는지 확인 가능!
                if (e.key === "Enter") { 
                    alert("엔터키를 누르셨군요!");
                }
            });

        ③ 마우스가 움직인 현재 좌표를 알아내야 할 때
            화면에 커스텀 마우스 포인터를 만들거나, 마우스를 클릭한 정확한 위치(X, Y 좌표)를 알아내야 할 때 사용합니다.

            $(document).on("mousemove", function(e) {
                // 마우스의 실시간 X, Y 좌표를 가져옴
                let mouseX = e.pageX;
                let mouseY = e.pageY;
                
                $("#pointer").css({ left: mouseX, top: mouseY });
            });

    앞으로 코드를 짜실 때 "내가 지금 실행하려는 코드에 '어떤 키를 눌렀는지', '어디를 클릭했는지', '기본 동작을 막아야 하는지' 같은 정보가 필요한가?"를 스스로에게 질문해 보세요.필요하다면 function(e)로 시작하고, 필요 없다면 그냥 function()으로 비워두시면 됩니다!
