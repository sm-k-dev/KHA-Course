JQuery(제이쿼리)?
	- 모질라 회사에서 개발자였던 존 레식이 자바스크립트 언어의 문법을 이용해 만든 라이브러리 언어.

라이브러리언어란?
	- 자바스크립트 문법으로 만들어진 다양한 함수들을 작성 해 놓은 자바스크립트 파일. .js 파일

Query라이브러리 사용하는 방법 2가지 
    1. JQuery라이브러리 파일 .js를 다운로드해서 사용하는 방법 
    2. 네트워크 전송 방법  CDN주소를 복사 해 놓고 인터넷을 통해 .js파일을 현재 페이지로 불러와 사용하는 방법
