1. 파일 및 디렉토리 관리: 가장 기본이 되는 디렉토리 이동과 파일 제어 명령어
    pwd: 현재 디렉토리 위치
    ls -la: 숨김 파일 포함 상세 목록 출력
        -a 숨긴 파일이나 디렉토리 함께 표시
        -l 파일이나 디렉토리 상세 정보 함께 표시
        -r 파일의 정렬 순서를 거꾸로 표시
        -t 파일 작성 시간순으로 (내림차순) 표시
    cd [경로]: 지정한 디렉토리로 이동
        ~ 홈 디렉토리 (ex. cd ~ : 홈 디렉토리로 이동)
        . : 현재 사용자가 작업 중인 디렉토리
        .. : 현재 디렉토리의 상위 디렉토리
    mkdir [이름]: 새 디렉토리 생성
    touch [이름]: 빈 파일 생성
    cp [원본][대상]: 파일 복사 (-r 추가 시 디렉토리 복사)
    mv [원본][대상]: 파일 이동 또는 이름 변경
    rm [파일]: 파일 삭제 (-rf 추가 시 디렉토리 강제 삭제)
        -r : 디렉토리 안에 있는 하위 디렉토리와 파일을 함께 삭제

2. 시스템 정보 및 관리: 서버 상태를 확인하고 제어할 때 사용
    uname -a: 커널 및 OS 정보 확인
    df -h: 디스크 남은 공간 확인 (읽기 쉬운 단위)
    free -m: 메모리 사용량 확인 (MB 단위)
    top: 실시간 프로세스 소비량 확인
    ps -ef: 실행 중인 전체 프로세스 목록 출력
    kill -g [PID]: 특정 프로세스 강제 종료
    history: 이전에 입력한 명령어 기록 조회

3. 권한 및 소유권 (Security 기초): 파일 접근 제어 명령어
    chmod [권한][파일]: 파일 권한 변경 (예: chmod 755 script.sh)
    chown [유저]:[그룹][파일]: 파일의 소유자와 그룹 변경
    sudo [명령어]: 관리자(root) 권한으로 명령어 실행
    passwd: 현재 사용자의 비밀번호 변경

4. 네트워크 설정 및 진단: 네트워크 장비나 서버 간의 연결을 확인하는 명령어
    ip a: 네트워크 인터페이스 및 IP 주소 확인 (ifconfig 대체)
    ping [IP/도메인]: 대상 서버와의 연결 상태 점검
    netstat -tuln: 열려있는 포트 및 네트워크 연결 상태 확인 (ss -tuln 사용 권장)
    nslookup [도메인]: DNS 네임 서버 조회
    tracerout [IP]: 목적지까지 가는 네트워크 경로 추적
    curl -l [URL]: 웹 서버의 헤더 정보 요청 및 응답 확인

5. 파일 내용 확인 및 텍스트 처리: 설정 파일을 열어보거나 특정 로그를 찾을 때 필수
    cat [파일]: 파일 내용 전체 출력
        cat file(s) > Newfile - file(s)를 차례로 연결해서 새로운 파일인 Newfile을 만든다
        cat file1 >> file2 - file1의 내용을 file2의 내용 끝에 연결
    less [파일]: 큰 파일을 페이지 단위로 화면 출력 (종료는 q)
    head -n 10 [파일]: 파일의 상위 10줄 출력
    tail -f [파일]: 파일의 하위 내용을 실시간으로 모니터링 (로그 확인용)
    grep [패턴][파일]: 파일 내에서 특정 문자열 검색
    nano [파일] / vi [파일] / vim [파일]: 텍스트 에디터로 파일 편집
        빔의 ex 모드 명령
            l 이나 a를 눌러서 입력모드로 바꿔야 한다
            :w / :write - 편집하던 문서를 저장
            :q / :quit - 편집기를 종료
            :wq - 저장하고 종료
            :q! - 저장하지 않고 종료. 확장자가 swp인 임시파일이 생성된다
            :wq 파일명 - 편집하던 문서를 지정한 파일명으로 저장

1. 실무형 명령어 및 옵션 검색 사이트
    tldr pages (tldr.sh)
        리눅스 매뉴얼(man)대신 실무에서 가장 많이 쓰는 예제로 요약
        활용: 검색창에서 tar나 iptables를 치면, 압축을 풀거나 방화벽을 설정하는 실무 명령어 조합만 바로 복사할 수 있게 제공
    ExplainShell (explainshell.com)
        ps -ef나 tar -xvf 처럼 여러 옵션이 섞인 복잡한 커맨드를 입력하면 각 옵션이 무엇을 뜻하는지 쪼개서 시각적으로 설명
        활용: 과거에 썼던 복잡한 명령어가 기억나지 않을때 구조파악하기 좋음
    Linux Command Library (linuxcommandlibrary.com)
        수천 개의 리눅스 명령어가 카테고리별로 깔끔하게 정리, 각 명령어의 상세 옵션과 예제를 볼 수 있다

2. 한눈에 보는 고품질 시트 (Cheat Sheets)
    Cheatograpy Linux Cheat Sheets

        추천검색어: Sysadmin, Networking, Security 키워드로 검색하면 요약본을 찾을 수 있다.

3. 체계적인 무료 독학 및 리드미 자료
    The Linux Command Line (linuxcommand.org)
        리눅스 커맨드 라인의 교과서 같은 서적을 저자가 웹사이트에 무료로 공개 (PDF 다운로드 가능)
