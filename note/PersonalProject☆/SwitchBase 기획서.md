# SwitchBase 기획서

Oct 12, 2026 · @Soon

## 개요

SwitchBase는 기계식 키보드 스위치를 데이터와 취향으로 정리하는 지식 + 커뮤니티 플랫폼이다. 부제는 "Mechanical Keyboard Switches, structured by data and taste."

**프로젝트 성격**

- 장기 취미 + 커뮤니티형 프로젝트
- 감정 회복과 창의성 유지를 위한 작업
- 나중에 "나라는 사람"을 보여주는 보조 스토리
- 취업용 메인 포트폴리오는 아님

그래서 일정이나 완성도 압박보다, 오래 즐겁게 손볼 수 있는 구조를 우선한다.

## 목적과 타겟

**목적**

- 키보드 스위치를 제조사 / 특성 / 소리 / 감각 기준으로 체계화
- 유저가 경험 기반 데이터를 남길 수 있는 커뮤니티
- "어떤 스위치가 나에게 맞을까?"를 감각적으로 탐색

**타겟 유저**

| 유저 | 주로 하는 일 |
| --- | --- |
| 기계식 키보드 입문자 | 첫 스위치 고르기, 용어 배우기 |
| 스위치 수집가 / 커스텀 유저 | 상세 스펙 비교, 체감 데이터와 후기 남기기 |
| 타건감·소리 취향이 분명한 사용자 | 취향 기준 필터로 비슷한 스위치 찾기 |

## 핵심 기능

스위치 위키가 중심이고, 체감 평가와 타건음 샘플이 그 위에 쌓인다. 스펙은 모두가 함께 고치는 하나의 정답이고, 체감은 각자 남겨서 집계하는 의견이다.

### 1. 스위치 위키

스위치 데이터는 위키피디아처럼 유저가 직접 등록하고 수정한다.

| 구분 | 항목 |
| --- | --- |
| 기본 | 제조사, 모델명, 타입 (Linear / Tactile / Clicky), 출시 연도 |
| 규격 | MX 호환 / 로우프로파일 / 자석식(홀 이펙트), 3핀 / 5핀 |
| 힘과 거리 | 작동 압력 (g), 바닥 압력 (g), 작동 거리 (mm), 총 이동거리 (mm) |
| 재질 | 상부/하부 하우징, 스템, 스프링 정보, 공장 윤활 여부 |
| 구매 | 판매 상태 (판매 중 / 단종 / 한정판), 가격대 |
| 관계 | 리컬러, OEM 리브랜드, 후속 버전 (나중) |
| 미디어 | 사진 |

- 스위치 하나 = 위키 문서 하나. 수정할 때마다 버전이 남고, 이전 버전과 비교하거나 되돌릴 수 있다
- 스펙 항목마다 출처 링크를 단다 (제조사 페이지, 실측 영상). 제조사 표기값과 실측값이 다르면 둘 다 적는다
- 새 스위치 등록 전에 이름 검색을 거쳐 중복을 막는다
- 처음엔 운영자(나)가 "최근 변경" 목록을 보고 이상한 수정만 되돌린다. 사람이 늘면 신규 계정의 수정만 검토 대기로 돌린다
- 빈 위키로는 사람이 오지 않으니, 공개 전에 운영자가 직접 스위치를 채워둔다 (운영 원칙 참고)

### 2. 체감 평가와 빌드 환경

유저가 써본 느낌을 남기고, 집계한 평균 특성을 시각화한다. 같은 스위치도 빌드에 따라 소리가 달라서, 평가마다 어떤 빌드에서 썼는지를 함께 받는다.

**체감 항목**

| 항목 | 입력 방식 |
| --- | --- |
| 소리 크기 | 조용함 \~ 큼 (척도) |
| 소리 성향 | 도각 / 쪅 / 묵직 / 둔탁 (선택) |
| 타건감 | 부드러움 / 명확함 / 걸림 (선택) |
| 피로도 | 낮음 \~ 높음 (척도) |

**데이터 구조**: 빌드 환경은 스위치 테이블의 열이 아니라 평가 한 건에 붙는다. 평가가 쌓여도 행만 늘고 열은 그대로다.

| 테이블 | 한 행이 뜻하는 것 | 예시 항목 |
| --- | --- | --- |
| 스위치 | 스위치 1종 (위키 문서) | 제조사, 타입, 압력, 하우징 |
| 빌드 | 유저의 키보드 1대 | 하우징 재질, 보강판, 마운트 방식, 키캡 |
| 평가 | 유저가 스위치 1종을 빌드 1대에서 써본 경험 | 체감 항목 4개, 윤활 여부, 개조 태그 |

- 빌드는 프로필에 한 번 등록해두고 평가할 때 고르기만 한다. 빌드 없이도 평가는 가능하다
- 자주 필터링할 핵심 항목(하우징 재질, 보강판, 마운트, 윤활 여부)은 고정 선택지로 받는다
- 테이프 모드, 폼 제거, 스프링 교체 같은 나머지 개조는 자유 태그로 받되, 기존 태그를 자동완성으로 먼저 보여줘 "알루 / 알루미늄 / aluminum" 같은 분열을 막는다
- 화면에서는 기본으로 전체 평균을 보여주고, "알루미늄 + 순정만" 같은 필터로 좁혀 본다
- 평균 옆에는 표본 수(평가 N명)를 항상 표시한다
- 감각 용어(도각, 쪅, 묵직, 둔탁, 걸림)는 뜻을 정의한 용어 사전을 두고, 평가 화면에서 바로 볼 수 있게 한다. 입문자 가이드 역할도 한다

### 3. 타건음 샘플

유튜브 영상을 모아 쓴다. 영상마다 녹음 환경이 달라 완전한 객관성은 포기하고, "같은 조건끼리만 비교"와 "조건을 투명하게 표시"로 간다.

1. 소리 파일을 받아 올리지 않고, 유튜브 임베드 + 시작 시간으로 단다. 다운로드 후 재업로드는 저작권과 유튜브 약관 문제가 생길 수 있다
2. 샘플마다 녹음 조건을 아는 만큼 태그로 단다: 채널, 키보드/보강판, 키캡, 윤활 여부. 위키처럼 유저도 샘플을 추가할 수 있다
3. 비교의 단위는 "같은 채널"이다. 한 유튜버가 같은 보드에서 스위치만 바꿔 녹음한 시리즈는 서로 비교가 꽤 공정하다. A vs B 비교 화면에서 같은 채널 샘플이 있으면 그걸 먼저 보여준다
4. 샘플 옆에 "녹음 환경에 따라 다르게 들릴 수 있어요" 한 줄을 둔다
5. 나중에는 같은 보드·마이크·거리로 직접 녹음한 "SwitchBase 기준 샘플"을 만든다. 보유 스위치가 늘수록 쌓이는 자산이고, 비슷한 서비스에 거의 없는 것이다

### 4. 유저 활동

- 별점 평가
- 짧은 사용 후기
- "이 스위치는 이런 사람에게 추천" 체크
- 내 컬렉션: 스위치마다 즐겨찾기(Wishlist) / 보유 중 / 써봄 상태를 따로 표시
- 프로필: 내 빌드 목록, 내 평가로 만든 취향 요약 (나중)
- 후기 "도움됨" 표시 (나중)
- 신고 버튼과 간단한 이용 규칙. 위키 수정과 후기 모두 대상

### 5. 탐색

- 검색과 정렬: 이름 검색, 평점순, 평가 많은 순, 최신 후기순
- 필터: 제조사, 타입, 규격, 압력 범위, 소리 성향, 타건감, 판매 중만 보기
- 비교 보기 (A vs B): 스펙, 체감 평균, 같은 채널 타건음을 나란히
- 입문자 가이드: 리니어/택타일/클릭과 감각 용어 사전을 한 페이지로
- 취향 테스트 (나중, AI 없이): 질문 몇 개에 답하면 필터 프리셋으로 바꿔 "나에게 맞는 스위치" 목록을 보여준다

## 계정 / 인증

이메일 기반 로그인만 둔다. 둘러보기는 로그인 없이 가능하고, 즐겨찾기 / 평가 / 후기 작성 때만 로그인이 필요하다. SNS 로그인은 후순위.

## 운영 원칙

- 언어는 한국어 먼저. 스위치 이름과 제조사는 영문 원어를 그대로 쓴다
- 수익이 없으니 월 비용 상한을 정해두고, 무료 티어 위주의 기술 스택을 고른다 (상한 금액은 미정)
- 이메일을 받으니 공개 전에 개인정보 처리방침과 회원 탈퇴를 준비한다
- 사진은 유저가 직접 찍은 것을 우선하고, 제조사 사진은 출처를 표기한다

## 단계 (제안)

취미 프로젝트가 지치지 않으려면 작게 완성되는 지점이 있어야 한다. 각 단계는 그 자체로 쓸모가 있게 끊는다.

1. **나만의 스위치 위키**: 스위치 위키 + 검색/필터. 운영자가 국내에서 많이 쓰는 스위치 50\~100개를 직접 채운다. 로그인 없이 둘러보기
2. **커뮤니티 열기**: 이메일 로그인, 유저 위키 수정, 체감 평가 + 빌드, 후기, 내 컬렉션, 신고
3. **소리와 비교**: 타건음 샘플 임베드, A vs B 비교, 입문자 가이드
4. **그 다음**: 취향 테스트, 프로필 취향 요약, 스위치 간 관계, SwitchBase 기준 샘플 녹음

## 비슷한 서비스와 경쟁력

스위치 스펙 DB는 이미 잘 만든 곳이 있어서 그걸로는 이기기 어렵다. 대신 "빌드 맥락이 붙은 유저 체감 데이터"와 "한국어 감각 용어"는 확인한 서비스 중 제대로 하는 곳이 없었다.

| 서비스 | 성격 | 강점 | 없는 것 |
| --- | --- | --- | --- |
| [KeebFinder](https://keeb-finder.com/switches) | 스위치 카탈로그 (약 1,000개) | 스펙·필터·가격·비교가 매우 충실 | 유저 평가·후기, 타건음 (소리는 "Thocky" 같은 텍스트 한 단어) |
| [kbd.news 스위치](https://kbd.news/switch/) | 판매량 기반 스위치 목록 (상위 500개) | 실제 판매 데이터, 판매처 가격 | 유저 평가·후기 |
| [RTINGS](https://www.rtings.com/keyboard-switch/learn/how-we-test) | 실험실 테스트 리뷰 (약 150개) | 표준화된 측정, 객관성 | 커뮤니티, 적은 개수, 일부 유료 |
| [Deskthority 위키](https://deskthority.net/wiki/Category:Keyboard_switches_by_brand) | 유저 편집 위키 | 빈티지·역사까지 깊음 | 체감 데이터, 탐색·비교 화면 |
| [ThereminGoat 리뷰](https://www.keebtalk.com/t/gateron-x-v3-switch-review/23246) | 한 사람의 심층 리뷰와 점수 | 일관된 기준, 신뢰도 | 다수의 취향, 한국어 |
| 국내 커뮤니티 ([퀘이사존](https://quasarzone.com/bbs/qc_user/views/145052), [클리앙](https://www.clien.net/service/board/cm_keyboard/18466154) 등) | 게시판 후기 | 한국어, 활발한 사용자 | 구조화된 DB, 집계 (후기가 글로 흩어져 있음) |

**SwitchBase가 비집고 들어갈 자리**

- 빌드 환경이 붙은 체감 평균: "알루미늄 + 순정에서는 이렇더라"를 숫자로 보여주는 곳은 확인한 범위에 없었다
- 한국어 감각 용어로 구조화된 DB: 도각, 쪅, 묵직 같은 말은 해외 서비스에 없고, 국내는 게시판 글에 흩어져 있다
- 같은 채널 기준 타건음 비교: 다른 곳은 소리를 텍스트로만 설명한다

**약점과 대응**

- 스펙 범위는 KeebFinder를 못 따라간다 → 국내에서 많이 쓰는 스위치만 깊게 다룬다
- 체감 평균은 사람이 모여야 의미가 있다 → 운영자 본인 평가를 먼저 쌓고, 국내 커뮤니티에 조금씩 공유한다

취미 프로젝트라 경쟁에서 이길 필요는 없다. "내가 제일 쓰고 싶은 스위치 사이트"가 기준이면 충분하고, 위 세 가지는 그 기준과도 겁친다. (조사 기준일 2026-10-12, 웹 검색 범위)
