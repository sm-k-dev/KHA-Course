**수정일:** 2026년 10월 19일

---

## 0. 기본 원칙

| 도구 | 역할 | 하지 않는 것 |
|------|------|-------------|
| **종이 + 계산기** | 개념 이해, 손계산 | - |
| **Java** | 공식을 코드로 구현, 시뮬레이션 실습 (주 학습 도구) | - |
| **Python** | 함수 그래프 검산 (Java 결과가 맞는지 눈으로 확인) | 문법 공부, 프로그래밍 학습 |

**핵심:** Python은 "계산기 옆에 두는 그래프 확인용"입니다. 코드 작성 실력을 키우는 용도가 아닙니다.

---

## 1. 하루 30분 구성

```
15분  개념 학습 (종이에 손으로 풀기)
10분  Java로 같은 개념 구현
 5분  Python으로 그래프 검산 (복붙 + 실행만)
```

검산 코드는 Claude가 써주고, 나는 **실행해서 그래프가 맞는지만 확인**합니다.

## 2. Phase 1: 수학 + 물리 (6개월)

### Month 1-2: 선형함수와 거리
| 주차 | 개념 (종이) | Java 과제 | Python 검산 |
|------|-----------|----------|------------|
| 1-2주 | y = mx + b, 기울기 의미 | `double f(double m, double x, double b)` 함수 작성, x 값별 y 출력 | y = 2x + 1 그래프 |
| 3-4주 | 피타고라스, 두 점 사이 거리 | `distance(x1, y1, x2, y2)` 메서드 작성 | (0,0)-(3,4) 거리 = 5 확인 |
| 5-6주 | sin, cos 의미 (단위원) | Math.sin, Math.cos로 원 위의 점 좌표 출력 | 원 그래프가 찌그러지지 않는지 확인 |

**체크리스트**
- [ ] 기울기와 y절편을 말로 설명 가능
- [ ] Java 결과 값과 그래프가 일치
- [ ] 거리 공식을 손으로 유도 가능

### Month 3-4: 속도, 가속도, 뉴턴 법칙
| 주차 | 개념 (종이) | Java 과제 | Python 검산 |
|------|-----------|----------|------------|
| 7-8주 | 속도 = 거리/시간, 가속도 | 등속 운동 위치 계산 (x = v·t) | 직선 그래프 |
| 9-10주 | 등가속도 공식 s = v0·t + ½at² | 등가속도 위치를 t=0~5초까지 출력 | 포물선 그래프 |
| 11-12주 | 뉴턴 제2법칙 F = ma | 질량, 힘 입력 → 가속도 계산 메서드 | 손계산 값과 비교 |

**체크리스트**
- [ ] 그래프의 기울기가 속도인 이유 설명 가능
- [ ] 힘과 질량으로 가속도를 손으로 계산 가능

### Month 5-6: 에너지와 벡터
| 주차 | 개념 (종이) | Java 과제 | Python 검산 |
|------|-----------|----------|------------|
| 13-16주 | 운동에너지 ½mv², 위치에너지 mgh | 높이별 에너지 계산, 에너지 합이 일정한지 확인 | 에너지 그래프 |
| 17-20주 | 벡터 덧셈, 크기 | Vector2D 클래스 작성 (add, length 메서드) | 화살표 두 개 합쳐지는 그림 |
| 21-24주 | 자유낙하 시뮬레이션 개념 (작은 시간 간격으로 반복 계산) | 0.01초 간격 루프로 낙하 위치 계산 | 낙하 궤적 그래프 |

**Phase 1 완료 체크리스트**
- [ ] 선형함수, 거리, 속도, 가속도를 종이에서 계산 가능
- [ ] 뉴턴 법칙으로 간단한 운동 예측 가능
- [ ] Java로 간단한 물리 시뮬레이션 1개 완성 (낙하 또는 포물선 운동)

## 6. 막혔을 때

- **개념이 안 잡히면:** 종이에서 숫자 하나를 넣어 손으로 따라 계산
