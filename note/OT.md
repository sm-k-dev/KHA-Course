클라이언트 - 사이트 이용자
웹브라우저 - 사이트 이용자가 사용하는 프로그램 (크롬, 사파리, 엣지 종류)
IP - Internet Protocol, 컴퓨터나 특정 기기 하드웨어에 부여된 전 세계 하나밖에 없는 고정된 주소
Protocol - 통신의 약속, 규칙
서버 - 24시간 켜 놓고 정적, 동적 파일을 저장해 놓고 제공하는 슈퍼 컴퓨터
서버종류 - 1. 웹서버 2. 웹어플리케이션서버 3. DNS 서버 4. DB 서버
    1. 웹 서버 - 정적인 문서 .html .css .js .jpg .png 를 보관하고 브라우저로 제공하는 서버
    2. 웹 어플리케이션 서버 - 동적인 문서 .java .jsp 를 DB 서버로 부터 가져온 데이터와 합쳐서 브라우저로 제공하는 서버
    3. DNS 서버 - 웹서버 IP 주소와 도메인 주소를 한 쌍으로 연결해서 저장. 
                웹 서버의 IP 주소를 클라이언트가 처음 도메인 주소로 요청한 브라우저로 제공하는 서버
    4. DB - 대량의 데이터 Data Base 
        4.1 DB 서버 - DB를 저장하고 관리하고 제공하는 서버. 고객 정보, 게시판 글 정보, 날씨 정보 등
        4.2 DB 서버 종류 - MySQL, Oracle, 몽고DB, PostgreSQL, SQL-Server

    URN - Uniform Resource Name 자원의 이름
