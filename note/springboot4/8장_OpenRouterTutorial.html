이 자습서는 IntelliJ IDEA에서 따라 하는 실습서입니다. 파일은 IntelliJ 편집기에서 열고, 명령은 IntelliJ 아래쪽 Terminal 탭에서 실행합니다. 별도의 PowerShell 창은 열지 않습니다.

💡 이 자습서에서 할 일
1) IntelliJ에서 프로젝트를 열고 설정을 점검합니다. 2) 책의 순서대로 코드를 읽고, 필요하면 IntelliJ에 붙여넣습니다. 3) ▶ 버튼으로 앱을 실행하고 결과를 확인합니다. 4) 미션과 퀴즈로 이해를 점검합니다.

2 OpenRouter 키 등록 (PDF 8.2 · 05단계 대체)

💡 API 키는 AI 서비스를 쓸 때 내는 집 열쇠입니다. 책은 OpenAI 키를 쓰지만, 이 자습서는 무료로 쓸 수 있는 OpenRouter 키를 씁니다. 키는 코드 파일에 적지 않고 Windows 환경 변수(컴퓨터에 저장된 비밀 메모)에 둡니다.

  1. 브라우저에서 openrouter.ai에 로그인하고, Keys 페이지에서 Create Key로 키를 만듭니다. 키는 sk-or-v1-으로 시작합니다. 한 번만 보이니 바로 복사하세요.

  2. Windows 환경 변수에 등록 (화면으로 하는 방법): 시작 메뉴에 환경 변수를 검색 → 사용자 환경 변수 편집 → 사용자 변수 목록 아래 새로 만들기 → 변수 이름 OPENROUTER_API_KEY, 변수 값에 복사한 키를 붙여넣기 → 확인.

    📌 이 PC는 이미 등록되어 있습니다(점검표 ⑧). 등록 여부만 확인하고 싶으면 아래 명령을 Terminal에서 실행하세요. 값은 보이지 않고 결과만 나옵니다.
    IntelliJ Terminal
    if ($env:OPENROUTER_API_KEY) { "설정됨" } else { "없음" }
    ✅ 성공 기준: 설정됨이 나옵니다. 없음이면 위 화면 방법으로 다시 등록하세요.

  3. IntelliJ를 완전히 끄고 다시 엽니다. (File → Exit 후 다시 실행) IntelliJ는 켜질 때의 환경 변수만 읽기 때문입니다. 이미 실행 중이었다면 이 과정이 꼭 필요합니다.

  4. 설정 파일 application.yml을 엽니다. Ctrl + Shift + N을 누르고 application.yml을 입력해 여세요. 키는 ${OPENROUTER_API_KEY}로 환경 변수에서 읽고, 주소는 OpenRouter로 바꿔 두었습니다. (책의 api-key: <<입력>> 자리와 같은 곳입니다)

    src/main/resources/application.yml
    spring:
  jpa:
    show-sql: true
    properties:
      hibernate:
        format_sql: true
    defer-datasource-initialization: true
  datasource:
    url: jdbc:h2:mem:testdb
    username: sa
  h2:
    console:
      enabled: true
  ai:
    openai:
      # OpenRouter는 OpenAI 호환 API를 제공하므로 base-url만 바꿔서 사용합니다.
      # Spring AI가 뒤에 /v1/chat/completions 를 붙이므로 /v1 은 빼야 합니다.
      base-url: https://openrouter.ai/api
      api-key: ${OPENROUTER_API_KEY}
      chat:
        options:
          # 무료 라우터 모델입니다. 실행할 때마다 여러 무료 텍스트 모델 중 하나가 자동 선택됩니다.
          # 텍스트(글 생성)만 가능하고 이미지 생성은 할 수 없습니다.
          model: openrouter/free

# 무료 모델(openrouter/free)은 이미지 생성을 지원하지 않아서 섬네일 기능을 꺼 둡니다.
app:
  thumbnail:
    enabled: false
    ⚠️ 흔한 실수: base-url 끝에 /v1을 붙이면 주소가 두 번 붙어서 404가 납니다. 지금 값(https://openrouter.ai/api)을 그대로 두세요.
⚠️ 자주 나는 오류
· Could not resolve placeholder 'OPENROUTER_API_KEY' → 환경 변수가 없거나 IntelliJ를 다시 켜지 않았습니다. 위 3단계를 다시 하세요.
· 나중에 401 오류 → 키를 잘못 옮겼습니다. Keys 페이지에서 새로 만들어 환경 변수 값을 바꾸세요.
🛠️ 미션 4: Terminal에서 설정됨이 나오고, IntelliJ를 다시 켠 뒤 체크하세요.

3 의존성 추가 · 테스트 실행 (PDF 8.3 · 의존성 추가하기)

💡 의존성(dependency)은 프로젝트가 가져다 쓰는 외부 라이브러리 목록입니다. 요리에 비유하면 재료 주문서입니다. 스프링 AI 2.0은 아직 "미리 공개된 테스트 판(마일스톤)"이라서 마일스톤 저장소 주소가 필요합니다. BOM은 여러 라이브러리의 버전을 한 번에 맞춰 주는 버전 목록표입니다.

  1. build.gradle을 엽니다(Ctrl + Shift + N). 아래는 파일 전체입니다. 스프링 AI 관련 줄은 repositories의 마일스톤 주소 한 줄과 dependencies의 세 줄입니다.

    toolchain {

    maven { url 'https://repo.spring.io/milestone' }
}

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter'
    implementation 'org.springframework.boot:spring-boot-starter-web'
    implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'

    implementation platform('org.springframework.ai:spring-ai-bom:2.0.0-M1')
    // OpenAI 호환 스타터: OpenRouter처럼 OpenAI 방식으로 말하는 AI 서비스에 모두 연결할 수 있습니다.
    // ChatClient(글 생성)와 ImageModel(이미지 생성) 자동 설정이 이 한 줄로 들어옵니다.

    testImplementation 'org.springframework.boot:spring-boot-starter-test'
    testImplementation 'org.springframework.boot:spring-boot-starter-webmvc-test'
    testImplementation 'org.springframework.boot:spring-boot-starter-data-jpa-test'

    runtimeOnly 'com.h2database:h2'
    compileOnly 'org.projectlombok:lombok'
    annotationProcessor 'org.projectlombok:lombok'

tasks.named('test') {
    useJUnitPlatform()
}

import java.util.Map;

// [8장 · 글쓰기 도우미 · 요청 데이터]
// 글 작성 화면의 "AI 도움받기" 창에서 입력한 값을 서버로 보낼 때 쓰는 "택배 상자"입니다.
// 브라우저가 보낸 JSON {"title": "...", "content": "...", "question": "..."} 이
// 이 record 객체로 자동 변환됩니다(@RequestBody 덕분).
//
// record: Java 14부터 정식 도입된 "불변(한 번 만들면 못 바꾸는) 데이터 객체"입니다.
// 필드, 생성자, getter가 자동으로 만들어져서 DTO를 짧게 쓸 수 있습니다.
public record WritingSuggestionRequest(
        String title,     // 지금 작성 중인 글 제목
        String content,   // 지금 작성 중인 글 본문
        String question   // "어떤 부분이 고민되시나요?"에 적은 질문
) {

    // 프롬프트 템플릿(resources/prompts/writing-assistant.st)의 빈칸을 채울 값들을 Map으로 묶습니다.
    // Map.of의 "키"("title", "content" ...)가 템플릿의 {title}, {content} ... 이름과 똑같아야 합니다.
    // format은 BeanOutputConverter가 만든 "JSON으로 답하라"는 안내 문장입니다.
    public Map<String, Object> toMap(String format) {
        return Map.of(
                "title", title,
                "content", content,
                "question", question,
                "format", format
        );
    }
}

    src/main/java/me/shinsunyoung/springbootdeveloper/service/WritingAssistantService.java
    package me.shinsunyoung.springbootdeveloper.service;

import me.shinsunyoung.springbootdeveloper.dto.WritingSuggestionRequest;
import me.shinsunyoung.springbootdeveloper.dto.WritingSuggestionsResponse;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.prompt.PromptTemplate;
import org.springframework.ai.converter.BeanOutputConverter;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.core.io.Resource;
import org.springframework.stereotype.Service;

// [8장 · 글쓰기 도우미 · 핵심 서비스]
// 이 클래스가 "AI에게 물어보고 결과를 정리하는" 일을 모두 합니다.
//   1) 프롬프트 템플릿(writing-assistant.st)에 사용자 입력을 채운다  → PromptTemplate
//   2) 완성된 문장을 AI(ChatClient)에게 보낸다                        → ChatClient
//   3) AI의 JSON 답변을 자바 객체로 바꾼다                           → BeanOutputConverter
// 스프링 AI 덕분에 OpenAI, OpenRouter 등 "어떤 AI 회사"를 쓰는지 이 코드는 몰라도 됩니다.
@Service
public class WritingAssistantService {

    // AI와 대화하는 "전화기" 역할입니다. 설정(application.yml)을 보고 스프링이 자동으로 만들어 줍니다.
    private final ChatClient chatClient;

    // 빈칸(중괄호 {...})이 있는 문장 양식을 실제 문장으로 채워 주는 도구입니다.
    private final PromptTemplate template;

    // AI가 준 JSON 글자를 WritingSuggestionsResponse 객체로 바꿔 주는 "번역기"입니다.
    // getFormat()은 "이런 JSON 모양으로 답하라"는 안내문을 만들어 줍니다.
    private final BeanOutputConverter<WritingSuggestionsResponse> outputConverter =
            new BeanOutputConverter<>(WritingSuggestionsResponse.class);

    // 생성자: 스프링이 필요한 재료를 넣어 줍니다(의존성 주입).
    //  - ChatClient.Builder : AI 전화기를 만드는 공장
    //  - promptResource     : src/main/resources/prompts/writing-assistant.st 파일 자체
    public WritingAssistantService(
            ChatClient.Builder chatClientBuilder,
            @Value("classpath:prompts/writing-assistant.st") Resource promptResource
    ) {
        this.chatClient = chatClientBuilder.build();
        this.template = new PromptTemplate(promptResource);
    }

    // 실제 기능: 사용자 입력 → 프롬프트 → AI 호출 → 제안 목록(DTO)
    public WritingSuggestionsResponse getWritingAssist(WritingSuggestionRequest request) {
        // (1) 템플릿의 {title}, {content}, {question}, {format} 자리를 채워서 최종 프롬프트 문장을 만듭니다.
        String prompt = template.create(request.toMap(outputConverter.getFormat())).getContents();

        // (2) 만든 문장을 AI에게 보내고, 답변 글자(content)만 받습니다.
        String response = chatClient.prompt().user(prompt).call().content();

        // (3) AI가 준 JSON 글자를 WritingSuggestionsResponse 객체로 바꿔서 돌려줍니다.
        return outputConverter.convert(response);
    }
}

    package me.shinsunyoung.springbootdeveloper.controller;

import lombok.RequiredArgsConstructor;
import me.shinsunyoung.springbootdeveloper.domain.Article;
import me.shinsunyoung.springbootdeveloper.dto.*;
import me.shinsunyoung.springbootdeveloper.service.BlogService;
import me.shinsunyoung.springbootdeveloper.service.WritingAssistantService;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RequiredArgsConstructor
@RestController
public class BlogApiController {

    private final BlogService blogService;
    // [8장 · 글쓰기 도우미] AI에게 글쓰기 제안을 받아오는 서비스입니다.
    // @RequiredArgsConstructor 덕분에 final 필드들은 생성자로 자동 주입됩니다.
    private final WritingAssistantService writingAssistantService;

    @PostMapping("/api/articles")
    public ResponseEntity<Article> addArticle(@RequestBody AddArticleRequest request) {
        Article savedArticle = blogService.save(request);
        return ResponseEntity.status(HttpStatus.CREATED)
                .body(savedArticle);
    }

    @GetMapping("/api/articles")
    public ResponseEntity<List<ArticleResponse>> findAllArticles() {
        List<ArticleResponse> articles = blogService.findAll()
                .stream()
                .map(ArticleResponse::new)
                .toList();
        return ResponseEntity.ok()
                .body(articles);
    }

    @GetMapping("/api/articles/{id}")
    public ResponseEntity<ArticleResponse> findArticle(@PathVariable long id) {
        Article article = blogService.findById(id);
        return ResponseEntity.ok()
                .body(new ArticleResponse(article));
    }

    @DeleteMapping("/api/articles/{id}")
    public ResponseEntity<Void> deleteArticle(@PathVariable long id) {
        blogService.delete(id);
        return ResponseEntity.ok()
                .build();
    }

    @PutMapping("/api/articles/{id}")
    public ResponseEntity<Article> updateArticle(@PathVariable long id,
                                                 @RequestBody UpdateArticleRequest request) {
        Article updatedArticle = blogService.update(id, request);
        return ResponseEntity.ok()
                .body(updatedArticle);
    }

    // [8장 · 글쓰기 도우미 · API] 브라우저의 "제안 받기" 버튼이 호출하는 주소입니다.
    // 흐름: 브라우저(JSON) → 이 메서드 → WritingAssistantService(AI 호출) → JSON 제안 목록 응답
    // 요청 예) POST /api/ai-suggestions  {"title": "...", "content": "...", "question": "..."}
    @PostMapping("/api/ai-suggestions")
    public ResponseEntity<WritingSuggestionsResponse> writingAssist(@RequestBody WritingSuggestionRequest request) {
        WritingSuggestionsResponse response = writingAssistantService.getWritingAssist(request);

        return ResponseEntity.ok()
                .body(response);
    }
}

// 흐름: 파일 검사 → FormData에 담기 → POST /api/upload → 받은 imageUrl을 숨김칸에 저장 → 미리보기
// 이미지 업로드 버튼
const imageUpload = document.getElementById('image-upload');
if (imageUpload) {
    // async: 이 함수 안에서 기다림(await) 없이 fetch를 쓰지만, 나중에 기다림을 넣기 쉽도록 붙여 둡니다.
    imageUpload.addEventListener('change', async (event) => {
        // 사용자가 고른 파일 목록 중 첫 번째 파일을 꺼냅니다.
        const file = event.target.files[0];
        if (!file) return;

        // 확장자가 아니라 "MIME 타입"(image/png, image/jpeg 등)으로 이미지인지 확인합니다.
        if (!file.type.startsWith('image/')) {
            alert('이미지 파일만 업로드 가능합니다.');
            return;
        }

        // FormData: 파일을 "폼 전송"처럼 담는 상자입니다. key 이름 'file'은 서버의 @RequestParam("file")과 같아야 합니다.
        const formData = new FormData();
        formData.append('file', file);

        // POST /api/upload 로 파일을 보냅니다. (Content-Type은 브라우저가 자동으로 맞춰 줍니다)
        fetch('/api/upload', {
            method: 'POST',
            body: formData
        }).then((response) => {
            // 서버가 201(Created) 등 성공 코드를 주면 response.ok는 true입니다.
            if (!response.ok) {
                alert('이미지 업로드에 실패했습니다.');
                throw new Error();
            }
            // 응답 본문(JSON)을 자바스크립트 객체로 바꿉니다. 예) {imageUrl: "/uploads/...png"}
            return response.json();
        })
            .then((data) => {
                // 받은 주소를 숨김칸(image-url)에 저장합니다. 나중에 "등록" 버튼이 이 값을 서버로 보냅니다.
                document.getElementById('image-url').value = data.imageUrl;
                displayImagePreview(data.imageUrl);
            })
            .catch((e) => console.error(e));
    });
}

                        html += `<li class="list-group-item suggestion-item" style="cursor: pointer;" data-suggestion="${suggestion.replace(/"/g, '&quot;')}" title="클릭하면 본문에 추가됩니다">
                                ${suggestion}
                                <small class="text-muted float-right">클릭하여 추가</small>
                             </li>`;
                    });
                    html += '</ul>';

    package me.shinsunyoung.springbootdeveloper.service;

import me.shinsunyoung.springbootdeveloper.dto.UploadResponse;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.UUID;

// [8장 · 이미지 업로드 · 내 PC에 저장하는 구현체]
// FileStorageService의 실제 구현입니다. 파일을 프로젝트의 uploads 폴더에 저장합니다.
// 서버를 운영할 때는 이 방식 대신 클라우드 저장소를 쓰는 것이 일반적입니다(인터페이스 덕분에 교체 쉬움).
@Service
public class LocalFileStorageService implements FileStorageService {

    // 파일을 저장할 "절대 경로" 폴더입니다. 예) C:/chapter8/uploads (자바 주석에서는 역슬래시를 쓰면 안 됩니다)
    private final Path uploadDir;

    // 생성자: application.yml의 app.upload-dir 값을 읽습니다.
    // 값이 없으면 기본값 "uploads"(프로젝트 안의 uploads 폴더)를 씁니다. ":" 뒤가 기본값입니다.
    public LocalFileStorageService(@Value("${app.upload-dir:uploads}") String uploadDir) {
        // toAbsolutePath(): 상대 경로를 전체 경로로 바꾸고, normalize(): ..\ 같은 중복 경로를 정리합니다.
        this.uploadDir = Paths.get(uploadDir).toAbsolutePath().normalize();
    }

    @Override
    public UploadResponse store(byte[] bytes, String filename) {
        try {
            // 1) 저장 폴더가 없으면 만듭니다. (이미 있으면 아무 일도 하지 않습니다)
            Files.createDirectories(uploadDir);

            // 2) 확장자(.png, .jpg 등)를 원래 파일 이름에서 잘라 냅니다. 점이 없으면 .png로 정합니다.
            String ext = filename.contains(".")
                    ? filename.substring(filename.lastIndexOf('.'))
                    : ".png";

            // 3) 같은 이름의 파일이 덮어써지지 않도록 UUID(무작위 고유 문자열)를 이름으로 씁니다.
            //    예) 3f2a9c1e-....png
            String saved = UUID.randomUUID() + ext;

            // 4) 실제로 디스크에 파일 내용을 씁니다.
            Files.write(uploadDir.resolve(saved), bytes);

            // 5) 브라우저가 이미지를 볼 수 있는 "웹 주소"를 돌려줍니다.
            //    WebMvcConfig가 /uploads/** 주소를 uploads 폴더와 연결해 줍니다.
            return new UploadResponse("/uploads/" + saved);

        } catch (IOException e) {
            // 파일 쓰기에 실패하면 실행을 멈추고 오류를 알립니다.
            throw new RuntimeException();
        }
    }
}

    package me.shinsunyoung.springbootdeveloper.service;

import me.shinsunyoung.springbootdeveloper.dto.GeneratorThumbnailRequest;
import me.shinsunyoung.springbootdeveloper.dto.GeneratorThumbnailResponse;
import me.shinsunyoung.springbootdeveloper.dto.UploadResponse;
import org.springframework.ai.chat.prompt.PromptTemplate;
import org.springframework.ai.image.Image;
import org.springframework.ai.image.ImageModel;
import org.springframework.ai.image.ImagePrompt;
import org.springframework.ai.image.ImageResponse;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.core.io.Resource;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestClient;

import java.net.URI;

// [8장 · 섬네일 자동 생성 · 서비스]
// 제목과 본문으로 AI 이미지 모델(ImageModel)을 호출해 섬네일을 만들고, 로컬에 저장합니다.
// 중요: 무료 모델(openrouter/free)은 이미지 생성을 지원하지 않아서 기본값으로 꺼 두었습니다.
//       @ConditionalOnProperty: app.thumbnail.enabled=true 일 때만 이 클래스를 등록합니다.
@Service
@ConditionalOnProperty(name = "app.thumbnail.enabled", havingValue = "true")
public class ThumbnailGeneratorService {

    private final ImageModel imageModel;
    private final PromptTemplate template;
    private final FileStorageService fileStorageService;
    private final RestClient restClient = RestClient.create();

    public ThumbnailGeneratorService(
            ImageModel imageModel,
            FileStorageService fileStorageService,
            @Value("classpath:prompts/thumbnail-generator.st") Resource promptResource
    ) {
        this.imageModel = imageModel;
        this.fileStorageService = fileStorageService;
        this.template = new PromptTemplate(promptResource);
    }

    // 전체 흐름: 프롬프트 만들기 → 이미지 생성 AI 호출 → 이미지 내려받기 → 로컬 저장 → 주소 반환
    public GeneratorThumbnailResponse generateThumbnail(GeneratorThumbnailRequest request) {
        String prompt = template.create(request.toMap()).getContents();

        // 이미지 생성 AI에게 프롬프트를 보냅니다. (OpenRouter 무료 모델에서는 이 호출이 실패합니다)
        ImageResponse response = imageModel.call(new ImagePrompt(prompt));
        Image image = response.getResult().getOutput();

        // AI가 준 이미지 "주소(URL)"에서 실제 이미지 데이터(바이트)를 내려받습니다.
        byte[] bytes = restClient.get()
                .uri(URI.create(image.getUrl()))
                .retrieve()
                .body(byte[].class);

        // 내려받은 이미지를 업로드와 같은 방식으로 저장합니다(FileStorageService 재사용).
        UploadResponse saved = fileStorageService.store(bytes, "thumbnail.png");

        return new GeneratorThumbnailResponse(saved.imageUrl());
    }
}

    package me.shinsunyoung.springbootdeveloper.controller;

import lombok.RequiredArgsConstructor;
import me.shinsunyoung.springbootdeveloper.dto.GeneratorThumbnailRequest;
import me.shinsunyoung.springbootdeveloper.dto.GeneratorThumbnailResponse;
import me.shinsunyoung.springbootdeveloper.service.ThumbnailGeneratorService;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

// [8장 · 섬네일 자동 생성 · API 창구]
// 원래 책에서는 BlogApiController 안에 있던 섬네일 주소를, 기능을 켜고 끌 수 있도록 따로 뺀 파일입니다.
// @ConditionalOnProperty: app.thumbnail.enabled=true 일 때만 이 주소(/api/ai-thumbnails)가 살아납니다.
//   - 꺼져 있으면(false, 기본값) 요청 시 404 Not Found가 나오는 것이 정상입니다.
@RequiredArgsConstructor
@RestController
@ConditionalOnProperty(name = "app.thumbnail.enabled", havingValue = "true")
public class ThumbnailApiController {

    // 실제 섬네일 생성은 서비스가 맡습니다. 컨트롤러는 "요청을 받고 결과를 돌려주는" 역할만 합니다.
    private final ThumbnailGeneratorService thumbnailGeneratorService;

    // POST /api/ai-thumbnails  {"title": "...", "content": "..."} → {"imageUrl": "/uploads/....png"}
    @PostMapping("/api/ai-thumbnails")
    public ResponseEntity<GeneratorThumbnailResponse> thumbnailGenerator(@RequestBody GeneratorThumbnailRequest request) {
        GeneratorThumbnailResponse response = thumbnailGeneratorService.generateThumbnail(request);

        return ResponseEntity.ok()
                .body(response);
    }
}
