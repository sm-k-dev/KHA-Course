CSS가 겹칠 때 브라우저는 어떤 스타일을 선택할까?

CSS는 웹 문서의 옷을 입히는 규칙입니다. 그런데 같은 글자에 색을 여러 번 지정하면 무엇이 최종 화면에 보일까요? 이 PDF의 핵심은 그 선택 기준인 캐스케이딩, 우선순위, 상속입니다.

정확히 보기 일반 스타일과 !important 스타일은 따로 비교합니다. 그래서 “무조건 사용자 스타일이 1등”처럼 외우면 헷갈릴 수 있습니다.
ZIP 다운로드 HTML만 받기
1. 겹치면 우선순위를 본다 더 강한 규칙이 약한 규칙을 덮어씁니다.
2. 같은 힘이면 나중 것이 이긴다 같은 종류의 CSS라면 아래쪽에 쓴 규칙이 적용됩니다.
3. 부모 스타일은 자식에게 전달된다 글자색, 글꼴 같은 일부 속성은 안쪽 태그로 이어집니다.

캐스케이딩의 뜻

캐스케이딩은 물이 계단처럼 위에서 아래로 흐르는 모습을 떠올리면 쉽습니다. CSS에서는 여러 스타일 규칙이 동시에 적용될 때, 정해진 순서와 힘에 따라 최종 스타일이 결정된다는 뜻입니다.

겹침

한 요소에 스타일이 여러 개 올 수 있음

예를 들어 같은 제목에 color: green과 color: brown이 함께 지정될 수 있습니다.

판정

브라우저가 규칙을 비교함

브라우저는 출처, 적용 범위, 작성 순서 등을 비교해 가장 알맞은 규칙을 고릅니다.

결과

최종 화면에는 하나가 보임

여러 규칙이 있었더라도 사용자 눈에는 최종으로 선택된 스타일만 보입니다.

스타일 시트 종류

스타일은 어디에 적었는지에 따라 종류가 나뉩니다. 실무에서는 보통 관리가 쉬운 외부 스타일 시트를 많이 씁니다.

종류 쉬운 설명 예시
브라우저 기본 스타일 아무 CSS를 쓰지 않아도 브라우저가 기본으로 적용하는 모양입니다. 제목은 굵고 크게, 링크는 파랗게 보이는 기본값
인라인 스타일 HTML 태그 안에 style 속성으로 바로 적는 방식입니다. <p style="color:red">
내부 스타일 시트 HTML 문서 안의 <style> 태그에 모아 적는 방식입니다. <style> p { color: blue; } </style>
외부 스타일 시트 CSS만 따로 파일로 저장한 뒤 HTML에 연결하는 방식입니다. <link rel="stylesheet" href="css/mystyle.css">

CSS 기본 선택자

선택자는 “누구에게 스타일을 줄 것인가?”를 정하는 표시입니다. 사람을 부를 때 이름, 반, 전체 방송을 구분하는 것과 비슷합니다.

선택자 뜻 작성 예시
전체 선택자 문서의 모든 요소를 선택합니다. * { margin: 0; }
타입 선택자 같은 태그 이름을 가진 요소를 모두 선택합니다. p { font-style: italic; }
클래스 선택자 같은 이름표를 붙인 여러 요소를 선택합니다. 이름 앞에 점을 붙입니다. .bg { background-color: #ddd; }
id 선택자 문서 안에서 한 번만 쓰는 특별한 이름표입니다. 이름 앞에 #을 붙입니다. #container { width: 500px; }
그룹 선택자 여러 요소에 같은 스타일을 한 번에 적용합니다. h1, h2 { text-align: center; }

스타일 우선순위

같은 요소에 여러 스타일이 걸리면 브라우저는 먼저 “얼마나 중요한가?”, 다음으로 “얼마나 정확하게 찍었는가?”를 봅니다.

출처

어디에서 온 스타일인가?

일반 스타일만 비교하면 보통 제작자 스타일이 사용자 일반 스타일보다 우선합니다. 반대로 사용자 !important는 제작자 !important보다 강합니다.

범위

얼마나 정확하게 지정했는가?

넓게 “모든 문단”을 고르는 것보다, 특정 id나 class를 찍는 규칙이 더 강합니다. 단, !important는 선택자 힘보다 먼저 비교되는 특별 표시라 남용하지 않는 편이 좋습니다.

브라우저가 판단하는 순서

1
중요도와 출처 일반 규칙인지, !important인지, 브라우저/사용자/제작자 중 어디에서 온 규칙인지 봅니다.
2
선택자의 구체성 같은 조건이라면 인라인, id, class, 타입처럼 더 정확히 찍은 선택자가 강합니다.
3
작성 순서 위 조건까지 같으면 CSS에서 나중에 나온 규칙이 먼저 나온 규칙을 덮어씁니다.
4
상속 직접 지정된 값이 없을 때 부모에게서 물려받은 값이 사용될 수 있습니다.

같은 제작자 CSS 안에서 자주 만나는 강한 순서

!important일반 규칙보다 우선
인라인 스타일태그 안 style
id 스타일#container
클래스 스타일.accent
타입 스타일p, h1

초보자용 기억법: “같은 조건이라면 정확히 찍을수록 강하다.” 전체 안내 방송보다, 이름을 콕 집어 부르는 말이 더 강하게 전달됩니다.

소스 작성 순서

중요도와 적용 범위가 같다면, CSS 파일에서 나중에 작성한 스타일이 먼저 작성한 스타일을 덮어씁니다. 

p {
  color: black;
}

h1 {
  color: brown !important;
}

p {
  color: blue;
}

<h1 style="color: green">레드향</h1>
<p style="color: red">껍질에 붉은 빛이 돌아 레드향이라 불린다.</p>
<p>레드향은 한라봉과 귤을 교배한 것으로</p>

레드향

껍질에 붉은 빛이 돌아 레드향이라 불린다.

레드향은 한라봉과 귤을 교배한 것으로

일반 귤보다 2~3배 크고, 과육이 붉고 통통하다.

  1. 제목은 갈색 h1에는 인라인으로 초록색이 있지만, 타입 스타일에 !important가 붙어 갈색이 최종 적용됩니다.
  2. 첫 문단은 빨간색 p 타입 스타일보다 태그 안에 직접 쓴 인라인 스타일이 더 강합니다.
  3. 나머지 문단은 파란색 p { color: black; }과 p { color: blue; }는 같은 타입 스타일이므로 나중에 쓴 파란색이 적용됩니다.

스타일 상속

HTML 태그는 부모와 자식 관계를 가집니다. 부모에게 글자색이나 글꼴을 지정하면, 자식 태그가 따로 지정하지 않는 한 그 스타일을 물려받을 수 있습니다.

부모

body에 글꼴을 지정하면?

문서 안의 많은 태그가 body의 자식이므로, 따로 지정하지 않은 글자는 같은 글꼴을 이어받습니다.

예시

부모의 색과 글꼴을 이어받은 문장

이 문단은 부모 영역에 지정된 글자색과 글꼴을 그대로 사용합니다.

모든 속성이 상속되는 것은 아닙니다. PDF의 팁처럼 배경색이나 배경 이미지는 일반적으로 자식에게 그대로 상속되지 않습니다. 직접 지정한 스타일이 있으면 상속값보다 직접 지정한 값이 우선하고, 직접 지정한 값끼리 충돌하면 다시 우선순위와 작성 순서로 판단합니다.

연습 문제 핵심

PDF 마지막 문제는 내부 스타일 시트를 외부 스타일 시트로 분리하고, class와 id 선택자를 제대로 쓰는지 확인합니다.

문제 1: 내부 CSS를 외부 CSS로 바꾸기

<style> 안의 CSS만 잘라서 mystyle.css 같은 파일에 저장합니다. HTML에서는 <link> 태그로 그 CSS 파일을 연결합니다. 

<link rel="stylesheet" href="css/mystyle.css">
문제 2: class와 id 빈칸 채우기

전체 영역처럼 한 번만 쓰는 큰 상자는 id="container"가 어울립니다. 여러 곳에서 강조할 수 있는 빨간 글자는 class="accent"가 어울립니다. 

#container {
  width: 600px;
  margin: 20px auto;
}

h1 {
  display: inline-block;
  background-color: #0404aa;
  color: #fff;
}

.accent {
  font-weight: bold;
  color: red;
}

마지막 체크

  • 캐스케이딩: 여러 CSS가 겹칠 때 최종 스타일을 정하는 과정
  • 우선순위: 중요도와 출처를 먼저 보고, 그다음 선택자의 구체성을 봄
  • 작성 순서: 같은 힘이라면 나중에 쓴 규칙이 적용됨
  • 상속: 부모의 일부 스타일이 자식 태그로 전달됨
  • 외부 CSS: 스타일을 별도 파일로 관리해 여러 HTML에서 함께 사용 가능

한 문장으로 끝내기

CSS 캐스케이딩은 “겹친 스타일 중 무엇을 최종으로 보여줄지 고르는 규칙”이고, 그 판단에는 중요도, 출처, 선택자의 구체성, 작성 순서, 상속 관계가 함께 사용됩니다.
