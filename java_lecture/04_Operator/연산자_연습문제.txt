[3-1] 다음 연산의 결과를 적으시오.

[연습문제/ch3/Exercise3_1.java]

class Exercise3_1 {
    public static void main(String[] args) {

        int x = 2;
        int y = 5;
        char c = 'A';   // 'A'의 문자코드는 65
		
		=======================================================================================
		
        System.out.println(1 + x << 33);												정답: 6
        	설명
        		1 + 2 << 33
        		3 << 33
        		int는 4 byte, 32bit 이므로 33번 시프트 하지 않고 1번만 시프트 한다.
        		3 * 2 와 같으므로 6
        		
        		자바에서 int 타입으로 시프트 연산을 할 때 33번을 밀지 않고 1번만 미는 이유는, 
        		자바 언어 명세(Java Language Specification)에 "시프트 이동 횟수는 자동으로 32로 나눈 나머지값(뒤의 5비트)만 사용한다"라는 규칙이 정해져 있기 때문입니다.
        		
        		컴퓨터 CPU는 시프트 연산을 할 때 속도를 높이기 위해, 시프트 횟수를 나타내는 숫자의 하위 5개 비트만 읽어서 연산하도록 하드웨어적으로 설계되어 있습니다.
        		2진수에서 5개 비트(00000 ~ 11111)로 표현할 수 있는 최대 숫자가 딱 0부터 31까지입니다.
        		33을 2진수로 바꾸면 100001인데, 맨 뒤 5자리인 00001(10진수로 1)만 쏙 잘라서 써버리는 것입니다.
        		
        		만약 long x = 3, x << 33 일때는, long 타입일 때는 1번이 아니라 33번을 그대로 다 시프트 합니다!타입이 int에서 long으로 바뀌면 컴퓨터가 칸수를 깎는 기준(나머지 연산의 기준)도 함께 바뀝니다.
        		
        		int 타입 (32비트): 시프트 횟수를 32로 나눈 나머지를 씀 (칸수 % 32)
        		long 타입 (64비트): 시프트 횟수를 64로 나눈 나머지를 씀 (칸수 % 64)
        		
       	=======================================================================================
        		
        System.out.println(y >= 5 || x < 0 && x > 2);
        
        =======================================================================================
        
        System.out.println(y += 10 - x++);
        
        =======================================================================================
        
        System.out.println(x += 2);
        
        =======================================================================================
        
        System.out.println(!( 'A' <= c && c <= 'Z' ));
        
        =======================================================================================
        
        System.out.println('C' - 'c');
        
        =======================================================================================
        
        System.out.println('5' - '0');
        
        =======================================================================================
        
        System.out.println(c + 1);
        
        =======================================================================================
        
        System.out.println(++c);
        
        =======================================================================================
        
        System.out.println(c++);
        
        =======================================================================================
        
        System.out.println(c);
        
        
    }
}

[3-8] 아래 코드의 문제점을 수정해서 실행결과와 같은 결과를 얻도록 하시오.

[연습문제]/ch3/Exercise3_8.java

class Exercise3_8 {
    public static void main(String[] args) {
        byte a = 10;
        byte b = 20;
        byte c = a + b;                         => byte c = (byte)(a + b);

        char ch = 'A';
        ch = ch + 2;							=> ch = (char)(ch + 2);

        float f = 3 / 2;						=> float f = 3 / 2f; 
        	// 정수 / 실수 = 실수
        	
        long l = 3000 * 3000 * 3000;			=> long l = ( 3000 * 3000 * 3000 )L ;

        float f2 = 0.1f;
        double d = 0.1;

        boolean result = d==f2;					=> d == (double)f2;

        System.out.println("c="+c);
        System.out.println("ch="+ch);
        System.out.println("f="+f);
        System.out.println("l="+l);
        System.out.println("result="+result);
    }
}


[실행결과]
c=30
ch=C
f=1.5
l=27000000000
result=true
