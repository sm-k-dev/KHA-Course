[해설] 문자열과 덧셈연산을 하면 그 결과는 항상 문자열이 된다.

             문자열  + 숫자   
          -> 문자열  + 문자열  ->  문자열 
          
             숫자   +  문자열
          -> 문자열  +  문자열 ->  문자열
          
          =================================
          
          ""  +  7  ->  ""  +  "7" -----> "7"
          
          7   + ""  ->  "7" +  ""  -----> "7"
         
         ======================================= 
          
          7   +  " " -> "7" + " "  -----> "7 "
		 
		 " "  +   7  -> " " + "7"  -----> " 7"

		 =======================================
		 
		 7  +  7 + ""  ->  14  + "" -> "14" + "" ----> "14"
		 
		 "" +  7 +  7  ->  "7" + 7  -> "7"  + "7" ----> "77"
		 ========================================
		 
		 true + ""  ->   "true" + "" -----> "true"
		 
		 null + ""  ->   "null" + "" -----> "null"

====================================================================================

[해설] 하지만 문자와 문자의 덧셈연산 결과는 int형 정수값이 된다.
	  왜냐 하면 int형 보다 작은 타입(byte, char, short)은 
	  int형으로 변환된 후에 덧셈연산이 진행되기 때문이다.		 
	  
  'A' + 'B'의 경우,  char + char ->  int  + int -> int의 과정을 통해 최종결과는 int형 정수값이 된다.	

  					'A' + 'B' ->    65  +  66 -> 131     'A'와 'B'의 문자유니코드값은 각각 65와 66이다.
  					'1' +  2  ->    49  +   2 -> 51      '1'의 문자유니코드값은 49이다.
  					'1' + '2' ->    49  +  50 -> 99

[2-10] char타입의 변수에 저장될 수 있는 정수 값의 범위는? (10진수로 적으시오)
0 ~ 65535

char는 2 byte ( 2 * 8 = 16 bit) 이므로 2의 16제곱 개의 값을 표현할 수 있다.
2의 16 제곱은 65535 개이며, 0을 포함해야 하므로 0 ~ 65535 (모두 65536개) 가 char 범위가 된다.
